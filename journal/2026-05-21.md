## UEFN dashboard UI/UX pass

Sam reported tooltip z-height issues and misaligned UI on the UEFN Demand
Intelligence dashboard. Did a focused CSS/JSX pass on
[UefnDemandDashboard](../path-builder/src/components/UefnDemandDashboard/).

**Tooltip clipping root cause:** stacked `overflow: hidden !important` on
ancestor containers (`.uefn-demand-dashboard`, `.dashboard-columns`,
`.column-suggestions`, `.column-trending`) clipped tooltips regardless of
`z-index: 99999`. `z-index` can't escape an `overflow: hidden` parent.

Changes:

- Dropped `overflow: hidden` on those four containers (kept internal scrolling
  on `.suggestions-list` / `.trending-list`, where the existing CSS already
  flips tooltips below the trigger).
- `.suggestion-metrics`: `align-items: baseline` → `center`, plus
  `flex-wrap: wrap` so confidence/decay/trends/SEO badges align with the
  numeric metrics instead of floating off the baseline.
- `.suggestion-meta-row`: baseline → center so platform dots line up with the
  category text.
- Removed pixel hacks (`margin-top: 1px` on rank, `top: 1px` on platform dot).
- `.column-header`: dropped the `min-height: 125px` hack, split into
  `column-header-top` + filters rows so the heading + Blue Ocean toggle sit
  cleanly on one row.
- Moved Blue Ocean toggle's inline styles into `.blue-ocean-toggle` CSS.
- Consolidated duplicate `max-width` on the dashboard root, cleaned dup
  margins on `.granular-coverage`, purged stale `!important` overrides on
  `.stats-bar`, `.provenance-footer`, `.industry-filter-row`.
- Replaced fixed `width: 60% / 40%` column widths with `flex: 3 1 0 / 2 1 0`
  and `min-width: 0` so flex math drives sizing.
- Rewrote the 900px media query (it was redeclaring row layout instead of
  stacking) to actually collapse to single column.

Bundled into the same commit as the regional UEFN feature
(`f76156a9` on `uefn-demand-by-region`) which landed via PR #140 →

## Follow-ups worth considering

- Align local pre-push with CI (`--max-warnings 0`) so deploys never silently break again.
- Tooltips inside `.suggestions-list` still clip when a card sits at the very
  top of the scrolled viewport — the flip-below CSS handles "first visible
