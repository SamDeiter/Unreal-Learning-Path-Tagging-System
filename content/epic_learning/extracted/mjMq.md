# Unreal Fest 2025: Control Rig: Tips & Tricks for Linear Content

*This lab explores powerful features in Control Rig to help creators build rigs faster, add unique functionality, and reuse setups across multiple skeletal meshes. Through short, focused examples, participants will learn practical techniques such as simulations, proxy controls, procedural setups, dynamic hierarchies, custom controls, deformers, and morph target integration. Aimed at beginner to intermediate users with basic Control Rig knowledge, the session emphasizes working smarter with Control Rig’s unique toolset, uncovering hidden features, and expanding creative possibilities for linear content creation.*
