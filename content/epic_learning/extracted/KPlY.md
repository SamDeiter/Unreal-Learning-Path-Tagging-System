# An Introduction to the Mover Plugin | Unreal Fest 2024

*The recently released Mover plugin is an experimental tool supporting movement of actors with rollback networking. In this session, we will  discuss its high-level concepts, compare it with CharacterMovementComponent, take a look at what's running under the hood, and see what's planned for future development. Please note the README documentation file was missing from the initial 5.4 release -- but will be included in the 5.4.4 hotfix.*
