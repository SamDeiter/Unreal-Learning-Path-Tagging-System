# Chaos Cloth Outfit Asset Resizing Addendum

*This is an addendum of the Chaos Cloth Outfit Asset workflow introduced in 5.6 allowing for the ability to resize garments to work with the new parametric Metahuman Character Creator. This is the first release for the Cloth Outfit Asset, and there are a few caveats and issues you may encounter with the workflow which this document will hopefully help guide you through*
