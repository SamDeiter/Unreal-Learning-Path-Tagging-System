### Submitting Questions and Feedback

The best way to ask questions and submit feedback is on the Forums. There is a Substrate Feedback Thread that can be used for questions and comments. If you have more focused feedback that might require a longer conversation, please start a new thread under Rendering. Before starting a new topic, please search the forum first to see if there is already a relevant thread.
