# Modernizing Game Development with Visual Studio and AI | Unreal Fest 2024

*Watch this recorded session from Unreal Fest Seattle 2024 in which Microsoft demonstrates how Visual Studio can speed up your iteration cycle from start to finish. 

Discover productivity tools for optimizing class structure memory layout; identify and rectify build issues with Build Insights integration; and explore performance enhancements. 

Microsoft also covers advanced Unreal Engine integrations such as Blueprint references and directly editing your uproject. Lastly, you’ll get an in-depth look at the latest advancements of GitHub Copilot, regardless of your source control system.

To learn more about Unreal Engine, check out our website: https://www.unrealengine.com/en-US*
