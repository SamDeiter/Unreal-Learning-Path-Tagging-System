# Using Visual Dataprep with Datasmith

*The Datasmith Dataprep tools are a recent evolution in Unreal Engine. These tools can be extremely helpful for users importing content from a program like Revit or SketchUp, enabling them to understand and control the data they are importing before it is added to the project. In this course, you’ll learn about some of the different ways these tools can be used to help automate workflow. 

By the end of the course, you’ll be able to import and manipulate a large dataset before adding it to a project.*
