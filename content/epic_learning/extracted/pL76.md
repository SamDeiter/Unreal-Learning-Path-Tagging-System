# Surviving State Tree: A Real Case Study with Dinosaurs | Unreal Fest 2024

*Watch this recorded session from Unreal Fest Seattle 2024 that explores the development of ‘Goner’, a survival game with dinosaurs.

You’ll get an insight into how developer Black Shamrock gained extensive experience with State Tree, the new system for supporting AI development in UE5 and how they developed a set of tools and best practices for effective use of this system. 

This talk provides a straightforward overview of State Tree, focusing on the challenges Black Shamrock encountered and the solutions they implemented to create harmony between AI, gameplay, and animation.
