### SLAY Project

The SLAY Project represents a collaborative effort between Mold3D and Epic Games demonstrating the latest techniques and workflows for real-time content creation. More specifically, it offers insights into all areas of production in Unreal Engine and is a great project to reference as you are learning about real-time workflows.

The Slay Workflow videos provide a brief overview of the production process used on the project.
