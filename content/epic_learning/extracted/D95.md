# Unreal Engine Editor Fundamentals

*In this course from the Epic Online Learning team, learn how to navigate the various parts of Unreal Engine Editor and customize your workspace to suit your needs. We'll touch on the Toolbar, Viewport, World Outliner, Detail Panel, Content Browser. We will also cover Editor, Project, and World Settings.*


## 📁 Unreal Engine Editor Fundamentals Overview

Feel overwhelmed by the Unreal Engine Editor? Don't worry, we've got you covered. In this course, we'll take you through the basics of navigating around the Unreal Engine Editor and customizing it to your needs. Learn how to use the Viewport, Outliner Panel, Details Panel and Content Browser. Plus, get tips on modifying settings for your projects on a world level and project level.


### RUNNING TIME

47 minutes


### WHAT YOU'LL LEARN


### You'll learn how to:

- Navigate the Unreal Engine Editor interface and menus.
- Customize the Unreal Engine Editor Layout.
- Organize Assets and their properties in a project.
- Override World Settings on a per-level basis.
- Modify the Editor and Project by changing the Editor and Project Settings.
