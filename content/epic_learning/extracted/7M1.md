# Accessible Design with Unreal Engine

*In this course from Epic's online learning team, we will introduce you to Accessible Design with Unreal Engine.*


## 📁 Accessible Design in Unreal Engine Overview

Discover how to improve your projects by giving users options to enhance their overall experience through Accessible Design. We’ll start by touching on some common challenges and disabilities users might experience and some common accessibility features to help. We will then look at a few examples of accessibility features and how we can use them. Explore how subtitles work in the engine, how Color Vision Deficiency settings can improve the readability of our project, and how we can improve the user interface to enhance the overall experience for our users.


### RUNNING TIME

43 minutes


### WHAT YOU'LL LEARN


### You will learn how to:

- Identify examples of disabilities and ways to improve those users' experiences inside of Unreal Engine.
- Use the Color Vision Deficiency settings inside of the Unreal Engine and modify the settings are runtime.
- Add subtitles to audio assets and adjust the font used for the display.
- Create user interface options which are more accessible to all users.
- Locate additional features and options inside of Unreal Engine that can help to add more accessibility to projects.
