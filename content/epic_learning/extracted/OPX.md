# Virtual Puppeteering and Input Based Animation

*In this course from the Epic Online Learning team, you’ll learn how to build a digital puppet that can perform using just a controller. Create the puppet using a Skeletal Mesh, a Control Rig, input-based slider controls, and an Animation Blueprint. Use Take Recorder and Sequencer to record multiple puppets in one scene.*


## 📁 Virtual Puppeteering and Input Based Animation Overview

Bring a digital puppet to life with a single controller for live or pre-recorded performances! In this course, we’ll create a hierarchy using a Skeletal Mesh, a base Control Rig, input-based slider controls, and an Animation Blueprint for smooth puppet performance. Then, we’ll discuss some ways to record a performance with multiple puppets in Unreal Engine.


### RUNNING TIME

2 hours 15 minutes


### WHAT YOU'LL LEARN


### You'll learn how to:

- Set up Inputs Events in Unreal Engine to receive user input.
- Make an Animation Blueprint to read Blueprint Actor data.
- Drive Control Rig animation with UI Widgets and Input Events.
- Use Sequencer Subscene Tracks to combine separate performance takes into one scene.
- Record Actor performances driven by Control Rig with the Take Recorder.
