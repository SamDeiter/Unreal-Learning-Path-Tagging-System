## 📁Introduction to HoloLens 2 Mixed Reality Production for Unreal Engine

Learn how to develop mixed reality experiences on the HoloLens 2, from setup to submission, with Unreal Engine! Join Kevin Lyle as he provides comprehensive instruction on the process, including best practices, accessibility concerns, and common pitfalls.

Starting from a blank project, we will navigate our way through standalone-feature specific courses and take advantage of the Mixed Reality Toolkit to learn and implement many of the skills and features required to build immersive, interactive, and performant experiences in mixed reality.


### RUNNING TIME

7 hours 25 minutes

Technical Requirements:

- HoloLens2

### WHAT YOU'LL LEARN


### You'll learn how to:

- Set up a HoloLens and Unreal Engine development environment.
- Build HoloLens apps that use AR-specific features such as hand and head tracking, world mapping, and voice input.
- Implement interactive functionality using Blueprints.
- Appreciate the technical constraints around building HoloLens apps for standalone hardware, and some of the techniques for achieving acceptable performance.
- Prepare a finished HoloLens application for building and submitting to the Microsoft Store.

### Prepare Unreal Engine for Mixed Reality Development

Runtime: 33 minutes

In this course, you will learn how to configure Unreal Engine to develop HoloLens applications. You’ll prepare the Engine for development by ensuring you have the prerequisites and the HoloLens 2 target platform installed.


### Gaze and Head Interactions

Runtime: 56 minutes

Gaze input is the most basic form of interaction on the HoloLens. This course will walk through how to use HoloLens eye-tracking to let users interact with your software using their gaze. We will explore best practices for gaze interactions, ranging from how to design natural-feeling interactions to ways to avoid causing motion sickness.


### Incorporate Hand Interactions with UX Tools

Runtime: 1 hour 7 minutes

Hand controls are essential for creating a natural-feeling mixed reality experience. Using the Mixed Reality UX Tools open-source library to create hand interactions and reactive objects in HoloLens experiences, you’ll learn best practices and pitfalls to keep in mind when designing hand interactions for HoloLens.


### Implement UI with UX Tools and Unreal Motion Graphics

Runtime: 55 minutes

In this course, you’ll begin designing and building user interfaces (UI) for HoloLens.  Learn how immersive UIs differ from traditional flat UIs, best practices while building an efficient UI for hand interactions, and how to set up and effectively use the built-in UI components provided by the UX Tools open-source library.


### Sound Design for Spatial Audio

Runtime: 20 minutes

This course covers the importance of spatial audio in mixed reality experiences, how to use HoloLens’ spatial audio technology, and some quick debugging tips for when things don’t go as intended.


### Designing for Voice

Runtime: 38 minutes

In this course, you’ll learn how to augment your existing user interfaces with voice-based controls. You’ll learn best practices for designing voice interfaces that augment, rather than replace, hand controls.


### Mapping the Real World

Runtime: 1 hour 7 minutes

This course will explain how to use spatial mapping and room scan visualization to capture and render a 3D representation of the world around you that can be accessed directly in your applications. This learning path will focus on locally-stored world anchors.


### Retrieving Camera Data

Runtime: 12 minutes

This course will show you how you can read the incoming data from our PV Camera, located above the visor on the Hololens 2, and apply the feed directly to a texture for meshes or UI.


### Tools and Principles for Project Optimization

Runtime: 40 minutes

In this course, you will gain an understanding of the optimization tools available in Unreal Engine. These tools are recommended as a first pass for developers that wish to quickly investigate application performance, at the expense of more precise information.


### Prepare Your HoloLens App for Submission

Runtime: 24 minutes

This course will walk you through everything you need to take your finished HoloLens app and submit it for distribution on the Microsoft Store, as well as how to build and bundle an application for remote rendering.


### Multi-User Experiences with Azure Spatial Anchors

Runtime: 33 minutes

In this course, you will learn how to expand on the world-mapping techniques learned in the Mapping the Real World course to include multi-device experiences where different people can experience a shared mixed reality in the same physical space.
