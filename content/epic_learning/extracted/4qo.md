# Unreal Engine 3D Fundamentals Resource Guide

*This course is designed to provide educators and students with resources that will help them develop skills related to 3D Fundamentals with Unreal Engine.*


## Unreal Engine 3D Fundamentals Resource Guide

This course is designed to support educators and students in learning 3d Fundamentals with Unreal Engine.


### Unreal Engine 3D Fundamentals Resources

This course is designed to support educators and students in learning key concepts related to Interactive 3D with Unreal Engine.


### Unreal Engine 3D Fundamentals Certification

The Unreal Engine 3D Fundamentals certification powered by Gameplan is an ideal credential for secondary education courses and CTE pathways in game design, animation, virtual production, and digital art. It can be used to culminate a sequence of courses or validate independent learning. This certification serves as a powerful capstone for any student building foundational skills in interactive 3D with Unreal Engine.


### How to use this Resource Guide

We suggest that you use a project based approach to teaching Unreal Engine using a comprehensive curriculum that covers all of the topics through authentic projects that help students demonstrate true proficiency using the tools. The resource guide is designed to supplement your curriculum and ensure that there are learning materials specific to many valuable topics. Consider this as a reference and study guide, but this resource is not intended to serve as a full Unreal ENgine curriculum.
