# Tips and Tricks to Get Your Projects Shipping Faster! | Unreal Fest Gold Coast 2024

*In this talk, I discuss a range of topics spread across different domains that will help you produce and deliver games quicker.

- Using message bus systems to simplify subsystem communications.
- Common replication patterns, when to use them and how they work under the hood.
- Using the enhanced input system to simplify input handling.
- Using threads together with Blueprints to improve both performance and ease of content creation.
- Using Instanced Structs for simplifying data communication. 
- How to implement hotfixes into your game for rapid patching.
- Improving production pipelines through automation tools such as Jenkins and Unreal Game Sync.
- Improving the Steam Online Subsystem with handy features to improve production and QA flow.*
