# Fundamentals of Sequencer

*In this course from the Epic Online Learning team, we’ll explore how to bring scenes to life with Sequencer! Learn how to add Sequence tracks, animate objects, use keyframe animations, build cinematic sequences, and render them with the Movie Render Queue.*


## 📁 Fundamentals of Sequencer Overview

Want to use animation to bring your project to life? This course will show you techniques for animating scenes. Learn how to locate sequences, add sequence tracks, animate objects with keyframe animations, build cinematic sequences, and render sequences using the Movie Render Queue. Take your first steps in animation with this course!


### RUNNING TIME

24 minutes


### WHAT YOU'LL LEARN


### You'll learn how to:

- Identify where to locate sequencer and why it would be used.
- Add Sequence tracks to animate objects in a scene.
- Animate an object using Keyframe Animations.
- Build a cinematic sequence using a Master Sequence.
- Render Sequences using the Movie Render Queue.
