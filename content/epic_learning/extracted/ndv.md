# Supporting Photorealism through Cinematics

*In this course from Epic Online Learning, we create a cinematic shoot that takes place in a photorealistic city. Discover how easy it is to create a cinematic sequence with Sequencer; learn how to add camera shake to your shots; and perform the last touch-ups before you render out the final product.*


## 📁 Supporting Photorealism through Cinematics Overview


### RUNNING TIME

2 hours 16 minutes


### WHAT YOU'LL LEARN

You'll learn how to:

- Create a realistic city environment using a Post-Process Volume.
- Add camera shake to Cine Cameras using Sequencer.
- Export an EXR Sequence of the cinematic with the Movie Render Queue.
