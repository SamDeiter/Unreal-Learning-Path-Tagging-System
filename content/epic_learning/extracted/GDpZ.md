# Introducing the XR Creative Framework for Virtual Production and Beyond | Unreal Fest 2023

*The XR Creative Framework is a ground-up redesign of the VR Scouting tools that shipped as Experimental in Unreal Engine 5.1, and which unlock so much potential for XR-native foundational editor tools spanning everything from virtual production and previsualization, to animation, design, and more. Join this session to learn how to create a custom tool and use it as inspiration for your own innovative tools to empower new in-engine workflows.*
