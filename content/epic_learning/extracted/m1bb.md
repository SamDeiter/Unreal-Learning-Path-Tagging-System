# Automated Dialogue Workflows at Embark Studios | Unreal Fest 2023

*At Embark Studios, we aim to create scalable, stable, and easy-to-use workflows in all disciplines. Dialogue in games is commonly associated with large-scale file management, recording and editing schedules, complicated localization workflows, and expensive last-minute changes. Being a small studio with a small audio team, such a giant system has been one of our biggest challenges.

In this talk, I will show how we use state-of-the-art text-to-speech integrated in custom Unreal Editor widgets to convert large amounts of written dialogue lines into usable game assets - in one click. We’ll also cover how we use the LogicDriver plugin to build our own custom Dialogue State Machine system—an extremely versatile and powerful tool to script any Dialogue event in our games.*
