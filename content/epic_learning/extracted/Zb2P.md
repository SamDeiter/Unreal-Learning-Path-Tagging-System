# Game-Changing Inputs: Navigating Enhanced Input in Unreal Engine and Conquering Common Challenges | Unreal Fest Gold Coast 2024

*In this comprehensive session on Enhanced Input in Unreal Engine, we'll guide attendees through the essential setup process, briefly compare against the legacy input system, and explore advanced implementation techniques. 

Starting with a foundational overview, we'll swiftly navigate through the setup intricacies to ensure a seamless integration into your projects. Delving deeper, we'll speak about our previously successful methodologies used across various projects, focusing on scalability and compatibility with diverse peripherals, and discuss the decision-making process behind different input solutions for distinct user groups, ensuring an intuitive experience. 

We’ll then look at how the Lyra starter game implements some of its more interesting Enhanced Input functionality, and we'll showcase strategies and best practices that can be used in other projects.*
