# Faceware Retargeter

*Faceware provides tools to create believable facial animations. In this course from the Epic Online Learning Team, we discuss how to use Retargeter to apply tracking data onto a MetaHuman character’s Facial Rig, and then import that animation into Unreal Engine 4.*


## 📁 Faceware Retargeter Overview

Faceware provides tools to create believable facial animations. In this course, we import a MetaHuman character into Autodesk Maya and use Faceware Retargeter to apply a tracked performance. Explore ways to clean up tracked animation and batch process multiple performances. Then, we’ll transfer to Unreal Engine and render a sequence of our retargeted performance.


### RUNNING TIME

1 hour 54 minutes


### WHAT YOU'LL LEARN


### You'll learn how to:

- Capture and edit a facial performance video with correct specs to be used in Faceware.
- Track a facial performance in Analyzer to capture a performer's subtleties.
- Create a unique character setup for the facial rig in Retargeter.
- Apply tracking data to a character’s facial rig using Retargeter.
- Import an animated character in Unreal Engine to be showcased in Sequencer.
