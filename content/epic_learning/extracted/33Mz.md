# Runtime Hardware Acceleration of Neural Networks in Unreal Engine | Unreal Fest 2024

*Watch this recorded session from Unreal Fest Seattle 2024 in which the Qualcomm team explores real-time machine learning inference techniques in Unreal Engine for mobile platforms. 

The discussion delves into Unreal Engine’s latest Neural Network Engine APIs and introduces plugins created by the Snapdragon Studios team making use of Qualcomm’s AI Stack to leverage dedicated neural network hardware acceleration. 

Additionally, we cover optimization techniques and tools available for deploying large neural network models on mobile platforms.
