# A Simple Spline Animation Rig for Cinematics

*Every cinematic project needs simple and nimble rigs to work quickly and efficiently. If it takes too long to set up, it’s not worth the time to do it. Vehicles, FX, Characters, and special Lighting setups all can use these types of sharable rigs that can be quickly added to a scene and animated by anyone on the team. Lets dig in to see how we can create a car rig that respects the topology of the ground, but also changes on the fly.*
