# Building Games with Unreal Engine and Horde on AWS | Unreal Fest 2024

*Watch this recorded session from Unreal Fest Seattle 2024 that explores how to accelerate your builds with a CI/CD tool purpose-built for Unreal Engine.

Horde, released in Unreal Engine 5.4, is a powerful automation tool built by Epic Games. In this session, you’ll learn about the features of Horde, how Epic runs Horde on AWS internally, and how you can get started using Horde yourself with the open source Cloud Game Development Toolkit. 

Watch to find out why Horde should be the default choice for CI/CD workloads at studios using Unreal Engine.

To learn more about Unreal Engine, check out our website: https://www.unrealengine.com/en-US*
