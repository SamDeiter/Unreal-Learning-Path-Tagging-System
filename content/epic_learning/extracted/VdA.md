# Blueprint Debugging

*In this course by Epic Online Learning, discover various methods to identify and resolve bugs in your project Blueprints. Use Print String, Breakpoints, Debugger Window, and Debug Shapes to see Blueprints running in real-time, and use Enabling/Disabling Nodes to isolate bugs for efficient troubleshooting.*


## 📁 Blueprint Debugging Overview

Being able to identify any problems in your code is an important step in solving them. 
Let’s discuss some methods to track and display the data from your Blueprints in real-time, as well as isolate sections of your project for troubleshooting.


### RUNNING TIME

34 minutes


### WHAT YOU'LL LEARN


### You'll learn how to:

- Evaluate changes to values at runtime using the Print String node.
- Use Breakpoints to evaluate data at runtime in Blueprint code.
- Visualize data at runtime with the Blueprint Debugger window.
- Visualize data at runtime with Debug Shapes.
- Enable and disable nodes to alter the flow of execution in any Blueprint.
