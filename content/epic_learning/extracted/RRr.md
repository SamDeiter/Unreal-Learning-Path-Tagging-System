# Camera Framework Essentials for Games

*In this course from the Epic Online Learning team, use C++ and Blueprints to create polished in-game Cameras. Examine some types of Cameras in Unreal Engine: Static, Dynamic, and Active. Explore Spring Arms, Camera Shakes, and transitioning between multiple Camera View Targets.*


## 📁 Camera Framework Essentials for Games Overview

Cameras are an often overlooked but vital part of player experiences in games. In this course, we’ll consider when to use different types of cameras—Static, Active, and Dynamic—and how to use some native Unreal Engine components for Spring Arms and Camera Shakes. We will also discuss how to smoothly transition between multiple cameras using Camera View Target Blends.


### RUNNING TIME

2 hours 1 minute


### WHAT YOU'LL LEARN


### You'll learn how to:

- Learn the general concepts around Cameras and the Unreal Engine Camera Component.
- Implement and customize your own Spring Arm Component.
- Learn how to implement different types of Camera Shake.
- Use the Camera View Target with Blends functionality.
- Bring all of the features together, as well as a few smaller miscellaneous features, to create better camera systems.
