# IK Retargeting - 5.1 Features at a Glance

*This is an overview of new IK Rig &amp; IK Retargeting features that have been added to Unreal Engine 5.1. These include Stride Warping, Speed Planting, Live Link Preview, Retarget Pose Improvements, Viewport Improvements, Retarget Profiles, and more. IK Rig &amp; IK Retargeting is Unreal Engine’s retargeting system, a powerful toolset to let you craft robust retargeting setups for any types of characters with different skeletal hierarchies.*
