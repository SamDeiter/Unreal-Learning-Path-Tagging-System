# Tooling for Broadcast: Driving Real-Time Events Through Remote Control

*Broadcast environments offer unique challenges due to there need for robust projects that can injest large amounts of data that need to be displayed at runtime. This session will look at different data types we deal with on a day to day basis and how you can ingest this data into the engine. We discuss the creation of our own ingest program, advantages and limitations. Using the remote control API to allow for fast integration and why data integration is important for creating unique realtime experiences.*
