# Projectiles and Pickups with Paper 2D

*In this course from the Epic Online Learning team, you’ll learn how to create projectile attacks for Enemy AI, a health system to track damage, health pickups, and environmental hazards. Adjust player cameras, improve default lighting, and add complex Tile Maps using the Tile Map Editor.*


## 📁 Projectiles and Pickups with Paper 2D Overview

Looking to upgrade your Paper2D projects? Learn how to create intelligent projectile attacks for Enemy AI characters and add a health system for your player. We’ll also explore how to refine our project by giving the player camera some lead room and adding environmental hazards, item pick-ups that heal players, improved lighting, and complex Tile Maps to our final Level.


### RUNNING TIME

2 hours 21 minutes


### WHAT YOU'LL LEARN


### You'll learn how to:

- Add the ability to damage Actors by changing health values using the built-in damage system.
- Implement a health system to track Actor health using the Blueprint visual scripting system.
- Implement a basic item pickup system with Blueprint.
- Create a camera that makes adjustments based on player velocity.
- Add elements to a 2D Level to impactfully change gameplay.
