# Unreal Game Sync (UGS) MSI Installer Creation for Easy UGS Distribution

*This tutorial walks through the steps for a studio to build its own installer with custom Perforce paths for Unreal Game Sync, which is a tool that simplifies custom engine stream management for studios using several streams and/or custom builds of Unreal Engine. The creation of a .MSI installer allows a central IT / source control admin to build UGS from source for the entire company with the required custom parameters, and distribute an easy installer for artists and other users to install on their individual workstations.*
