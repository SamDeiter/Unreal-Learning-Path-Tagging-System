# Learn Blueprint: Create Elegant Floating Items using Blueprint Part 2

*In Part 2 of the Elegant Floating Items tutorial series, you’ll learn how to take control of a custom Blueprint Actor in Unreal Engine through simple and flexible runtime logic. This includes enabling or disabling movement, setting up player interactions, using hotkeys for global state changes, and integrating event-driven behavior. The tutorial focuses on making the system easy to use for non-technical team members while supporting advanced use cases like Path Tracer compatibility, all with a clean and modular Blueprint design.*
