# IK Retargeting - 5.4 Features at a Glance

*This is an overview of new IK Rig &amp; IK Retargeting features that have been added to Unreal Engine 5.4. These include Auto Retargeting, Post Retarget Phase, QOL, and more. IK Rig &amp; IK Retargeting is Unreal Engine’s retargeting system, a powerful toolset to let you craft robust retargeting setups for any types of characters with different skeletal hierarchies.*
