# Unrestricted Innovation: The Development of Carnage | Unreal Fest 2024

*Watch this recorded session from Unreal Fest Seattle 2024 to learn how Offworld revolutionized the gameplay in ‘Starship Troopers: Extermination’ just months before release, thanks to a culture of iteration and innovation. 

Inspired by a famous movie scene, the team found a solution to uniquely pose vast numbers of dead bugs in a large world with little performance impact. 

This talk covers the rendering techniques used in creating a system to pose instanced meshes utilizing efficiently packed render targets. It also covers lightweight custom collisions.
