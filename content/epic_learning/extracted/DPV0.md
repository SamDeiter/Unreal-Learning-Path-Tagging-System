# The Bundle: How Reality Capture, Twinmotion, and Unreal Engine Work Together | Unreal Fest 2024

*Watch this recorded session from Unreal Fest Seattle 2024 that looks at how Unreal Engine, Twinmotion, and RealityCapture can be used in combination on projects. 

Unreal Engine’s new pricing model revealed in early 2024 allows anybody using Unreal Engine to get free access to both Twinmotion and RealityCapture. Some users already use all three products, but others were hearing about them for the first time. 

This talk illustrates the different domains of all three software and how they compliment each other for different types of users and projects. 

Watch to learn how to leverage Twinmotion if you were exclusively using Unreal Engine before; how RealityCapture can create content for either Twinmotion or Unreal Engine; the details around how Twinmotion content gets loaded into Unreal Engine and why you might want to do that; and how to determine if a project needs all three products or only one.*
