# How Territory Is Using Rive and Unreal to Bring Inspirational Futuristic Experiences into the Real World | Unreal Fest 2024

*Watch this recorded session from Unreal Fest Seattle 2024 that explores how Rive and Unreal Engine are changing the way we build futuristic UI and experiences for Hollywood feature films, games, automotive, and tech products.  

In this talk, Rive and motion design and VFX experts Territory showcase real-world use cases and demonstrate the benefits of using real-time tools for everything from game UI and screen graphics for film to automotive touch screens.
