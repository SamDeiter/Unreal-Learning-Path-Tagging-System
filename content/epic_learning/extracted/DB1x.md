# Gameplay

*In this module, Thiago Carneiro guides you through building and refining core gameplay systems in Unreal Engine. Starting with isolated character testing, you'll implement movement logic, flipbook animations, and collision handling. The lessons progress into advanced blueprint adjustments, camera setup, and responsive control refinement. You’ll also create enemy characters with basic AI, set up damage systems using hitboxes and visual feedback, and build foundational combat mechanics. The module concludes with a full integration of movement, combat, and health systems, optimized for a polished and responsive gameplay experience.*
