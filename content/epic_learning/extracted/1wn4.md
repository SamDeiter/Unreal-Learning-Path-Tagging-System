# Unleash the Power of Unreal Engine for Industrial Applications Using PLM Data | Unreal Fest 2024

*Watch this recorded session from Unreal Fest Seattle 2024 that explores how to deploy UE assets for industries designing complex 3D systems, looking at integration in 3D data workflows and data management including cybersecurity constraints. 

You’ll see demos showcasing the approach employed by large OEMs leveraging UE, fed with CAD data, and integrated into business runtime applications for engineering. 

Topics covered include PLM interoperability; runtime async loading; user authentication; automatic map generation for Blueprint scripting; and runtime client with modular plugins architecture.

To learn more about Unreal Engine, check out our website: https://www.unrealengine.com/en-US*
