# UMG Viewmodels: Building More Robust and Testable UIs using MVVM | Unreal Fest 2023

*Join us for an informative presentation where we take a closer look at the newly introduced UMG Viewmodel plugin. We will explore how this plugin can bridge the gap between developers and designers, promoting effective cross-discipline collaboration and improving code maintainability through the adoption of the Model-View-Viewmodel (MVVM) pattern. 

This presentation will provide designers and developers with the knowledge and practical examples they need to setup their first Viewmodel-driven UI, as well as offering a sneak peak into some upcoming features on the roadmap.*
