## 📁 Creating and Modifying Control Rig Overview

Animate inside Unreal Engine with the Control Rig Plugin! This course covers the entire pipeline, including importing or creating rigs, animating characters directly in real-time, and using baking techniques to manipulate mocap animations.


### RUNNING TIME

1 hour 15 minutes


### WHAT YOU'LL LEARN


### You'll learn how to:

- Export character from an DCC application into Unreal Engine with proper settings.
- Create a Control Rig from scratch and get detailed info on the functionality of different nodes provided.
- Integrate Control Rig with your game projects using Blueprint or other production Pipeline.
- Use Sequencer to create and edit animations from scratch with Control Rig.
- Bake predefined animations with the Take Recorder.

### TECHNICAL REQUIREMENTS


### Course:

- Compatible with Unreal Engine 5.0

### Project Files:

- This course has no project files associated with it. However, if you would like to follow along yourself, you can use the Third Person Skeletal Mannequin from the Third Person template. You can either migrate it in or export and import it yourself. You can follow the provided documentation for instructions on how to do that.
