# Working Smarter in UEFN with Scene Graph | Unreal Fest Orlando 2025

*This session recorded at Unreal Fest Orlando 2025 demonstrates how Fortnite projects can benefit from Scene Graph. 

Watch to learn how to use Scene Graph prefabs and components to create reusable data-oriented designs for your project. 

The session also discusses how Scene Graph prefabs enable creators to reduce Verse code, iterate quickly, and reduce bug count. It also includes a comparison of the amount of Verse code in UEFN projects created both with and without Scene Graph.

Learn more about UEFN here: unrealengine.com/uses/uefn-unreal-editor-for-fortnite*
