# Skeletal Editor Usage Guide

*The Skeletal Editor is a new set of tools released with Unreal Engine 5.3 that will allow you to Create and Modify Skeletal Meshes. With these tools you can make modifications to skeletons, edit skin weights, and paint maps. This guide will show you how to get started with these powerful new tools.*
