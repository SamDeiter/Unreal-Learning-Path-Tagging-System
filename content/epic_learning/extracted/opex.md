# The Future of Animation Retargeting in Unreal Engine | Unreal Fest Orlando 2025

*Watch this session recorded at Unreal Fest Orlando 2025 for a showcase of the latest features in Unreal Engine 5.6 for animation retargeting—and find out what's to come in the future. 

This session explores how retargeting has changed since UE5 and what's new in UE 5.6, including a brand new Editor interface, support for drastically different character proportions, props, and more! You'll also get the hear about the direction of retargeting in Unreal Engine.

The session also shows how to easily set up a retarget for any kind of character with any set of animations, and how to use and navigate the new Retarget Editor.


Learn more about animation retargeting in Unreal Engine here: dev.epicgames.com/documentation/unreal-engine/animation-retargeting-in-unreal-engine*
