### Creating Super Mario collectible coin and powerup Blueprints (part 1)

Hello everyone, in this tutorial series we are going to learn how to create the blocks from Super Mario that generate coins as well as the surprise box that can generate different kinds of powerups - here we create an extra life power up.

In the tutorial i am going over how to code everything in blueprints and create one blueprint that can be customized for our need

In the following tutorials we will be modelling some simple assets using the Modelling tools in UE5 and adding UI elements to connect our blueprints code to.

I am going to add more ideas in further tutorials to create more mechanics from the Super Mario games - I hope you all enjoy this and learn from it

* I modelled the 2 blocks in Maya and they are free to download and follow along and use for your projects.
