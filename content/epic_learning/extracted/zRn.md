# Working with Assets in Unreal Engine

*In this course from Epic Online Learning, you’ll learn how to manage your assets for easy navigation and project optimization. Discover the best practices for basic asset management— including importing, creating, and deleting assets; locating assets and file directories; and exporting assets. Then, we look at some Unreal Engine features for efficient project management including Redirectors, migrating assets, Auto Reimport, bulk editing with the Property Matrix, and the Size Map tool.*


## 📁 Working with Assets in Unreal Engine Overview

Optimized projects start with intentional, efficient asset management. In this course, we discuss some core aspects of asset management including importing, creating, and deleting assets; locating files in Explorer; and exporting assets for use in other programs and projects. Then, we highlight some practical tools for keeping your projects streamlined and clean.


### RUNNING TIME

### WHAT YOU'LL LEARN


### You'll learn how to:

- Use the Size Map to view the memory that is used by assets.
- Edit multiple assets at once using the Property Matrix.
- Utilize the reference viewer to see the connections between assets.
- Migrate assets between projects with the built-in Migrate feature.
- Configure Unreal Engine to automatically re-import assets into a project.
