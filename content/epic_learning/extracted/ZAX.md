# Stylized Materials for Linear Content

*This course takes a look at developing static mesh materials and post processing materials for non-photoreal rendered looks using HLSL shaders, fresnel techniques, and textures.*


## Stylized Materials for Linear Content Development

A deep dive into creating stylized materials for static meshes as well as post processing materials.


## Introduction


### Challenge

Many animation and effects studios have limited knowledge of Unreal, and how the engine can be leveraged to make amazing content. The challenge presented here scratches the surface of material development, and how it can impact the stylization of a project, by creating a stylized material or group of materials that address a number of different looks that are more graphical in nature and less realistic by design. This project began with creating post processing effects, but evolved into a full set of stylized materials for both post processing, as well as static mesh materials which are applied to.
