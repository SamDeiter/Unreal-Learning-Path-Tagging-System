# Balancing Blueprints and C++

*Experience the best of both worlds with Blueprints and C++ in Unreal Engine. With best coding practices, you can structure projects to be more efficient in development and have better performance.*


## 📁 Balancing Blueprints and C++ Overview


### RUNNING TIME

30 minutes


### WHAT YOU'LL LEARN


### You'll learn how to:

- Recognize the strengths of Blueprints and C++ in Unreal Engine.
- Structure a project that follows coding best practices.
- Identify when it would be most advantageous for code to be converted to C++.
- Use classes with the programming language following best practices.
- Expose variables, functions, and events for designers and artists to use during development.
When should you use C++? What about Blueprints? How can you use both?

Different systems in the engine are designed around using Blueprints and C++, so it can be unclear which language to use. We’ll look at Blueprints and C++ in Unreal Engine, talk about their strengths, and how they can work together to make development easier for you and your team.

This course was written for learners who have some industry and game development experience. While you don't need to know anything about Unreal Engine, familiarity will help contextualize the content better.

Examples from the Lyra Starter Game are used throughout this course. You DO NOT need to download this project to understand or complete this course.
