# 13 Ways To Control Rig A Comic Book in Unreal Engine

*This quick tutorial is a window into how to rig a “turnable” page for a book in Unreal Engine using Control Rig. It doesn’t actually go through all 13 iterations of the process I went through, but it does, in it’s own way, emphasize the need to solve problems from many angles, which Unreal is very good at allowing artists to do.*
