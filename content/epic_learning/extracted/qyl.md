# Stylize Renders with Post Process Materials

*This course teaches strategies for non-technical animators and artists to achieve stylized renders with post-process Materials. Learn the theory, methodology, and tools to experiment in your own projects.*


## Introduction to Stylized Rendering

Instructor Kris Kaufman explores techniques and theories to create stylized renders using post process materials. Create flat shading, outlines, painterly effects, and more that can be applied to entire levels, or select Actors.
