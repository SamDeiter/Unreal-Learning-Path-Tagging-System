## What is DMX?

DMX, or Digital Multiplex, is a standard for digital communication networks, commonly used in the Live Events space to control simple to complex lighting and effects. It was originally intended as a standardized method for controlling light dimmers, which, prior to DMX512, had employed various incompatible proprietary protocols. It soon became the primary method for linking controllers, such as lighting consoles, to dimmers, as well as special effects devices like fog machines and intelligent lights.

DMX has also expanded and can now be used to control almost anything, from confetti launchers to lasers, which is reflected in its popularity with theaters and live venues.

In the context of Virtual Production, DMX is gaining momentum for several reasons: First, to control and trigger events in Unreal Engine by using a lighting desk. Second, to drive large sets of DMX-enabled lighting fixtures and devices. This can be done through the Pixel Mapping tool, where the generated image and pixels are used to drive a fixture's RGB values. Finally, high-quality previs of DMX-powered shows, projects, and virtual production setups can be created and viewed, all within Unreal Engine.


## DMX Protocols

We added DMX functionality by supporting both Art-Net and sACN industry variants.

Art-Net and sACN are network protocols that allow DMX data to aggregate and send over Ethernet (IP). Art-Net allows you to send 32,768 universes down a single network cable. Although it is an older protocol, it is supported by more gear and devices. sACN (streaming architecture for control networks), currently appears more popular and allows you to run 63,999 universes of DMX data down a single network cable.


## DMX Data

DMX can be thought of as a digital information package that is being sent from one location (our source) to a different location (our destination). Each package is created at some source with specific information that should be received and read by some recipients. Each packet is structured in a very intentional way and if you would like to know more about how this works on the hardware level, please read the ESTA Standards.

- ESTA Standards (pdf)
For our purposes, we are only concerned with the contained data. Each package contains an array of 512 bytes, and each byte has a value that ranges from 0-255.

Each byte is commonly referred to as a Channel. A transmitted package consisting of 512 channels is commonly referred to as a Universe. This is typically the maximum amount of data that can be reliably transmitted on a single DMX cable.
