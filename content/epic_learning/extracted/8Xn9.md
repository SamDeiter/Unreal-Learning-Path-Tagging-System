# Your First 60 Minutes with Gameplay Ability System

*In this tutorial we’ll go through many concepts of the Gameplay Ability System (GAS) and use them in a practical way. GAS is a framework for organizing gameplay values and behaviors for players, NPCs, items and interactables in reusable assets. GAS is used in Epic's own games, so it's a feature rich and battle tested system.*

- [{'type': 'paragraph', 'content': 'Scalable Floats: Damage that scales with the level of the applied GE. That level can come from player progression like a perk tree, the game’s difficulty setting or the level of an enemy NPC. A level can be provided when applying a GE that is used to do a lookup. With a ‘Scalable Float’, you can provide an optional curve table that defines per GE level how much to multiply the provided value.'}]
- [{'type': 'paragraph', 'content': 'Custom Calculation Class: A modifier in a GE can specify a custom calculation class. You can provide your own logic for how the modifier value is calculated or retrieved. For example: from actor properties, functions, based on the current movement speed or affected by whether the character is crouching, blocking or sprinting.'}]
- [{'type': 'paragraph', 'content': '<a href="https://dev.epicgames.com/community/learning/tutorials/DPpd/unreal-engine-gameplay-ability-system-best-practices-for-setup#whataresetbycallermagnitudes?">SetByCaller magnitudes</a>: the code that applies a GE can also provide custom values that are stored with a GameplayTag. That custom value can be directly used as an attribute modifier or retrieved by custom logic in GE Executions. A good example where SetByCaller is useful is when damage or knockback strength is affected by the impact velocity from a collision event.'}]
- [{'type': 'paragraph', 'content': '<a href="https://dev.epicgames.com/community/learning/tutorials/DPpd/unreal-engine-gameplay-ability-system-best-practices-for-setup#whataremetaattributes?">Meta Attributes</a> and <a href="https://dev.epicgames.com/community/learning/tutorials/DPpd/unreal-engine-gameplay-ability-system-best-practices-for-setup#howshouldiimplementdamagetypeslikefiredamage/fireresistance?">Executions</a>: When designers want to implement formulas that are more complex than attribute modifiers offer or involve game design specific steps like crit chance, dodge chance, typed damage resistances it’s common to introduce meta attributes and perform the calculation server-side in GameplayEffectExecutionCalculation classes: these allow you to run custom logic when applying a GameplayEffect by configuring its “Executions” property.'}]
