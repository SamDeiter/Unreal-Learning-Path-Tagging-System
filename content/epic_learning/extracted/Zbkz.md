# Memory insights and tracing with callstacks for Android

*Since UE 5.4, we have Memory Insights and tracing enabled for Android projects. Android developers can now see more detailed information about memory allocation and deallocation, including the Low Level Memory (LLM) tags and callstacks associated with each block of memory at any point in time.  Here is how you can enable it in Android projects.*
