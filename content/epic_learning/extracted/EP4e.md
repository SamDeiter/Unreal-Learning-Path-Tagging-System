# Workflows with Unreal Engine and OpenUSD | Unreal Fest 2024

*Watch this recorded session from Unreal Fest Seattle 2024 in which Sony Pictures Imageworks and Epic Games delve into USD workflow integration with Unreal Engine.  

Sony showcases their new pipeline and tools for producing rough layout using Unreal Engine and USD. The talk also includes an overview of current state and future plans for USD in Unreal Engine.
