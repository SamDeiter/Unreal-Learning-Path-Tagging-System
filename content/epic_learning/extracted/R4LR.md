# Custom Feature Detection Facilitating a Procedural 3D Twin of Earth | Unreal Fest 2024

*Watch this recorded session from Unreal Fest Seattle 2024 in which Blackshark provides a demonstration of the HUNTR and procedural content generation (PCG)-based 3D terrain generation process for a specific location (O'Ahu island). 

Check out how easy and efficient it is to create custom machine learning (ML) models, run them at large scale, and pass the data to Unreal Engine—and how great this capability works in combination with PCG and Megascans.

To learn more about Unreal Engine, check out our website: https://www.unrealengine.com/en-US*
