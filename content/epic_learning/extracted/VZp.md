# Virtual Scouting 2.0 User Guide

*Set up, use, and customize the new Virtual Scouting 2.0 tools.*


## Introduction to Virtual Scouting 2.0

An overview of the new Virtual Scouting tools and the prerequisites for using them.


### Overview

Unreal Engine’s Virtual Scouting tools have been completely rewritten from the ground up based on a new XR Creative Framework, which enables developers to create Headset-based XR tools using Blueprints.

This Virtual Scouting Plugin guide should serve as an example of how to build VR tools for the Unreal Engine Editor using the XR Creative Framework.

The legacy tools will be sunset and deprecated in a future Engine release. We encourage users to move to the new Virtual Scouting tools. Unused VREditor code and modules will be fully deprecated in a future engine release.


### Prerequisites

To use the new tools you must be using Unreal Engine 5.4 or higher, on a Windows PC, with VR-capable hardware and one of the following headsets:
