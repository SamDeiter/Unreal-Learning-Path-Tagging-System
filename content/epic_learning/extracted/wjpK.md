# Exploring the Power of Control Rig for Animation in Unreal Engine 5.4 | Unreal Fest Gold Coast 2024

*In this session, we'll explore the Power of Control Rig to build advanced animation rigs in Unreal Engine 5.4.

We'll dive deep into Control Rig graphs, demonstrating various rigging approaches such as iterative solving, data-driven rigging, control interactions, and proxy controls.
Together, we'll build two rig modules for the new Modular Rigging framework, and go over the new Layered Control Rigs along all the latest animation features in Unreal Engine 5.4.*
