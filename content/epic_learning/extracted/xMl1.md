# Extending Unreal Insights for Developers | Unreal Fest 2023

*This session will provide a deep-dive into the Unreal Insights profiling framework in Unreal Engine, demonstrating how to collect custom data from game systems through the Trace library and how to write custom extensions to visualize such data in the Unreal Insights application.

We’ll talk about the architecture of Trace and Unreal Insights and go through the complete step-by-step process from tracing data in your game code to writing UI code that visualizes it in Unreal Insights. 

This deep dive into Insights’ API and architecture will give you a great starting point to understand our profiling framework and extend it to include any game-specific information your project might require.

The target audience is developers familiar with C++ and working with engine code.*
