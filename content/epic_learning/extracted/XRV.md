### What is Motion Design?

Motion Design was developed for motion graphics artists who need a streamlined and creative suite loaded with familiarly designed tools that allow for rapid iteration and scalability. We left no stone unturned in the name of usability - this includes a reworked world outliner, user interface, rigging tools, cloners, customizable 2D/3D shapes, and a new way to create materials using a streamlined, layer-based workflow called Material Designer. In addition, everything you create can then be rigged with logic that allows for user customization and versioning through a variety of approachable solutions. We offer a robust Rundown tool that, in conjunction with our Transition Logic system, can run live-updated broadcast graphics with minimal rigging.
