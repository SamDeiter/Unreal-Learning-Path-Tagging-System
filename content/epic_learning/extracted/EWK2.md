# Motion Design: What's Coming in UE 5.6 | Unreal Fest Orlando 2025

*Watch this session recorded at Unreal Fest Orlando 2025 for a tour of some of the new features and use cases that will be useful for any motion graphics artist working in the broadcast and live events industry.

Unreal Motion Design is a UE feature set that enables you to create graphics and animations for broadcast and live events. 

We’ve pushed the motion design toolset further than ever before in Unreal Engine 5.6—check out the new updates that include cloners/effectors, improved video playback, new live data integration and scene state, text formatting improvements, updated support for packaged projects, PSD import, and much more!

Learn more about Unreal Motion Design here: dev.epicgames.com/documentation/unreal-engine/motion-design-in-unreal-engine*
