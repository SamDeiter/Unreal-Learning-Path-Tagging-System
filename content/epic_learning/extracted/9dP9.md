# Horde and Unreal Build Accelerator: Operating at Epic Scale | Unreal Fest 2024

*Watch this recorded session from Unreal Fest Seattle 2024 that covers Horde and Unreal Build Accelerator (UBA) from high-level overview to specifics around use. 

Introduced last year, UBA is Epic’s distributed build system. Watch this talk to find out how we use it at Epic for UE and internal projects, touching on efficiency savings, setup for studios, guidelines, and more. 

Horde is a service shipping with UE 5.5 that enables a collection of workflows that Epic has been shipping Fortnite and UE on for the last few years. In this video, we explore topics including (but not limited to) build automation (CI/CD), remote compilation of C++ code, services for managing dev kits, managing automated tests, collecting studio analytics, and more.

To learn more about Unreal Engine, check out our website: https://www.unrealengine.com/en-US*
