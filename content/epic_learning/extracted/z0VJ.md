# Getting Started with Texture Graph

*Get started exploring the experimental texture graph editor.  This  tutorial introduces the basic layout and functionality of the texture graph editor*

#### 

- [{'type': 'paragraph', 'content': 'Locate the TextureGraphEditor plugin in Edit &gt; plugins'}]
- [{'type': 'paragraph', 'content': 'Select TextureGraphEditor &gt; Restart Unreal'}]


#### 


#### 


##### 

- [{'type': 'paragraph', 'content': 'Save- Saves the current graph.'}]
- [{'type': 'paragraph', 'content': 'Open- Opens a graph from your content folder.'}]
- [{'type': 'paragraph', 'content': 'Export- The export tool opens the export window which controls the graphs final texture export. This window allows you to control which of the outputs in the graph get exported, you can choose to export just a single output or multiple textures if they exist.'}]

- [{'type': 'paragraph', 'content': 'Update- When Auto Update is not toggled on, the update tool will update the graph thumbnails and output previews. This can be useful for complex graphs where the auto updating can be slow.'}]
- [{'type': 'paragraph', 'content': 'Auto Update- The auto update toggle turns the graph auto update on or off. Depending on the complexity of the graph you may decide to toggle this option off.'}]
- [{'type': 'paragraph', 'content': 'Palette- Displays the palette of nodes.'}]
- [{'type': 'paragraph', 'content': 'Node Histogram- Displays the node histogram, the histogram provides valuable information about the texture distribution of values.'}]
