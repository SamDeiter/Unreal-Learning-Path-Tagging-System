# Unreal Engine for Live Performance: Big Sand Case Study | Unreal Fest Gold Coast 2024

*What happens when you put a live performer into Unreal Engine? What happens when you bring real-time performance to a physical venue with a live audience? What opportunities does Unreal Engine provide for games, music, and live performance to unite? 

In this session, you’ll hear how musician and former triple j presenter Sally Coleman created animated sci-fi band Big Sand using Unreal Engine, motion capture, streaming, and networking techniques. Big Sand’s first live shows have been world-first experiments using out-of-the box applications of Unreal Engine for live audiences.*
