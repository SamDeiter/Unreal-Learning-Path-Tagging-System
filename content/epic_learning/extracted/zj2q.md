# Demystifying Blueprints for Motion Design Artists

*This lab is designed to provide an approachable and useful introduction to Blueprints for motion design artists getting started with Unreal Engine.

Specifically tailored for motion graphics artists using UE5's Motion Design plugin, you’ll be introduced to creating and using the variables, events, and functions of the Blueprint visual scripting system to automate and extend motion graphics projects.*
