# Importing Blender Grease Pencil Sketches into the Epic Ecosystem

*This is a beginner tutorial to introduce the methods of importing Blender Grease Pencil sketches into the Epic Ecosystem. The Blender Grease Pencil is a 2D drawing system in Blender that allows users to draw directly in the 3D viewport. It can be used for 2D animation, storyboarding, 3D sketching, concept art, and illustrations.   There are a few simple ways that we can bring Grease Pencil data over to the Epic Ecosystem of tools, which can help in creating non-photorealistic styles.*
