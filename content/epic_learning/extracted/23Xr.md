# Animating Cinematics in Unreal: Lessons Learned from a Fortnite Animator | Unreal Fest Gold Coast 2024

*This session will dive into animating in engine to create epic cinematics. For newcomers to Unreal Engine, we’ll start with a basic overview of what animating in engine means. 

We’ll take a look at the pros and cons of working in Unreal Engine versus a more traditional animation software such as Maya. This talk covers the use of Sequencer and explores frequently used Unreal Engine Animation tools such as the Graph Editor, the Tween tool, Pose Library, constraints, and Control Rig.

Finally, we’ll do a deep dive into a Fortnite cinematic, which we’ll use as an example of how to set up a project in Unreal Engine and how to best structure your content to work collaboratively.*
