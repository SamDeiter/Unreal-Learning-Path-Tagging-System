# Scalable Pixel Streaming: From Building Your First Project to Cloud Deployment at Scale

*Pixel Streaming unlocks the ability to stream interactive, low latency Unreal Engine applications to any device with a web browser. Typical Pixel Streaming experiences include: high fidelity browser games; commercial product configurators; architectural visualization; virtual production; AI avatars and more.

his presentation demonstrates what Pixel Streaming is, the use cases it unlocks, and how to get up and running with Pixel Streaming in your projects. We introduce new features available in 5.2 and speak to the challenges of deploying and scaling Pixel Streaming in the cloud.We then present our solution to running Pixel Streaming in production at scale, “Scalable Pixel Streaming (SPS)”: a cloud-agnostic solution that allows you to run your Unreal Engine experiences in either Windows or Linux containers, scale based on demand, and save cost on expensive GPU instances.*
