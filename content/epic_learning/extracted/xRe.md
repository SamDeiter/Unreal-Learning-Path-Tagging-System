# Key Terms

Actor: Any object that can be placed into a level. Examples include a simple mesh, a character, or a camera.

Animation: A sequence of images showing changes in shape, size, rotation, or other properties of a character over time.

Aspect Ratio: The ratio of the width of an image to the height of an image.

Asset: A piece of content (sound, texture, or 3D model) that is used in Unreal Engine.

Blendshape: A tool that allows you to “blend” or animate facial expressions between different states.

Bone: A virtual bone is a segment between two adjacent joints.

Focal length: The distance between the camera lens and the camera sensor when the object of interest is in focus.

Frame: One single still image within an animation.

Frame Rate: The frequency or rate at which frames are shown in an animation, usually stated in frames per second.

Interactive 3D: A digital environment that allows for real-time 3D interaction. Examples of interactive 3D include video games, virtual reality (VR), and augmented reality (AR).

Joint: A point on a character where two bones join; joints can be rotated to pose a character.

Keyframe: The pose of a character at a certain time or “key...”

Level: Contains everything a player can see and interact with, like environments, usable objects, other characters, and lighting. Also referred to as a “map..”

Real-time rendering: The process by which digital 3D images are converted (in real time) to 2D images, allowing for immediate feedback and live interaction.

Rig: Digital rigs are the virtual bones, joints, and muscles that allow models to move. Once created, the rig can be used to animate a character.

Sequencer: A tool in Unreal Engine that allows you to create, edit, and preview animation sequences in real time.

Shot: A sequence of images or film taken with a continuous view from one camera.

Timeline: Displays the animation over time, which you can use to modify keyframes and preview your animation.

Track: A row in Sequencer containing keys for one or more controls..

Transform: Any movement, rotation, and scaling of an actor.

Unreal Engine: Computer software that uses real-time rendering to create interactive 3D environments.

UI (User Interface): The point of contact that allows the user to interact with computer software. Examples include the touch screen on a phone that can be pressed to activate underlying software or applications.
