# Odyssey: 2D Animation in Unreal Engine

*Bridge the gap between traditional 2D artistry and modern game engines by learning to navigate the Odyssey interface, animation tools, and pixel-art workflows within Unreal Engine. Through hands-on exercises, you will integrate 2D assets into 3D environments using level sequencing, material graphs, and specialized techniques like rotoscoping and mesh painting.*


## Odyssey: 2D Animation in Unreal Engine | Day 1

Get started with Odyssey and learn to use the Animation 2D asset Editor. This lesson covers the essential rater and vector tools you can use to draw, paint and transform your frames. You will also discover all the mechanisms from traditional 2D animation thanks to features like the Light Table, the Out-of-Peg or Stagger Cells.

Welcome to the course! Originally recorded as a live, five-day intensive, this training has been thoughtfully edited into modular lessons so you can progress through the material at your own pace. Before you dive into the tools, we recommend watching the introductory YouTube video and downloading the project files; you’ll also find a wealth of additional resources in the dedicated Box folder.
