# How to Build UI at Scale: Lessons from Marvel’s 'Midnight Suns' | Unreal Fest Orlando 2025

*In this session recorded at Unreal Fest Orlando 2025, Joel Gonzales explains the approach Turtle Rock Studios used to rapidly develop the many UI screens in Marvel's ‘Midnight Suns’ while minimizing defects along the way.

This talk covers the development and implementation of the UI architecture used, and how Firaxis was able to create the enormous breadth of UI screens the game required, including the ability to share functionality by reducing the complexity of UI creation.
