# Transforming Infrastructure Design With Unreal Engine Tools | Unreal Fest Orlando 2025

*In this session recorded at Unreal Fest Orlando 2025, infrastructure design giant HNTB explores how Unreal Engine enables them to create flexible and immersive visualizations for large-scale infrastructure projects. 

Topics include HNTB's custom Datasmith pipeline for importing GIS data and integrating their material pipeline, an interactive callout and chart system, and data-driven tools for construction sequences. 

HNTB's Python editor tools enhance Perforce integration and material creation, and expand customization of PCG foliage with OpenCV. Custom material graphs and HLSL shaders enable their artists to improve fidelity, introduce randomization, and address UV issues directly within Unreal Engine without constant round trips between other software. 

Finally, the session showcases HNTB's post-process materials for creating stylized environments, object highlighting, and custom mattes for compositing.
