# How to Build an Open World Game with 4,000 Strangers | Unreal Fest 2024

*In March, Epic launched Project Titan, a global collaborative game jam in which over 4,000 people signed up to build a massive 8x8km game world. In this talk, we explore the development of the project, the tools used to create and support it, and the back-end infrastructure that made it all possible.*
