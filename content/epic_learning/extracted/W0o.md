# Matrox Unreal Engine Plugin Guide for SMPTE 2110

*This course contains everything you need to know to set up and deploy SMPTE 2110 in Unreal Engine using a supported GPU and Matrox ST 2110 network card. It is intended for users who require high bandwidth SMPTE 2110 functionality, including the Broadcast and Film industry.*
