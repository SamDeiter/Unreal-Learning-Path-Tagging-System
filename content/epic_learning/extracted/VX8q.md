# Procedural Rigging with Control Rig

*In Unreal Engine 5.1 Control Rig has added a powerful new feature called the Construction Event. The Construction Event allows users to procedurally generate their rigs inside the Control Rig graph. This video will show you how to get started using the Construction Event and other new features for Control Rig in Unreal Engine.
