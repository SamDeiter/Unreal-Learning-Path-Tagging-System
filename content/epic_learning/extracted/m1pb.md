# Creating an Interactive Never-ending Procedural Music Album with MetaSounds | Unreal Fest 2023

*Unreal Engine offers an impressive array of tools for creating generative music and sound design. With deep integration into the engine, these tools unlock the potential for developing interactive and procedural music systems that incorporate synchronized visual elements, surpassing previous limitations. MetaSounds and the Quartz system have opened a door to another exciting application for Unreal Engine.

This talk will delve into the innovative “Sonic Lifeforms” technology, which generates professional-sounding soundtracks that continuously reinvent themselves, adapting to real-time parameters and user interactions.

We’ll also explore the development of the interactive music album Sonic Lifeforms - The Never-ending Album that has been released as as an iOS application. This project serves as a good example of the technology’s potential.*
