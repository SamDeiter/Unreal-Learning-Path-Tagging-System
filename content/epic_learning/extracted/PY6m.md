# Plugin-afying Lyra: Shipping a Game on the UE5 Lyra Framework | Unreal Fest 2024

*Watch this recorded session from Unreal Fest Seattle 2024 that explores how the Lyra Starter Game is a great place to begin for developers, but at larger scales it can become restrictive when you’re writing large chunks of game code from scratch. 

Many AAA studios are turning Lyra into a set of plugins that can be modularly composed into a compatible framework with runtime component loading and data plus tag-based modular gameplay. 

These plugins, properly crafted, can serve as an accelerated starting point for robust codebases delivering high-quality UE5 gameplay. Check out this video to find out how.
