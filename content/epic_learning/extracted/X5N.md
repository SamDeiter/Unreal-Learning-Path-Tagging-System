# Faceware Analyzer

*Faceware provides tools to create believable facial animations. In this course from the Epic Online Learning Team, we discuss how to capture and edit ideal footage for Faceware, track an actor’s facial performance in Analyzer, and train Analyzer for batch processing multiple recordings of the same performer.*


## 📁 Faceware Analyzer Overview

Faceware provides tools to create believable facial animations. In this course, we will discuss the challenges of using different styles of performance capture—pre-recorded footage, webcams, or head-mounted cameras—and how lighting, framing, and frame rate can affect tracking. Then, we dive headfirst into some of the features of Faceware Analyzer and explore how to batch process multiple performances.


### RUNNING TIME

1 hour 16 minutes


### WHAT YOU'LL LEARN


### You'll learn how to:

- Capture and edit a facial performance video using Faceware.
- Track facial performances in Faceware Analyzer to capture a performance.
- Create a unique character setup for the facial rig in Retargeter.
- Apply tracking data to a character’s facial rig using Retargeter.
- Import an animated character to Unreal Engine to be played in Sequencer.
