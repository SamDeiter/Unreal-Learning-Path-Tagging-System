# Building the Audio Inspector: How To Create a Great Workflow Using Data-Oriented User Experience | Unreal Fest 2023

*This session will present a way to approach building editor tools in Unreal Engine 5 that focuses on surfacing only the information relevant to the workflow and presenting it immediately and succinctly. 

As a case study, it will explore the development of SweejTech’s Audio Inspector plugin, examining the problem it aimed to solve, revealing how information is presented and refreshed using the Slate UI system, and highlighting its widespread adoption through the Unreal Engine Marketplace. 

The session will also include other dives into workflow development from SweejTech’s in-development products, which will focus on content creation and live-editing flows. 

We’ll present a tool development philosophy that focuses on data-oriented user experience, rather than the more traditional object-oriented user experience, and show how that can help teams and individuals work at scale in Unreal Engine 5.*
