# Vegetation Best Practices for UE5

*The complexity of a vegetation asset can vary greatly between a small flower and a majestic tree towering a forest. This session will share some of the current learnings into the technical limitations of common botanical problems and how users can work around them in their creation pipelines and applications. Topics will cover some of the best practices of when using Nanite but also for non-Nanite applications, to ensure content creation can be scalable across any platforms.*
