## 📁 Build a Third Person Character from Scratch Overview

Using the "Stack O Bot" project to build a third-person character that includes movement, cameras, animations, and a jetpack.


### RUNNING TIME

1 hour 15 minutes


### WHAT YOU'LL LEARN


### You'll learn how to:

- Build a basic movement system in a character Blueprint with the Enhanced Input System.
- Create different camera modes and view styles using Blueprints.
- Implement a range of Animation assets and physics based animations into an Animation Blueprint.
- Expand upon character movement by adding movement mechanics and animations to an existing character.
