# Optimizing the Game Thread | Unreal Fest 2024

*In this talk, Tanglewood Games will dive into the Game Thread in UE5 and explore how we can profile and optimize this.

Jake Simpson, Intermediate Programmer and Associate Lead at Tanglewood Games, will illustrate common issues using examples seen in real projects.

Using Unreal Insights, Jake will identify some of the common performance issues found in Unreal game projects and techniques that can help to get your timings down across the Game Thread, based on personal experiences.  

By the end of this talk, you’ll know how to identify a number of problems on the Game Thread and how you can diagnose and fix these.*
