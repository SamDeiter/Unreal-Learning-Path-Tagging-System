# Build Gameplay Mechanics for a Collectible Item Game

*In this course from the Epic Online Learning Team, create a single-player collectible item game featuring a pick-up and delivery mechanic. Use Blueprints to track player inventory and define a win condition based on time and score. Use UMG to show the player key information in a Heads Up Display (HUD) and for game start and end screens.*


## 📁 Build Gameplay Mechanics for a Collectible Item Game Overview

Building a single-player collectible item game is a great way to explore some basic elements of a complete game loop. Let’s consider how to visually communicate key information like score and time to players. We will also use Blueprints to continuously spawn items for players to collect, award players points for collecting and delivering items, and set a win/loss condition based on player score.


### RUNNING TIME

1 hour 52 minutes


### WHAT YOU'LL LEARN


### You'll learn how to:

- Alert a spawner that a pick has been claimed using Blueprint Interfaces.
- Interact with the delivery system with direct reference Blueprint communication.
- Use Blueprint to UMG communication to pass data to the UI.
- Control the start and end round gameplay experience with Event Dispatchers.
- Check if the player has scored enough points to win the game using Blueprint Casting.
