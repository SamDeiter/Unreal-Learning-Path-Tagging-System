# Designing Photoreal Environments for Cinematics

*In this course from Epic Online Learning, we cover the full range of techniques you need to create large scale cityscapes. Kitbash together existing high-quality assets to create a coherent theme. Learn how to use the Foliage Tool to build up your environment and create a Master Material for more versatility in lighting and color schemes. Populate a city with static signs and animated objects, then composite live-action videos into the scene using the Unreal Engine's Media Player pipeline.*


## 📁 Designing Photoreal Environments for Cinematics Overview


### RUNNING TIME

5 hours 34 minutes


### WHAT YOU'LL LEARN

You'll learn how to:

- Create large-scale urban environments with the foliage tool.
- Adjust Mesh UVs in the Static Mesh Editor.
- Simulate emissive surfaces with a Master Material for increased versatility.
- Populate a city with static and animated sign meshes in a quick and efficient way.
- Composite live-action videos into a scene using the Unreal Engine Media Player pipeline.
