# Chaos Cloth - Updates 5.7

*The Beta Chaos Dataflow Cloth Editor in 5.7 features editor improvements to the timeline and simulation controls as well as the porting of the Skeletal Mesh Editor painting and selection tools.  We’ve also added ClothAsset to Skeletal Mesh clothing data integration as well as some helpful cloth simulation properties.  This document will provide an overview of these 5.7 changes and updates as we continue to expand and develop new capabilities for our Cloth Dataflow Editor.*
