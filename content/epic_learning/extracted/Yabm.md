# Processing of the Habitat 67 Scan Data with the 3D Divider Script

*In this tutorial, you can download the Habitat 67 scan data that was used to create the photogrammetry mesh in the Hillside sample project. In total, 3199 images were acquired from a drone, and 207 terrestrial scan stations were used to capture Montreal's architectural icon. 

Because of the large volume of data, it was not easy to process it in RealityCapture and to render the final mesh in Unreal Engine. For this reason, we modified our existing divider script for processing large datasets. The old script only enabled dividing the reconstruction in 2D. The new divider script enables you to divide the reconstruction in 3D, which is very useful for vertical structures. In this tutorial, you'll learn how to use the script and how to easily process large datasets with thousands of images.*
