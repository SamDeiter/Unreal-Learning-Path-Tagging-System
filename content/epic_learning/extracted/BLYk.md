# ‘Hogwarts Legacy’: An Inside Look at Developing a Cross-Platform Open World Game in Unreal Engine | Unreal Fest 2023

*During this session, WB Games Avalanche tech leads will share the successful journey to get Hogwarts Legacy shipped across Sony PlayStation 5 and 4, Microsoft Xbox Series X/S and Xbox One, PC Steam, Epic Games Store, and Nintendo Switch.

We will cover development best practices for project setup, code and content submission guidelines and production tools, Unreal Engine assets data validation, CI and build distribution, game automation, profiling tools, and Unreal Engine upgrade process.

We will share details on the new Unreal Engine technologies we embraced, and the custom modifications needed for Hogwarts Legacy game, as well as outlining the key performance bottleneck areas we faced and how we optimized them to ship game at target frame rate.

Participants will get an end-to-end view of the development of a AAA game built with a large team spread across the globe using Unreal Engine, and come away with project setup best practices and performance optimization tips.*
