# Odyssey 2D Toolset: Enhancing Storytelling in Unreal Engine | Unreal Fest Orlando 2025

*In this session recorded at Unreal Fest Orlando 2025, Praxinos explores how the Odyssey 2D toolset can revolutionize your creative process in Unreal Engine. 

Whether you're a storyboard artist, animator, technical artist, or designer, Odyssey's powerful features can streamline workflows, enhance storytelling, and bring your projects to life with exceptional 2D art.

Watch to learn how Odyssey integrates seamlessly with Unreal Engine, offering new possibilities for animation, game design, and visual storytelling. 

Topics include creating 2D storyboards in a 3D environment; painting on 3D assets using Texture Editor and Decals; animating in 2D in a 3D environment for rotoscoping or 2DVFX; and how to paint post-processes.

Learn more about Unreal Engine here: www.unrealengine.com*
