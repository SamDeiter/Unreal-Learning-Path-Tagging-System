# Building AAA Mobile Games with Unreal Engine | Unreal Fest 2024

*In this talk, you’ll learn how to create stunning and smooth AAA mobile games on Android using Unreal Engine. 

You’ll discover the best practices for designing your game in pre-production, such as choosing the right lighting, setting realistic budgets, and optimizing your assets. 

We’ll also explore the features and tools that Unreal Engine offers for Android development, such as the mobile renderer, shading models, editor improvements, and toolchain improvements. All this will be presented through a live demo of a AAA mobile game running on an Android device.*
