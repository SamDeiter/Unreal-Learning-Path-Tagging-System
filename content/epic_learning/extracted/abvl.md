# Portal to Reality - Fusing Real-World Assets with Unreal Workflows Resources

*At Unreal Fest 2025 - Stockholm, I shared how to build high-fidelity, reality-based environments. This session guides you through separating key components like Substrate materials, lighting, cameras, and post-processing for better control and realism.
You'll learn how to set up your project for realism, including capturing your own lights and cameras, and upcoming AxF material support. The session covers lighting and camera setup techniques in portal-to-reality projects, including how to match real-world lighting using classification strategies and a custom light meter tool built in Unreal Engine.*
