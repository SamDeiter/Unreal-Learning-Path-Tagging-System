# Processing of the Habitat 67 Sample in RealityCapture

*In this tutorial, we will go through the steps of processing a small sample of the Habitat 67 scan that is part of the Hillside Unreal Engine sample project. Habitat 67 was scanned using terrestrial laser scanning and aerial and ground photogrammetry. RealityCapture supports the processing of all of these various sources of data. If the data is captured correctly, the alignment of laser scans with photogrammetry can be fully automatic with no manual user input, which is what we will show in this tutorial.*
