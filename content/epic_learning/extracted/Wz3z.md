# Making Of Twinmotion Demo Scene "Lakehouse" In Unreal Engine 5

*With Datasmith Twinmotion Importer Plugin, Twinmotion is not a closed box anymore when it comes to sending data across platforms. In this Making Of tutorial, environment artist Supameth Artwichai demonstrated step by step how he imported the Twinmotion demo scene Lakehouse into Unreal Engine 5, used Megascans trees from the Marketplace, painted vegetations, set sky, and created an animation in Unreal Engine.*
