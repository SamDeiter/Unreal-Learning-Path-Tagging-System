# Using UE5 to Build Modern VR Action Games | Unreal Fest 2024

*Watch this recorded session from Unreal Fest Seattle 2024 that explores how Survios built an immersive tech stack for 'Alien: Rogue Incursion' using Unreal Engine 5. 

Co-Founder and Chief Technical Officer Alex Silkin reveals how the team created a foundation to build action games that align with the high expectations for user experience of modern VR. 

This session covers the implementation of key systems, including player movement, physicalized avatars, props, player hand animations, and interactive object configurations. 

Learn how to effectively utilize and extend Unreal Engine's Chaos Physics, Enhanced Input, and Gameplay Ability System to elevate your VR game development.

To learn more about Unreal Engine, check out our website: https://www.unrealengine.com/en-US*
