# Introduction to Unreal Engine 5.3

*In this course, you will be shown the basics of how to interact with the Unreal Engine 5.0 Editor.  If you are new to Unreal Engine or going from Unreal Engine 4.0 to 5.0 this course is a must as it will help familiarize you with the Unreal Engine 5.0 editor layout as well as some of the most commonly used tools.*


## Introduction

This course introduces the instructor to the viewer and covers what areas of Unreal Engine 5 (UE5) the viewer will be introduced to.

- Architecture

- Virtual Production
