For additional 3D artwork using high-resolution textures, this compression is very effective with an almost imperceptible reduction in quality. Well, that's great in everything, but our textures are of a much lower resolution. If we look at the top of the Details panel, we can see that this texture is 512x256 pixels. For comparison, a single 3D character will often use multiple 2048x2048 textures, making compression and necessity. So, what does that mean for us? Well, it means two things. Firstly, our smaller textures won't really get much more late if they were compressed, and secondly, because we only have such a small number of pixels to play with, any compression artifacts would be much more obvious. This is because each individual pixel represents a much greater percentage of the whole. Moving down next to the level of detail rollout, we can see that the texture group has been changed to 2D pixels unfiltered. Normally, texture filtering will smooth things out and improve the overall look of the image. However, in our case, it'll just make the pixel art look blurry, which obviously isn't desirable. As we can see, Paper 2D is on a pretty good job of setting up this texture for us during the import process, but we do need to make a few quick adjustments. The first one is very quick. We need to make sure that no mid-maps are ever generated for these textures. We can do this within the level of detail rollout, locating the mid-gen settings and selecting no mid-maps. The intricacies of mid-mapping are beyond the scope of this course, but in short, mid-maps are used to reduce the detail of objects as they move further away from the camera. As we saw in the previous module, this project will be using an orthographic camera, which means that all objects are considered to be a single fixed distance from the camera. This means that mid-maps would serve no purpose, of the leading up space. The next thing we need to do is make the area behind the tiles transparent. If we look at the angled tiles and the railings in the viewport, we can see that the area behind them isn't actually transparent at the moment. It's a solid grey colour. We need to tell Unreal Engine to consider this grey colour as transparent by defining it as the Chroma Key. In the adjustments rollout in the details panel, check the Chroma Key Texture checkbox, indicating that we want to process a custom Chroma Key. Using the Chroma Key Texture checkbox allows us to select the Chroma Key colour option further down. Left-click the colour swatch next to the option to open the colour picker. Activate the eyedropper and select the grey colour directly in the central viewport. Click OK in the colour picker to select the colour and close the picker. We can see that the background of the texture has changed to alternating shades of grey, indicating true transparency.
