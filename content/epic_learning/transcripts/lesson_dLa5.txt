Hi, welcome to this course on real-time workflows with Faceware Studio. In this course, you'll learn to use Faceware Studio to create live and recorded facial performances for Metacumins in Unreal Engine. Upon completion of this course, you'll have learned how to use Faceware Studio to capture facial performance data using either live video sources or pre-recorded video. You'll learn how to tune and adjust the various facial performance channels being streamed from Faceware Studio and how to bring those streams into Unreal Engine through either the live link plugin or the Glassbox live client plugin. Finally, you'll learn how to record those facial performances and edit the resulting animations using tools in Engine. Let's get started.
