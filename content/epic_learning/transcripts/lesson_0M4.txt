In this module, we'll recap some of the ways that we can optimize our scene in Unreal Engine. At the beginning of any Unreal Engine project, you should keep in mind the hardware capabilities that your audience will be using when experiencing your Unreal Engine application. This will help you decide if some features may be too expensive to use, or how low poly your assets will need to be for you to reach your target frame rate. You learned that your current frame rate can be viewed by typing tilde stat FPS. You can also see the performance of your GPU and CPU by typing stat unit. We then used the GPU visualizer to find out what was causing our GPU to be the bottleneck when rendering our viewport. We noticed that our dynamic lighting and post-process volume effect were the biggest issues. We used stat scene rendering to gain an understanding of how many mesh draw calls were occurring in our project, and we used stat game to get a look at our game thread performance. You can use the command stat memory to get a view of your memory usage, and you can see a great breakdown of information for all of the textures and models used in your scene by going to the statistics window. We learned how to reduce the size of textures in the editor, and how to increase available memory by using streaming.pool size, and indicating the amount of megabytes to allocate to Unreal Engine. Using view modes, we were able to diagnose the scene using the light complexity, shader complexity, and quad-overdraw view modes. We also learned about LODs or levels of detail, how to create them, and how they are used to increase performance without sacrificing visual quality. We learned about the data-smith file type and how to import a data-smith file using a data prep asset. We added a simple recipe to automatically generate LODs for higher polymeshes before adding it to the project. We learned about the jacketing tool, which we can use to simplify 3D models or groups of models to eliminate or separate unneeded detail and polygons that we don't really need to render. Lastly, we learned about how to create UV maps in Unreal Engine for those times that we can't create them ourselves in a 3D modeling program. We'll wrap up this course by reviewing the importance of optimization for Unreal Engine, and taking a look at how much the scene has improved after the changes that we made in the project.
