There are three rig elements that you can create and use to set up your control rigs. These are bones, controls and nails. Let's create these and see what are the different options available for each of them. Let's start with the bone. So bone basically lets you add additional bones to the rig hierarchy. Now these bones are just transform elements with a parent child relationship and they can only be parented to other bones and are used for simulations, jiggles etc at runtime. To create a new bone just right click here and select new bone and you can see a new bone added to the rig hierarchy with transform properties here under the details panel. Moving on the next thing we can create in the rig hierarchy tab is controls. Controls are something that we are going to use the most. These are just visual shapes which are used to control or manipulate the bones while animating a character. To create a control you can just right click anywhere under the rig hierarchy tab and select new control or you can use the associated shortcut key control plus n to create it. This creates a visual shape that defaults to a small sphere. You can change the shape here under the details panel on the right using this shape drop down under the shape section. You can also change the color to your liking. Along with these two there are other shape related properties that you can manipulate. You can enable or disable the shape or toggle its visibility and even modify the transform. To modify the transform you can either punch in all the values here or you can utilize a cool new feature to directly edit the shape inside the viewport using the transform gizmo. To do that just select control plus period on the keyboard and this will toggle the viewport with this message to indicate your currently in the shape manipulation mode. In this mode just use the transform gizmos to set the desired transform values. Once you are done with that you can toggle out of this mode by pressing control plus period again on the keyboard. For controls there are different types that you can choose from the control type drop down placed under the control section of the details panel. This defines what properties of the controls can be animated. It defaults to Euler transform and you can see all the transform values segregated into different tabs for initial and current values along with the minimum and maximum values for setting limits. Additionally there are even more controls on what limits you can set under the minimum and maximum values. Just toggle these checkboxes placed to the left of each axis under individual parameters. Let's see all these in action and what happens if I switch to a different control type other than Euler transform. So let's assume a use case where I want to create a slider that opens the first when the slider value is set to 0 and closes at 100. The first thing I'll change is the control type to float and a new section called value pops up above the transform section. Now this contains the initial and current values along with the minimum and max tabs for limits. Now if you look under the transform section we are just left with three tabs out of which the initial and current agreed out. This is so that you don't get confused and make changes under the transform section instead of the value section for control type which are not Euler transform. Moving back to the value section you'll see the current value is set to 0.0. If I move my control to the right you'll see the current value going up to 100 but I can't move any further because of limits which is denoted by this red line in the viewport. You can disable drawing this debug line if you toggle this draw limits option under the details panel. Also it'll stop drawing limits if you toggle of either the minimum or max value like this. I'll keep it on for my slider. Now the slider always starts from 0 but I don't want the fills to be completely open by default. I want it somewhere around 30% open by default for a more relaxed pose. To do that let's change the initial value to 30 and once I hit compile you'll see the control moving to 30% mark by default. Since this is going to control the first let's place this control close to the left hand where it makes more sense. For that we can either punch and values under the offset transform or we can do it in a very intuitive fashion by switching our event mode to setup event up here in the toolbar. As the name suggests setup event allows us to setup our rig by moving all the regaliments in the viewport and setting up their offset transform. With my event mode set to setup event I can move the float control close to the rest. And once I'm happy with the placement I can toggle back to the forward solve by clicking on the event mode button. It quickly switches back to the last event mode. I'll cover more about all the different event modes in a later module. Now you can also change the primary axis to align it with any direction that you want. I'll leave it to X for now. That looks perfect. I'll go ahead and change the shape to a box and change the control scale to make it look more like a slided handle. Now let's switch the control type back to Euler transform and you'll notice that the shape transform and the offset transform stay the same. Talking about transform there are these small gizmo like icons to the right of the transform label. You can left click on this to individually toggle the transform coordinates between local and world space for location rotation and scale or you can just shift click to toggle all three at once. For rotation you can choose the type of rotation you want from this drop down menu. This helps you compare your rotation values with other applications where the coordinate systems might be different. For example in Unreal the z-axis is the up vector whereas in DCC application it's the y-up. So you can easily choose the rotation format. Along with the control type we have other properties under the control section like the display name which helps us in defining how we want the control name to appear in the sequencer track while animating. I'll leave it blank so the display name would be the same as the name property. Finally we have the animatable property for a control which defines if the control can be animated in the sequencer or not. In most cases it should be set to true as the primary purpose of creating a control is to give animators access to manipulate the skeleton using controls. Under controls the final rig element that we can create are nulls. If you are familiar with UE4 then consider null as an empty actor which can be used as the parent for a group of actors. Basically it does nothing but an intermediate transform that you can use to organize and offset controls. Nulls can be parented to any other element in the rig hierarchy tab as opposed to bones that can only be parented to bones. To create a null just right click in the rig hierarchy tab and select new null. This creates a null element which is indicated in the rig hierarchy tab by this locator icon. Under the details panel nulls have similar properties like bones where you'll see the initial and current transform. With that we have covered all the three rig element types that you can create in your rig hierarchy tab. And let's move on to the next module and start creating controls for the character.
