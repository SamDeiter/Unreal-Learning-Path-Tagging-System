In this final blueprint for the course, we are looking to give our end user the ability to change materials on actors populating our visualization project. This is a few challenges that we need to tackle, with the first and most obvious being the fact that we will need to create a way of getting the blueprint system to swap out materials using a predefined list. This could be done via a user interface of some sort, although this course is designed to get people who have zero experience with blueprints up and running, I think we will keep it as simple as possible and create a toggle instead. Now although this is relatively simple as compared to potential other approaches, there are still a few key issues that will need to be addressed. We will need to combine all of our blueprint work in order to pull it off. First of all then, we will need to limit the range from which the user can actually make a change to the material. And so, we will most likely want to use our line trace node here. Given that we have already used a line trace system in the level for our light switch blueprint, though, a new challenge will be learning how to use just that one line trace system in order to test for two different distance values. And of course, we will also need to be able to let the user know that the material assigned to an actor can be changed, with the approach that we will take being based on proximity to the actor. This blueprint clearly has some unique challenges that will need to be overcome then. And so, we will be a fitting conclusion to our look at how blueprint can enhance our visualization levels.
