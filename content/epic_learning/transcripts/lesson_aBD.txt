Time now to go ahead and make use of some of our Boolean variables, getting them to control whether or not our spawned actors cluster together. To do this we will also need to use some of our created float variables as well. To begin then we want to add the cluster around center variable to our graph view, via the get option. Now we need to have our math set up so as to cause the object to scale down to a defined minimum size if the option is checked. But if left unchecked then we want no change whatsoever to take place. Dragging from its output then lets locate and add a select float node, putting a value of 1.8 in the a float control and 1 in the b float. To explain we are going to be using the divide node here to create a distribution far off. If left unchecked it will be dividing the scale by 1, which mathematically will actually cause no change at all. If we do check our Boolean variable option though the position will divide by 1.8 as it moves away from the center of the spawn area, meaning that the majority will be spawned near the center giving us a nice distribution far off. As we will probably want to add some random variation into this, for a more natural look we can drag off the return value output and add a random float in range from stream node that will also allow the seed option to affect it as well. We want it piped into the max input so that we can set the minimum value to 1, again to ensure that we are using our base position when the cluster and far off are not engaged. Let's then add two divide nodes to the graph and piped the return value outputs from our random float nodes into the first slot of the divides. After which we can pipe the cluster flows random float node into the second slot of each. So why have we done this? Well as already mentioned if the cluster option here isn't enabled, a value of 1 will be piped through the maths nodes and so positional distribution won't change. Meaning we will then use the full radius variable amount and so cause zero clustering to happen. Incidentally the same principle will be reused a little later on so as to add scale far off to the meshes as well. Adding the cluster functionality means that our scatter tool can now be utilised in a wider variety of scenes our jobs that would benefit from it. For example we could create the look of stones that have been collected together, we could add boxes to a warehouse or we could even use it to create a cluster of buildings.
