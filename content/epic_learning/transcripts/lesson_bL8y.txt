In this module, we'll learn to set up a metahuman actor in an Unreal Engine level so that it can receive facial performance data from Faceware Studio through the Faceware Live link plugin. For the purposes of this module, I already have Faceware Studio running. Our performer is already calibrated and streaming is activated so that the data is being streamed out of Faceware Studio. Now we'll move over to Unreal Engine in order to receive that data and apply it to a metahuman actor. Here in a brand new level in Unreal Engine, we'll begin by making sure that the Faceware Studio Live Link plugin is installed and enabled. We can do that by going to the Edit menu and choosing Plugins, and then in the Search field, typing in the word Face. Here we find Faceware Live Link, and I have it enabled already. If you have the Faceware Live Link plugin installed and it's not enabled, simply check the enabled box and restart your project and you'll be ready to go. Now that we know that we have the plugin installed and enabled, we can go ahead and configure Live Link to receive data from Faceware Studio. To do this, we go to the Window menu and choose Live Link. Here we'll use the Plus Source button to add a source. We'll choose Faceware Live Link and make sure that the IP address of the source matches that of Faceware Studio. In this case, I'm using the Universal IP address of this machine since Faceware Studio is running on this machine. The port number matches the port number configured in Faceware Studio. The subject name is important if you're going to be using more than one Faceware Studio instance on a single network. For example, if you had two or more performers, all of them using a copy of Faceware Studio on different machines, you can use Subject Name to identify each individual source when configuring different meta-humans. For the purposes of this demo, I'll just name this demo FWSLL for demo Faceware Studio Live Link. Typically, I would use the name of the actor or the character in the subject name. We'll choose OK. And now we see that that source is receiving and we have a green indicator for our selected source. And it has a subject name of demo FWSLL. Additionally, if we go back to Faceware Studio, we'll note that the stream indicator has switched from being amber to being green, indicating that it is not only streaming, but that there is also a client connected. Back here in Unreal Engine, our next step is to configure a blueprint for the facial performance capture to stream the appropriate data for the subject name that we set up in our Live Link configuration. Having already followed Faceware's instructions for copying the Motion Logic FWLL folder into our project, we can find that folder here in the Content Browser. We'll click to open that folder and we'll find the default BP MetaHuman Faceware Live. This blueprint is configured to receive the data from Faceware Studio and apply it to a MetaHuman face. However, the default configuration doesn't have the subject name that we configured in our Live Link plugin. So let's make a copy of this blueprint by selecting it in the Content Browser and using Control W to make a duplicate. In this case, I'll call this duplicate Demo FWSLL. This matches the subject name that we configured in the Live Link plugin. We can now double-click on this to open it up in the blueprint editor. And here we find an evaluate Live Link frame node. We'll need to change the subject name from Animation Values, which is a default, and instead choose our Demo FWSLL subject that we had configured in the Live Link window. With this selected, we can choose Compile, and now we see our sample head responding to the Data Stream. Save and Close. With this blueprint in price, we're ready to set up a MetaHuman that'll use this blueprint for facial performance. We'll go back to the top level of our Content Browser, enter into MetaHuman, and in this case, I'm going to choose my Danielle MetaHuman. Double-click to enter her folder. Again, to preserve the original form of BP Danielle, we'll simply select that blueprint and use Control W to create a duplicate that will customize. This duplicate I'll rename Danielle FWSLL. Double-click to open up this blueprint in the Blueprint Editor. Select the face component for this MetaHuman, and we'll change the Animation class to be the blueprint that we just duplicated and configured to receive data for this demo. So by clicking this dropdown, I'll enter the word Demo into the search, and here I'll find my BP MetaHuman facewear Live Link, Demo FWSLL. Selecting this, now configures this MetaHuman Blueprint to receive the streaming data from facewear studio. We'll choose Compile, and Save and Close. Finally, we're ready to use this MetaHuman. We'll drag her from content into the level Tap F to frame up or fit her into the view. I used my rotation here to turn her into the light, and then my mouse navigation tools to be able to get a good view of her face. Finally, to begin receiving the facial performance data, we'll use the Simulate mode here in the Play menu. And that's it. Our MetaHuman is now executing the performance in response to the data streaming in from facewear studio. Once we're happy with that, we can use the Stop button to exit the Simulate mode.
