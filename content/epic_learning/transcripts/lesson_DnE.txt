With our character Blueprint Actor now created, we're moving on to setting up for a live link streaming. As the first stage of that, we will create an animation Blueprint for the Scalet tool mesh, which will then add to our character Blueprint Actor. To create an animation Blueprint for a Scalet tool mesh, simply right-click on the Scalet tool mesh in the Content browser, go to Create, and select Anim Blueprint. Let's leave the name as it is. Double-click on the animation Blueprint to open it up. Now we'll be using the Anim graph, part of the animation Blueprint, and just to clarify, for the purposes of this course, I'm using a Rococo Smart Suite Pro to demonstrate the workflow, but most, if not all, inertial tools that you can use with the Unreal Engine, will share the same workflow that I'm presenting here. I'm telling you this because I will be using Rococo-specific nodes and I will be using Rococo-specific steps, but the workflow is pretty much the same for every other suit out there. To start off, I'm going to right-click in the empty field in the Anim graph and search for Rococo. I will select the Rococo body pose node, right-click on the Rococo Actor name input, promote it to a variable, then take the animation pose and drag it into the result of the output pose. This will automatically add a component to local conversion nodes to our animation Blueprint. I will click on the Rococo body pose node now and select the bone map override that is provided by default by Rococo. Now what you can see here is that the default bone map override is not visible, this is because my engine content is not visible. So to make it show up, I will go to the View Options and select Show Engine Content. And you can see the default bone map override provided by Rococo show up instantly. I will click on that. This my SkyTool mesh is using the same skeleton that the Rococo tools are streaming into Unreal, I can just use the default bone map override. I will now click on Compile for the Blueprint, select my Rococo Actor name node, and since in the Rococo Studio app, the actor that I want to stream in is the Peter Actor, responding to my name, I will change the Rococo Actor name to Peter. I will now click Compile and Save. Close the Animation Blueprint, open up the Character Blueprint, and now we will assign the Animation Blueprint we just created to the Character Blueprint. So to do this, I will click on my SkyTool mesh within my Character Blueprint, go to the Animation drop-down menu, make sure that the animation node is set to use Animation Blueprint, and in the Enem class option, I will click and select the Animation Blueprint I just created. Now click on Compile, saving what you'll notice is if I drag my Character Blueprint into my level and click on the SkyTool mesh, it will have the Animation Blueprint I created already assigned to it.
