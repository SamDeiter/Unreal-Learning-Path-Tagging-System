This is course 8, where we will capture data from the PV camera and use it in our project. The PV or photo video camera that is located on the visor of the HoloLens can be used for mixed reality capture. It will capture the world in front of us mixed with the holograms around us. This is the camera I have been using to show you my point of view throughout these courses. It can also be used inside of Unreal Engine as a texture that we can use in various ways. In this course, we will modify our project settings to gather the data retrieved from the PV camera to build a texture we can use in our scene as well as in our UI. We're going to use this texture inside of a new material to display the feed from the camera. Let's get started by modifying our project settings to allow Unreal Engine to access this data. Open the project settings and scroll down to HoloLens. Under Capabilities, turn on webcam. Setting this to true will not allow us to preview the feed while simulating inside of Unreal Engine. To see this in action, we need to package it and run it directly on the HoloLens. Let's also quickly create the material we will use to handle this data. Navigate to World Builder, Material, and create a new material named M underscore cam capture. We're going to create a simple material to handle the texture data that we'll receive. For this simple material, we want to set the shading model to Unlit. We'll only be setting an emissive color and don't need anything else. Right-click and search for texture sample. Plug the RGB into emissive color. Then, from text, drag backwards and get a texture object parameter. Rename this parameter to cam capture. We'll need to remember this name for later use as we're going to use it to set the texture of this material in real time. Press apply and save. We'll be setting this data all inside of BP-PON, but any mesh that uses this material will receive the texture updates. In this module, we modified the project settings to request a stream from the PV camera located right above the visor on the HoloLens 2. We created a new Unlit material and added a parameter object to it that we will use to display the feed from our camera.
