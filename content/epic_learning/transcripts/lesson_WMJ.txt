As we will see moving forward, pushing your project to a build is relatively easy. However, there are some universal considerations I'd like to mention that will be relative to virtually any project you deploy. Consideration 1. The Starting Map. When building your project, it will always begin with the Game Default Map. If you are building your project successfully, but start in the wrong level, this is likely your problem. Then the Anubi have stumbled here myself included. To set this straight, simply go to Project Settings, and then Maps and Modes. And make sure the Starting Map is selected to the one you want. Consideration 2. Choosing your target platform. When starting any UE4 project, it is very helpful to have a target platform in mind. The reason for this is simply because all hardware has different capabilities. For example, developing for a high-end gaming PC with an abundance of CPU, RAM, and video performance, you will have far fewer performance requirements than an Android phone. The phone, however, has aspects that can't be replicated on a PC. For example, AR Core for augmented reality capabilities which use phone hardware for orientation and camera data. It is with this understanding that I want to convey the need to build and test on your target platform early and often. Once you have decided on your target platform or platforms, you will want to head over to your project settings. There, you can confirm that your project is in fact set up as desired in the supported platforms tab and in the target hardware tab. Consideration 3. Editor viewing. Depending on your platform, it might be nice to get an emulated viewport in the editor to more closely resemble the target platform. In UE4, you can switch the editor viewport rendering to do just this. If you go to settings, then preview rendering level, then choose the platform you want to emulate. Consideration 4. Granular platform performance control. Especially where multi-platform projects are concerned, it is helpful to know that you can gradually control the output rules for virtually every device. To do this, simply click on Window, Developer Tools, Device Profiles. Depending on the RENCH icon will allow you to set the defaults per platform. The engineers at UE4 have already built a fantastic and rather complete list of generalized defaults, but you may find it necessary to edit these values if you start hitting texture memory issues. Now that those considerations are covered, let's get started.
