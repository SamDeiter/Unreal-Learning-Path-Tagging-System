Besides being able to paint materials onto terrain meshes in Unreal, something else that we can do is paint foliage. We are going to discuss both when and how we might want to manually add foliage to a terrain inside a project. We won't always have the time to do this, of course, and in certain situations hand-pating foliage placement may actually give us a less natural looking, less convincing result than would procedural approaches. In other situations though, it can give us exactly what we need, simply because we can craft the look of our landscape foliage to our exact requirements. To use the full-lead tool, let's click the full-lead button in the panel and then watch the foliage edit mode window appear. From here we can select the drop-down button to add either a foliage type that places Blueprint on native actor instances in the scene or one that uses mesh-instancing. We could also, and if we wanted, make use of the mesh list, which is where static meshes that are able to be used as foliage can be added from. To add a static mesh to the mesh list, we can drag and drop it from the content browser. To adjust the properties of a static mesh, we simply click to select it in the mesh list and then press the small icon in the lower right corner of the foliage controls, which will then show the selected static meshes details. Follage meshes in the mesh list can be enabled or disabled by hovering the mouse over the list and then checking or unchecking the box in the upper left-hand corner. Now we can also select foliage meshes by clicking on them in the mesh list, which will put an orange highlight around them and then in the options panel below, adjust various properties for the selected foliage meshes. Adding mesh files for use as foliage means that we have complete control over not only which actors actually get used, but also over where they will ultimately be used as well. Although this usually takes more time and effort than what using a procedural approach, it does far use in certain situations allows us to carefully craft the look of our landscapes so as to suit the project's needs.
