Even if we are completely new to Unreal, exposing parameters so that we can quickly edit and adjust an actor on a per instance basis is not as difficult a proposition as we may assume. In fact, the work to enable us to do this has already been done. And so, let's see just how easy it is to set this parameter up. With the light actor blueprint open, let's find our set intensity node and notice that we have this green new intensity input. Now the input is green because it requires floating point numbers in order to set the lights intensity. We can quickly set this up by right clicking on the input and choosing the Promote to Variable option. Now we could also have created a float variable manually if we had wanted via the plus icon in the Details tab. Right clicking for me is just a much quicker approach. Let's call our variable something that will trigger our memory should we need to come back to this scene later in time. So there's something like IES, underscore light, underscore intensity. And then I'll also give it a useful tool tip like Controls Light Intentative. Very imaginative I know. But to expose this parameter, let's click the compile button which will now allow us to change its default value as well as expose it. Inside the Details tab, we should see the new default value rollout appear with our float variable set at 0. As this is a light, let's change this to a value of 1000, although you may need to use a different value in your scene depending on current exposure settings. Next, to expose this for ourselves inside the editor, let's come to the Variables rollout of the My Blueprint tab and then click the I icon. This exposes the variable to the editor so that we can easily adjust it even after the actor has been placed into the scene. Finally, we can compile and save. And with that, we are now ready to use our newly completed light actor inside the level and see what advantages it would bring if we were to use it inside a production setting.
