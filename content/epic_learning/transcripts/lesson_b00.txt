When it comes time to adjust and sculpt the terrain in our levels, something that we will need to understand is how we might use the painting tools made available to us. Something that we will make a start on by discussing the visual information feedback that we get inside the viewport when sculpting. To see these, we can click to enter sculpt mode, and make sure that the selected tool is set to sculpt. Now inside the modes tab, we will see a number of rollouts with numeric values inside them. Now these options correspond to the selected tool, which is the case for any tool that we select from the drop-down list that we just saw. As we move the cursor over the landscape, we can see that we have two white circles with the inner reflecting the brush size option. As we adjust, we can see that both circles update, which is because the outer circle actually represents the brush far left, which is relative, as we might expect, to the brush size itself. As we adjust this value, only the outer circle changes. Now the light blue colour that we see is a visual representation of the tool's size and far left options in combination. Now most tools in the drop-down use this same method of viewport representation, although we can take a look at one or two that differ. For example, if we change over to the ramp tool, we see that not only do the options change, but as we move out mouse cursor around a viewport now, we no longer have the same white circles on show, but rather a single crosshair. In fact, this particular tool's gizmo does not appear until we click and drag but more on that later. For now though, let's just switch back to the sculpt tool. Knowing how to use the viewport in order to quickly gauge how our sculpt tool will affect the terrain that we are working on can only help speed up the sculpting workflow no end. And as we use the tools more frequently, this kind of feedback will only become more familiar to us.
