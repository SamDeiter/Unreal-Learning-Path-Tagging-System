The datasmith file is a plain text XML file which contains information about your assets, including the material definitions. To handle materials in an efficient manner, Unreal Engine uses a Revit Master material and material instances. A master material is referred to as the parent material and can be used as a base for many different materials that have similar properties. Material instances all inherit parameters and properties from the parent material. For example, these metal, gravel, and wood materials are all based on the same parent master material, but the metal value and the textures are parameters that can be changed for each instance. If we were to multiply the roughness value on the master material, that change would be passed on to each different instance. Material Instancing is a powerful tool that can be used across all aspects of your project. This can really help to streamline and unify how materials are created and used in your project. If you see any warnings or errors, verify that everything is correctly plugged in as it should be. So what are bump maps and normal maps? Bump maps are grayscale images that simply determine if a given point on the material should be higher or lower. When values are at 50% gray, there is no difference. Nothing looks like it is higher or lower in the texture. Bump maps can be great for adding tiny details to a model like cracks, pores, or wrinkles. Normal maps use RGB values to determine which direction each pixel should be facing in 3D space. In other words, a bump map determines if the surface is higher or lower, but a normal map determines the facing direction of each pixel. Because normal maps use an RGB input, they give a more accurate bump effect for reflections and lighting. Bump maps and normal maps do not add geometry to an object. They simply add detail to an already modeled object. These two static meshes here have the same amount of geometry, but the one on the bottom has a normal map.
