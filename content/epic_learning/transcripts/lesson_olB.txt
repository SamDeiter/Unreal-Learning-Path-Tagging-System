The Mirror Tool, as is the case with the Region Tool, can be very useful in situations where we need to give a more man-made art landscape look to certain areas of our terrain. In this exercise then we will look at how we can put this tool to use when needing to add symmetry to our landscape. Coming to the toolstrap down there, then we have already been working with quite a bit. Let's click to activate the Mirror Tool. Instantly we should see a huge green plane that splits our landscape in half. Now we need to keep in mind that this represents the current Mirror Axis plane and that the red arrow shows the Axis Operation Direction. In other words, the direction in which the terrain will be copied. If we click the Apply button, we can see this in action. And as we change the orientation option, we can also see the Axis plane and Direction Indicator update so as to give us new feedback regarding how the Mirror Operation will now work. Now sometimes when mirroring we can end up with a hash edge along the Mirror Axis. And so to help solve this, we have the smoothing width option. To take a look at the terrain as it runs along the Mirror Axis here, let's first of all press the Control plus Z, our Z keys to undo the mirror that we performed. And then set the smoothing width to the value of 25, which is so high that it will smooth out some of our large terrain. After which, we can click Apply. What we can hopefully see now is that the landscape has indeed been smooted along the Mirror Axis. And although not always needed, it is good to keep the tool in mind for the occasion when we do end up with more noise or hash transitions in our terrain once it is mirrored. If we should at some point offset the Mirror plane via the MirrorPind X and Y settings, and then want to get it back to the centre of the landscape, we can simply hit the Resenter button. And we will start the rest out for us. Now before we continue here, let's make sure that we have removed all of our mirror operations via the Undo command. The Mirror tool then, as its name would suggest, can help save us a lot of time when sculpting a landscape as it can quite literally cut our sculpt time in half. As it is also able to create very interesting shapes in a landscape, it is something that needs well worth spending a bit of time experimenting with.
