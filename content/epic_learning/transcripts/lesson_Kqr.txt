In this module, we'll learn about the Datasmith file type and how to use the Datasmith Attributes modifier in 3ds Max to further optimize our export before we bring our model into Unreal Engine. Datasmith is a unique file format created by Epic Games that is designed to solve many specific challenges faced by developers and artists when using 3D models from various digital content creation platforms. When we use this file format, we can bring entire pre-constructed scenes and complex assemblies into Unreal Engine regardless of size. This file format carries geometry, texture files, materials, lights, animations, and metadata for all of the objects in a scene. This will save us a lot of time when we bring our 3ds Max model into Unreal Engine. Since we installed the Datasmith exporter at the start of this course, we now have access to a new modifier in 3ds Max to assign specific attributes to various 3D models before we export. I could use this to specify which models already have Lightmap UVs that I've manually created. I'll select these objects, the table and these ledges here, then add the modifier, Datasmith Attributes, and under Lightmap UVs, choose specific Lightmap Channel and set it to Map Channel 2. That's why I've stored the Lightmaps that I made here. We could also use this modifier to assign custom collisions, or we could export certain objects as bounding boxes.
