Sometimes, you may import architecture, engineering, or manufacturing data into Unreal Engine, only to find that the geometry is much more dense than you actually need, or it includes geometry that the user will never actually see. In this module, we'll learn about the jacketing feature that can be used to quickly remove objects and unneeded polygons. One way to improve performance in your project is to simply render less objects, especially with complex engineering files, it's not uncommon to have a large amount of 3D models that are contained within a larger object, like an engine or complex mechanical assembly. For objects like these, we may want to consider using a function called jacketing to delete these objects, merge them, or place them on their own layer that we can toggle on and off. When we use this tool, Unreal Engine determines whether objects are visible from the outside of the assembly, and if so, modifies them based on user-defined parameters. Keep in mind that this operation cannot be undone and will affect the static mesh that you have saved in your content browser. So if you plan on using the jacketing function on geometry in your project, consider making a duplicate in your content browser as a backup just in case you change your mind. First, make sure that the polygon editing plugin is enabled. Go to Edit, Plugins, and search for polygon editing. Select the object or group of objects in your viewport that you would like to modify. Right-click and select Jacketing. In this pop-up, we have a few different options. Voxel precision determines the precision of the scan. Gap max diameter determines how large of gaps we should skip over if any are present. We can choose Level or Mesh scan. Level target scan will look to see if objects are inside the external casing and modify those objects that are not seen from any angle outside of the exterior object. You would likely use this for an engine with multiple components, the hull of a vehicle and its interior parts, or a large building that has extraneous geometry located inside. Mesh scan will instead consider occlusion at the level of individual triangles and delete polygons that are not visible from the exterior. This is helpful for individual complex objects that have a large amount of detail on the interior side that we really don't need to render. If we go to Wireframe View Mode, we can see that there's a lot of geometry inside the model that we don't need to render. So for this scenario, I'll choose Mesh scan. I'll keep the other settings at default and continue. When the operation is complete, we can peek inside to see that a ton of interior faces are now deleted. This operation can also be performed using a data prep asset so you can simplify your geometry before it even reaches your content browser and viewport. At the time of this recording, this function is only available on 64-bit Windows machines.
