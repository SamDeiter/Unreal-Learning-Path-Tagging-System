In the previous video, we set up Navigation Mesh that does a good job of defining the traversable space for a human-sized character that moves along the ground. But what if we wanted to add another character that was much larger, or one that could swim, or fly? We could solve this problem by creating new NavMesh agent definitions and configuring each one to define the different dimensions and movement capabilities of the new character. Agent is a generic term, meaning any form of autonomous entity within an environment, and in our case refers to any AI character that we create. We'll take a look at how to create these agent definitions, and how we can use them to support multiple NavMesh's within the same level. We'll begin by selecting the recast NavMesh from the world outliner. We'll find the Generation rollout within a Details panel and note that there are several options here related to the agent. We have Agent Radius, Agent Height, Agent Max Height, Agent Max Loop, and Agent Max Step Height.
