So what exactly is Datasmith? Well, Datasmith is a collection of tools and plugins and helps you basically bring content inside of Unreal Engine. But not just any content. It's designed to bring in heavy content from industries such as architecture, engineering, construction, and the like. Things where you have very complex assemblies and you don't want to piece them out part by part and bring them in and then reset them back up. So Datasmith allows you to bring in those original scenes as they are and use them inside the engine for things like real-time rendering and visualizations. So if we look at this workflow here, you can see the basics. We either have a supported format which comes directly into the engine, creates assets in our browser and then we can put them inside of our level. Or we can use a export plugin inside of 3D Studio Max, export that scene to the support format and then bring it in. So there's currently two things. You have your direct workflow and your indirect workflow. Here's a list and we can see there's quite a few things here. For our examples in this course, we're going to be using a GLTF file which you can see is set for direct. So we're going to be able to bring it in directly and work with it directly. We're also going to be using a 3DS Max scene. Inside of 3DS Max, we're going to take our scene, use the plugin and then export that out to a Datasmith format and bring it inside of Unreal Engine. In terms of plugins, there are a few supported plugins. Right now we have 3DS Studio Max, Sketchup Pro and Autodesk Revit. You can download the supported plugin, install it to the engine, it'll like to export it out into a Datasmith format. Then once we actually have a file in a Datasmith format, how do we use it in the engine? Well, the first thing you're going to want to do is make sure you have the Datasmith plugins enabled. So here's the Datasmith option right here. On our toolbar, if we click on it, it's going to ask us for a Datasmith file. When we bring it in, it's going to import it into our scene. If you don't have this Datasmith option, you want to make sure it's enabled. So you'd go to edit, plugins, and then we want to find the Datasmith section. Now it's going to be other importers. You can see here we have a few options. The two main important plugins that need to be enabled for Datasmith itself is Datasmith Content and Datasmith Import. This is going to allow us to import the actual U Datasmith format. And if you want something else, for example, we're going to be using GLTF, we're going to choose the Datasmith GLTF Import. There are other options as you can see here, such as CAD, FBX, and IFC. And if you have those enabled, when you click on Datasmith, you'll see them as available options here for importing. Once you have this enabled, you can go ahead and start working with either the plugin or a supported format to import directly. Keep in mind, you can do this on any existing project. It doesn't have to be Datasmith enabled or using a Datasmith enabled template. You can simply enable the plugins, restart your project, and you're good to go with importing.
