Having pre-made systems available that can be used to light any project in Unreal is always going to speed up our work, and so it is good news for all of us that Unreal does indeed come with just such a tool. To help us take a look at it, we have for this video created a new project with the Starter Kit enabled, which we have done because it is inside the Starter Kit that we will find a fully dynamic and ready to go sun and sky system complete with a working sky dome. Inside a project that has the Starter content enabled then, if we follow the folders to content, Starter content, Blueprints, we should see a blueprint called BP underscore light studio. Let's click and drag this into our scene, and then after a few seconds we should see it appear in the level. The arrows indicate the direction of the sun, and so if we rotate using the E key, we can see how easily we are able to update its colour as well as the look of the sky dome. Over in the Details tab we have access to its intensity setting, which we can adjust like so. And if we put a check in the Use HGRI slot, we will not only get HDR lighting when baking the solution, but as we rotate, we can see that this again automatically updates the system. If we added our own HGRI file instead, we can rotate, change its brightness and contrast, and indeed set it up to work in whatever manner we need it to separate from the sun system. As we scroll through the parameters for the blueprint, we can see that we have a whole raft of controls available, usually found in different actors' properties, all laid out in an easy to use manner. And on top of this, if we right click on the blueprint and come to the Asset Actions roll-out, we can even migrate this to another project and use it there if we wanted or needed to. Although not all scenes will call for a natural lighting setup such as this offers, having a ready made and fully functional day lighting blueprint at our disposal, can certainly save both time and trouble when lighting certain types of projects.
