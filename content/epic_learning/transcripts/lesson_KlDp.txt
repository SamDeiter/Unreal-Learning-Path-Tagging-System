In this course we're going to be creating collectable item game building off the stack of our project files. We'll be looking into event dispatches, blueprint interfaces, direct reference blueprint communication and blueprint casting to communicate between blueprints and also explore how we can communicate between UMG blueprints through user interface. We'll create a collection component to add to the stack of our character. The course is designed to build on top of either the stack of our character we made in the first course in series or from the BP Unscore bot stack bot from the stack of our marketplace download. In fact the collection system can easily be applied to any character. We're going to use blueprints to create collection and delivery mechanics and build a player HUD using UMG. We'll then set up a game loop with a target score and time limit using event dispatches. Let's take a look at what we'll be building. Our game is going to feature a simple game loop, the start screen of which you can currently see. The game requires the player to pick up orbs and deliver them to the delivery zone. We'll set up variables to limit how many orbs the player can carry, the amount of time they have to collect them and the target number of orbs they have to deliver to win. In this short demo I'll set the carry limit to 3, the target delivery number to 5 and the time limit to 30 seconds. If the player fails to deliver 5 orbs within the 30 second time limit, the player loses. If they deliver 5 within the time limit, the player wins. We'll set up a win and loss screen which will feature retry or exit options.
