While getting the final app up to the Microsoft Store is a great way to get your app distributed, it is not the only way to get it onto devices. Many apps created are for internal use only, and some require many more resources than the HoloLens 2 can provide. In this module, we're going to package a Windows executable and set it up to immediately stream onto the HoloLens. This will be done simply by appending the executable with some command line arguments, and using the holographic remoting app that we have used throughout development. Let's get started by packaging our app in its current form to Windows 64-bit. When it is finished, find the package. Right-click on the executable and create a shortcut. Right-click on the shortcut and open the properties. We need to run the Holo-Remoting app on our HoloLens. Things so will also provide the IP address that we need. At the end of Target, append the text –VR, – HoloLens Remoting, equals, and then the IP address to your HoloLens. When that's finished, press OK. While the Holo-Remoting app is running on our device, open the shortcut. This has begun to run the app using its own resources and streaming it to our device. In this module, we packaged our project to Windows 64-bit and prepared a shortcut that we can use to launch the app and stream it to our HoloLens 2.
