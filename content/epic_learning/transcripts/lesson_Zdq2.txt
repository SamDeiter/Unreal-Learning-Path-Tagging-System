So what is Lumen? At its basic level, Lumen uses multiple ray tracing methods to solve global illumination and reflections. We use screen traces, followed by a more reliable method in both hardware and software. We can use software ray tracing using sign distance fields, or the higher quality using hardware ray tracing when it's supported and enabled. So how is Lumen different from dynamic and static lighting? This and designers are no longer tied to static scenes, with pre-computed lighting baked into the textures. A huge time saving when you can see the results of changes right in the editor, without needing to rebuild lighting or set up light-matte UVs for individual static meshes. This is handled by Lumen implementing efficient software ray tracing, allowing global illumination and reflections to run on a wide range of video cards, while supporting hardware ray tracing for higher end visuals. Now note, when Lumen is used, pre-computed lighting from static lighting is removed. You can disable pre-computed lighting entirely for the project by unchecking the box next to allow static lighting in the project settings. By doing this, it allows us to save some static lighting overhead with shader permutations. It will also allow for material ambient occlusion input and allows material bent normals to work with Lumen global illumination. Best of all, no more light-matte build times. So how does Lumen work? Next we have our surface cache. Lumen generates an automatic parameterization of the nearby scene services called the surface cache. It is then used to quickly look up lighting at ray hit points in the scene. Lumen then captures the material properties for each mesh from multiple angles. These capture positions, called cards, are generated offline for each mesh. Next we have our screen tracing. Lumen features trace rays against the screen first. We call it screen tracing or screen space tracing. We are moving on to a more reliable method if no hit is found or the ray passes behind a surface. Screen tracing supports any geometry type and is useful for covering up mismatches between the Lumen scene and the triangle scene. And then lastly we have the ray tracing itself. We have two methods of ray tracing in Unreal Engine 5. Software and hardware. Software operating on the widest range of hardware and platforms and hardware ray tracing which requires supported video cards and systems to operate. The software ray tracing works against sign distance fields by default. This tracing representation is supported on any hardware supporting shader model 5 and only requires generate mesh distance fields to be enabled in the project settings. Alternately we have hardware ray tracing support. It supports a larger range of geometry types than software ray tracing. In particular it supports tracing against skinned meshes. Hardware ray tracing also scales up better to higher qualities because it intersects against the actual triangles and has the option to evaluate lighting at the ray hit instead of the lower quality surface cache. And it is also the only way to achieve high quality mirror reflections. Lumen is a powerful tool that allows us to make our scenes more realistic and active.
