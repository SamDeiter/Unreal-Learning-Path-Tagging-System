In this module, we'll learn how to create a level where N-A player has to maneuver through a platform, scattered with explosive mines. These explosives first emit smoke to signal an impending detonation before an explosion goes off eliminating the player upon collision. Particularly with Niagara, we're going to implement the visual side of this obstacle, and leave the logic side to the next module when we cover blueprints. We'll start with a blank level, but first we need to borrow some lighting from the hour of code level that comes with the project.
