Before we dive into Unreal Engine, we first need to export a Data Smith file from our 3D modeling program, in this case 3ds Max. Data Smith is a file type created by Epic Games that is designed to solve many specific challenges faced by developers and artists when using 3D models. Here we are in 3ds Max. This model of a house was originally prepared in Autodesk Revit before it was imported into 3ds Max. Here it's been simplified and optimized for us to use in Unreal Engine. As we look around, you can see that there are some lights inside the house, a few basic materials already set up, and a lot of attention has been paid to how the geometry fits together. This is set up this way so we can have a really nice light build demo line. The geometry in this scene already has UV maps created for the materials and the light maps. This will be a great start. Our geometry looks really nice, but we'll want to apply new materials to the geometry as soon as we import this scene into an Unreal Engine project. We may also want to replace all of the furniture with our own models. Of course, we can do this quickly and easily in Unreal Engine for this project because there's not a lot of furniture to worry about here, but if you're working with a model of a huge office or a large facility, an operation like that could take a very long time. Right click in the viewport and choose Unhide All. Next go to File, Export, choose the Data Smith file type, and then go to File, and then Data Smith file type, and a name and location for your file. If you don't have the Unreal Data Smith file type as an export option, you may need to download the Data Smith file exporter plugin for 3ds Max available on the Unreal Engine website. Make sure you're exporting visible objects so that everything is exported, all the geometry, lights, cameras, materials, textures, and metadata. In the file explorer, we can see that we now have a U Data Smith file as well as an assets folder that contains all of the mesh and texture information needed for that file. Remember, this folder and the U Data Smith file should always be located in the same folder. Now that we've exported our Data Smith file from 3ds Max, it's time to open an Unreal Engine file and prepare our Data Prep asset for our import.
