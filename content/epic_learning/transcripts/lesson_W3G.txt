Because we will want the user of our Blueprint tool to have complete control over the size and placement of scattered meshes, we ideally need to introduce float variables to the mix. Simply because floating point numbers can give us finer or more nuanced control over how different aspects of the Blueprint are working. Now to do that, we will once again want to come to the My Blueprint section inside the Advanced Scatter Blueprint. Then click on the Add New Variable button. Now we can name this first control, Scale, Min, and press the Return key, change its Variable Type to Float, and then after hitting Compile, we can set its default value to 0.8 in the Detail section. Now this setting obviously is going to be subject to the scale of our own projects. And so we can later on expose this option to the user so that they can make adjustments should the need arise. A float variable lets us use numbers with a decimal point in them such as 25.2. This, as noted, gives the user much finer control over a tool or parameter than would a simple Boolean R integer value. And whilst such finer control isn't always needed, it will in this case be beneficial. Let's create a second float variable then, giving this one the name Scale Max. And again, after pressing Compile, let's set its default this time to 1.25. Now these will be used to determine the Scatter Actors minimum and maximum scale, and they will be adjustable by the user when placing the tool in the level. And so don't get too hung up on default values here. We're not done with floats just yet, and so let's add another to our blueprint, calling it Radius. And then one final variable giving it the long and yet specific name of Collision Trace Range. After clicking the Compile option, we can set the default value for the Collision Trace Range variable to 50, which will work well with our current scene scale. And then the Radius float value, we can set its default to 200, which should make it large enough to spot in most scenes once it is dragged in. Now just to give a bit of context, the Radius will be what the user can adjust to change the spawn area size. And the Trace Range variable will be used to 80 making sure that we don't spawn objects inside other actors by creating a straight down trace from each spawned actor's location. Now this Range variable will allow us to limit how far the blueprint looks, so as to provide any unwanted errors. Finally, we then want to make each of these options public so that we can edit them whenever they may be needed. And the float variables that we have created here play a massive role in making our tool as flexible and adjustable as possible. Here we see even common variable types can add very important functionality to our blueprints. Now the applications of the float variables can be quite extensive, as our getting used to using them will help us on other advanced blueprints that we might want to create.
