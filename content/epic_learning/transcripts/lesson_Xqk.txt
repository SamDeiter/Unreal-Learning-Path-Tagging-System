Unreal Engine 5 comes with some fantastic new rendering features, including Lumen, the new dynamic global illumination and reflections system. This is a big system in pipeline change, and while we can use it straight out of the box, there are parameters that we may want to alter. They are currently located in two locations. The project settings for global defaults and inside of a post-process volume for local changes. Using our post-process volume, we can override the Lumen global illumination and reflection quality settings. For this module, we will take a look at the default values in the project settings, and then override them using our PPV global that we made in a previous module.
