Welcome to the Blueprints and gameplay and development course, a beginner course for aspiring gameplay designers looking to create content inside of Unreal Engine 4. Before we start, I'd like to introduce myself. My name is Tim van Kahn and I want to help you become a technical gameplay designer like myself. I've worked with Unreal Engine 4 daily since the day it became free. I'm a publisher on the Unreal Engine marketplace and an indie developer working on different titles, the main one being Aaron's Adventure. Over the years, I've worked on a variety of projects, reaching from games or VR experiences all the way to commercials for TV. The awesome thing about this, all of it was done inside Unreal. Just because you're working in a game engine doesn't mean you're always going to working on game experiences. In this course, we will go over a lot of topics inside of Unreal Engine 4. First, we will discuss what the role is of a gameplay designer working in a team. We will change variables at runtime and we will debug our work. We will set up gameplay input for new character actions. We will create our own door, parent blueprint and set up different child blueprints that share some of the functionality with its parents. We will be adding basic sounds and particles and we will utilize the post-process effects to radically change the look of our scenes. You'll learn how to use timelines and you'll get an introduction to UMG. In the first lesson, we will have a look at what is expected of a gameplay designer in a team and more specifically a team working with Unreal Engine 4. Remember that Unreal Academy has the option to change the playback speed of the video, so in case things are going a little bit too fast for you, you can slow it down. But if something sounds familiar, you can also speed it up and I recommend doing this instead of skipping a video. There could always be something there for you to learn that you would otherwise miss.
