Unreal Engine contains many standalone features and mechanics that we can use to create the solutions for our projects. We can use additional tools built to complement these that are readily available and built specifically for mixed reality. In this module, we will download and set up the open-source MRTK or mixed reality toolkit for Unreal Engine. This toolkit is a great set of ready-to-use components that we will use in many of our upcoming courses. What is great about this is that they have been modulately built, so we will only include in the final build what we actually use. This will help keep our final project size nice and small. Let's begin by downloading the MRTK for Unreal Engine. To make sure we all have the most up-to-date version, go to gethub.com slash Microsoft. Search for Unreal in the repository search and open mixed reality UX tools Unreal. On the right, click on the UX tools for Unreal that has the latest tag. For me, it's version 0.11.0. Download the UX tools and UX tools examples zip files. Both of these files are also located in the Epic Games Marketplace, but I want to be certain you are using the same version that I am. Extract both of those zip files to a new folder named Plugins, located in our project folder. Before we open our project backup, open the UX tools folder and then content folder. Earlier, I had mentioned that these tools were built modularly, and we can see that here. We will only need to include the tools that we intend to use. I'm going to keep everything here for now, but know that we will not be using all of them. Alright, open our world builder project. Unreal Engine has noticed that we have a new plugin. Open the project settings and scroll all the way to the bottom. Select UX tools and let us look at a couple of the default settings. Notice that start with hands enabled is on by default. The hands referred to here are for testing our project similarly to the HoloLens emulator. We'll still need to set up our hands for tracking and rendering. Also the hand mesh at the bottom can be changed if you wanted to use a custom skeletal mesh, and below that is the option to change the animation blueprint controlling the skeletal mesh. We're going to keep everything here as default. In this module, we have retrieved the latest version of the mixed reality toolkit and successfully merged it with our world builder project. We saw how it is modulately built and found the location of the default settings. Next, we will prepare our BP pawn to track and render our hands as a possible mesh.
