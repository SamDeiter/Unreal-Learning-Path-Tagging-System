As suggested by the title, we'll be looking at various types of data assets that we can leverage to improve our workflow in C++ as well as Blueprints. Implementing a data-focused workflow allows us to do things like automating our updates and also abstract certain tasks from Unreal, which may better be suited to external programs. In this course, we'll be looking at a wide range of different data assets both native and external to Unreal, and then we'll look at the different ways in which we can utilise these. We'll start by seeing the different types of external files we can work with, how to create them and why they're going to be useful, we'll then take a deeper look into the types of external data assets, the various ways we can create them, and how to import and export them with Unreal. With an understanding of the different types of data we can work with, we'll then get familiar with accessing the information and using it through Blueprints and C++ inside of Unreal. To provide a few different scenarios for us to work with all of these different types of data structures, we'll be working from a template project which includes three different item assets, a radio, a football trophy, and a spaceship, all from the Edith Finch Twin's Room free asset that you can find on the marketplace if you wanted more assets in the same style. These will be purely for visual representation and using these assets a few simple actor classes and a mix of different data assets. We'll see how we can store update and retrieve various details about each of these different items such as their name, description, cost, and even the mesh and icon that should be used to represent each of them. And finally, the target audience is going to be the more intermediate programmer. It's expected that you'll be familiar with navigating the Unreal interface, creating Blueprints and C++ classes, implementing the basic logic in code and understanding the fundamental programming terminologies. By the end of the course, you'll be able to identify opportunities to automate parts of your pipeline with the use of data assets while selecting the ideal data type for the task.
