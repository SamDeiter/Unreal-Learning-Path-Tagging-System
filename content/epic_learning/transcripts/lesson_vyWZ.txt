Hello, I'm Sonali Singh and welcome to the course on creating and modifying control rig. We'll start the course by importing a skeletal mesh FBX in Unreal Engine 5 and then we'll create a custom control rig on it using different rig nodes and Enbuilt debugging tools provided in the control rig asset. Once we have the control rig ready, we'll use it to animate from scratch and modify existing animation using some mocap data. Finally, we'll conclude this course with some new animation tools that you can use to enhance your workflow and take a look at some great use cases of control rig in various production pipelines.
