This scene is almost entirely made using meshes with an amazingly high amount of detail. Not just the big stuff. I'll switch to wireframe to show you. Each decorative element on every building literally all the nuts, bolts, fasteners, the trash on the street and the chain link fence. These are not textures. All of them are geometry. And they are all utilizing Nanite to render very fast while maintaining such high fidelity. How is it able to do this? Let me open a single static mesh. When a rigid mesh is converted into a Nanite mesh by simply setting it to true in the Nanite settings, the Virtualize Geometry system takes over and abides by the parameters set here. At runtime, the Nanite system will spawn a new scene proxy implementation. So any LOD that was added to the original mesh is ignored and Nanite's LOD process is used instead. The city sample map takes into account a good rule for when to use Nanite. If it supports it, use it. That being said, it doesn't work with everything. This includes arc character and crowds, as well as any non-rigid deformations like when a vehicle hits something or any translucent or masked material which there are plenty of those here. Specifically with the vehicles, let's see how this was handled because these are Nanite meshes. I'll run over to this vehicle and the door open so we are able to apply transformational animations to the Nanite mesh. And okay, now when I crash this car, the meshes are indeed deforming. I'll open the menu and set the visibility of Nanite meshes to triangles. Okay, again, we see that the vehicle is utilizing Nanite and when I hit something, the Nanite mesh is being replaced by its non-nanite equivalent, allowing for the deformation of the component to occur. So the solution here was to use Nanite for everything that can use it, but the moment it wasn't needed anymore, or rather the second I crashed this car, the mesh was replaced to a deformable mesh. The last note about Nanite I want to touch on is the view distance. As I look around this smaller but still large city, all the meshes in the distance are rendering in the same quality as if they were all right near the camera. This allows us to experiment with visible distance in our products that we weren't able to do so previously at this quality.
