Let's start with importing the skeletal mesh FPX of the character and see what are the different import options that we need to keep in mind. For this course, you can go ahead and create a blank project to follow along with me. I've already created a project with no starter content in it. In the content browser, I've made a character folder where I'll import my character FPX. Now to import an FPX, you can either right-click on the content browser and select import to game characters option or you can just drag and drop your FPX file onto the content browser here. Now game refers to the content folder and character is the folder that I've created here. Once you choose your FPX, our window pops up with all the import settings, let's quickly go through the important options here. Under mesh, we leave the skeleton blank because we want to import mannequin along with its own joint setup. Next, there is skeletal mesh which indicates if the imported FPX has bones or not. So if we turn this option off, then the engine will assume it to be a static mesh without any bones. Make sure to keep this box checked. Then the import mesh is self-explanatory, so we'll keep this option on as we want to import the character mesh. For import content type, we have geometry and skin weights. So we'll leave it to default as we want to import both the geometry plus the skin weights from the FPX skeletal mesh. Let's move on to the advanced options which has a few more important options that we need to consider. Rest we can leave it to default values. First one is create physique asset. This will create a separate asset to define physics for your character. So let's keep it checked. Then there is use t0 as reference pose. Unreal's default mannequin uses an a pose or relax pose as the base pose. So if your custom character is in t pose, make sure to toggle this option on to use your defined pose as the base pose for the character skeleton. Otherwise if you toggle this off, UE4 will force this character to the engine default pose which is the a pose as the base pose. And that will create problems. I prefer to keep this on as a best practice. Next is import morph targets. If your character uses morphs or blend shapes for facial animation or some corrective poses, then make sure to keep this on. Otherwise all those blend shapes won't get imported. Then we have normal import method. Use this based on how you want your mesh normals to be calculated. Since we are just importing the character skeletal mesh, we'll leave animation as unchecked. But transform and material settings will leave it as default. If you want more details on all the options under import settings, then I would highly encourage you to check the official documentation. Now that we have all the settings as required, I'll go ahead and hit import all. This will take some time depending on the PC you have and how dense the polygon count is for your character. Once we have the mannequin imported, let's double click and open the skeletal mesh editor to check if the character is imported as intended. As you can see, the base pose is perfect and not modified or broken in any way while importing. Next under the skeleton tree tab on the left, we have the skeleton hierarchy similar to how it was set up in the DCC application with a single parent joint called root and there are no unnecessary joints or empty groups. Switching over to the asset details tab, we can check all the details like materials, LOD settings etc here. I'll look for import settings in the search bar and you'll see all the import settings similar to what we saw in the FPX import window here. In case you missed any option while importing, for example you forgot to import your morphs or maybe you want to import this skeletal mesh with a different transform, then you can always come back here, make the required changes and then click on the option, Reimport Base Mesh. This will reimport the base mesh with the updated settings. Now that we have the character imported in the project, it's time to finally start creating a custom control required.
