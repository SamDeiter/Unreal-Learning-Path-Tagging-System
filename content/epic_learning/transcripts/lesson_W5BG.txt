Before we begin, let's answer the question, what is Faceware? Faceware is a set of tools designed to help users capture the subtlety of an actor's facial performance and translate it onto a digital character in order to give us high quality facial animations. Traditionally, to animate a face without such tools, animators would be required to keyframe every expression in key poses, then adjust the transitions for the entirety of the timeline. This produces great looking animations, but can be very tedious and time consuming. While creating key poses remains an important part of Faceware's workflow, they only need to be created once during the initial setup. For every frame, retargeter will evaluate the current expression, identify the poses that best match, and apply them onto our character. This provides us with accurate transitions between expressions. It's worth mentioning that there are other methods that may seem quicker, like audio-generated facial animations or real-time facial solvers. However, they do not offer the precision or flexibility found in Faceware Analyzer and Retargeter. Faceware Analyzer is a standalone software that allows us to track an actor's facial landmarks. While an auto-track option exists to quickly get started, we have the ability to manually adjust them in order to get the most accurate tracking data from our footage. Faceware Retargeter is a plugin available from Maya, Motion Builder, and 3D Studio Max that allows the tracked data to be applied onto any character's facial rig. The goal is to pair an actor's expressions to our character's custom poses. When done correctly, retargeter will handle the rest. The Studio Plus versions support batch processing capabilities, allowing teams to generate hundreds if not thousands of lines of dialogue for a larger project. With this, we can set up a semi-automated pipeline to process a large volume of performances, obtain high-quality animations, and get each shot to the Polish phase in roughly 70% of the time that it would take to do it manually.
