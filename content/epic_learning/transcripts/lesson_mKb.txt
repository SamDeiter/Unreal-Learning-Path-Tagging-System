With our list of meshes already in place from the previous exercise, we are ready to put them to good use. And so in this video we will be taking a look at how we can paint them onto our landscape so as to handcraft the look and placement of our foliage. To make a start though, we first of all need to make sure that we are inside the foliage tab of the Mode section. We're down the left hand side, we have a number of ways open to us in which we can paint and then edit what we have painted in terms of foliage meshes. Firstly then, we can paint with a brush tool that works very much like our texture painting in that we can set the brush size. And then add foliage to the terrain with a simple left click and drag like so. The paint density option will let us paint with as many actors as a setup in the mesh properties. This ranging from zero, where we won't use any, up to a value of one, which will use 100% of the density option found inside the mesh properties. With the Erase Density feature, again using the mesh properties, but this time in order to determine how many of the mesh instances will be removed, should the user start to erase them. We can use the Select tool to move or change individual instances of the foliage found on the terrain, which is fantastic should one or two of the mesh actors need to be tweaked in order to stop them spiling the overall look and feel of the foliage. We can also Lasso select if we wish to edit more than a single instance. Or we can use the paint bucket to fill an entire landscape with a selected mesh should we need to take a much quicker approach. Inside the painting tab, we can set the density for our mesh painting which of course relates to the paint density option that we just used. We also have, if we scroll down, access to the placement parameters for our currently selected mesh, meaning we can add an offset if we want, which can be useful for making sure that our foliage doesn't appear to be floating in any way. And we can also, if we want to tell our painted meshes to align either to the terrain's existing normals, are maintained their original orientation, which we may want to do for say something like trees that are being added. We can even, from the options available, add a greater variety of foliage meshes if we want, so as to make our terrain look even more believable.
