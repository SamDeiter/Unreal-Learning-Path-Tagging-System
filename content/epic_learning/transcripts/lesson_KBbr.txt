One way to add interest in realism to a scene's lighting will be to use industry standard IES profiles in our projects. IES profiles oftentimes being provided by lighting and fixture manufacturers themselves and so can usually be found in abundance by means of a simple web search. The files contain data that basically outline the intensity and distribution pattern for a real world-like fixture that Unreal can both read and reproduce. Although the intensity setting can be overridden if we like in other two account for artistic rather than physically accurate reproduction. To take a look, let's first of all in our world outline select all our spot lights and then scroll down to the light profile's rollout. Now I already have two IES profiles, one for the spot lights and one for the ceiling lights and so let's click and drag on the spotlight IES file and then drop it into the IES text slot. Right away we can see the difference that this is making and if we go ahead and bake the lighting. We can really see the changes that this brings to the lights distribution pattern. Now if we want to use the illumination intensity setting as found in the file rather than having control ourselves we can put a check in the use IES intensity option or if we want the best of both worlds we can adjust the IES intensity scale value which lets us dial the intensity both up and down using the profiles built in intensity setting as a base our starting point. In this instance what we are getting now is way too bright for my tastes but this could indicate that our exposure settings are currently a little off, something that we will look at fixing later. For now though let's just turn that particular option off. If we take a look at the spotlight on our stairs now because we increased the intensity value we can really see the IES file at work and so let's select all of our point lights and do the same again only this time adding the down light underscore IES profile. Finally let's re bake the lighting one last time. Clearly then if we want to add extra quality to our lighting setup it may well be worth searching for and then downloading some IES profiles that can then be attached to the lights that we are using inside our visualization project.
