The Real Engine 5 offers a very robust fracturing system that is part of the Chaos Destruction tools. This fracture tool allows you to create cinematic quality fractures that will run with real-time performance. Let's go ahead and pop into the editor and take a look at this tool. To access the tool, we come up to our selection mode and then down to fracture. With a mesh selected in the scene, we can then generate a new fracture, create a location for it to save. Then fracture our object using the tools provided. Using the Explode amount, we can see what our fracture is going to end up looking like. We have various different tools that allow us to do things like create clusters, glue objects together so that they will break apart when a certain damage threshold has been met, as well as change the materials and effects that are utilized in the various stages of our fracture simulation. You can utilize the fracture tools again to fracture just a single object or we can further fracture objects so that as the individual pieces break, they become more refined while creating this really amazing life-like content while still maintaining that real-time interactive frame rate.
