We have been looking so far in our course at Blueprints that can be used at runtime inside of Visualization, but Blueprints can also be used in the construction of the Visualization level itself. Our goal in this chapter then is to create a blueprint that helps make the placement of lights inside a building a little easier for the level designer to accomplish. Now this of course means that we will need to use a construction script as we will want it to run as and when we are placing the actor in the level. Now what we will need to know for this tool then is firstly the actor's current location when first placed in the level, and then somehow we will need to measure upwards from the actor in order to see if there is a ceiling on which the light needs to be placed. One way we can do this, being via the line trace that we have already worked with, seeing is it can clearly gather and store lots of useful information. We will also want a way to somewhat limit the effect as we won't want our lights just snapping to any and all surfaces that are above them as this could get annoying, building in some kind of maximum distance setting then will be essential. A variable our limiter to the line trace potentially working just fine here. Finally we will also need to be able to update the actor's location and move it to wherever the line trace hits, if it is within the distance limit that is. We will need to know that can access the actor's transform settings and then override them if required. With the clear view of our goals in mind then let's dive in and make a start at creating our blueprint.
