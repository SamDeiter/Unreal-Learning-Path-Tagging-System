Because we will stream this data over our network to the computer, we need to enable a few new capabilities in the HoloLens settings. Open project settings and scroll down to HoloLens. Under capabilities, enable Internet Client, Internet Client Server, and Private Network Client Server. For us to connect to our desktop, we need to create a custom launch profile so we can add some command line arguments to the package. Open the project launcher. At the bottom, create a new custom launch profile. Starting under build, open the advanced settings and enable build UAT. In the additional command line parameters, add dash trace host equals, and then the IP address of the desktop. Make sure it matches the same subnet as your HoloLens. For example, if your HoloLens IP address was 192.168 etc. Enter the IP of your desktop that matches that. Okay, add a space and type dash trace equals. After the equals, you can add the types of data you want to profile. I'll add all of the ones we can currently receive from our device. Just add a comma between them. So log, bookmark, frame, CPU, GPU, load time, file, net. Keep in mind that more of these that you add, the larger the trace file will be. Next is cook. Set it to buy the book and scroll down in the cooked platform window and select HoloLens and select the map to cook. Under package, set it to package and store locally. Browse for a location to save the package to. And finally set deploy to do not deploy. Return to the project launcher and launch the profile. When it finishes packaging, upload the app to the HoloLens from Windows Device Portal. In the apps menu, find the .app expandal file and select install. Close Unreal Engine and open Unreal Insights. It is located in the install directory of your version of Unreal Engine. It's in the binaries win64 folder and search for unrealinsights.exe. If asked by your firewall, be sure to give permission to access the network. Now that the app is finished loading to the HoloLens, I'll open it. Make sure that Unreal Insights is running before you open the app. It has contacted my desktop and Unreal Insights has begun to profile the project. Double click the trace session to see it.
