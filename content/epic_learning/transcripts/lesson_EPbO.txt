Nanite is Unreal Engine 5's new virtualized geometry system. What Nanite does is it allows you to have very, very high resolution 3D meshes, and when you import those in to Unreal and enable Nanite, Nanite will take that very, very high resolution model, convert it to an internal format that not only is very compressed, but also automatically applies a level of detail system to it that makes switching between the various levels of detail in this Nanite object completely seamless. Now, let's jump into Unreal and see when we enable Nanite for use in our projects. First, we need to enable Nanite by going to Edit, Project Settings, we're going to click on All Settings and we're going to search for Nanite. We can see here under our Rendering Settings, we will have Nanite enabled. Once Nanite has been enabled, you can actually mix and match Nanite objects and static mesh objects. To enable any mesh to become a Nanite mesh, we simply need to right-click on it. Then the static mesh editor will see here Nanite and then we enable Nanite. Or we can disable. We can also do this by Shift, selecting a bunch of assets, right-clicking, Nanite, and enabling Nanite, as well as opening up each individual asset and enabling it from the static mesh settings. In order to test to see if Nanite is working correctly on your project, you can do this by coming up to our Lit Mode, coming down to our Nanite visualization and clicking on Overview. Once we've done this, we will see the various render views showing us the different stages that Nanite is taking in order to render the content we're seeing on screen. The Overview Mode is a fantastic way to make sure that Nanite is enabled on your projects or to help you debug, especially when you're utilizing Nanite with other static meshes. With any new Unreal Engine by product, Nanite will be enabled by default, as it is considered production-ready. It should be the preferred format, especially when dealing with very, very high resolution or high density static meshes.
