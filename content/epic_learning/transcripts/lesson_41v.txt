Hello, my name is Matthew Wadstein and welcome to the course on Pixel Streaming Interactive. So what is Pixel Streaming? Well, in a traditional environment, we have our Unreal Engine project. Using Pixel Streaming, we can take that project, send it out to our Pixel Streaming servers, using a connection, maybe locally or remotely, like over the internet, we can send it out to multiple clients. Now the advantage of this is because everything is running on our servers, the clients don't have to be very strong. It could be something like a tablet, or a mobile device, or someone else's computer. As long as it's running an HTML web browser, we have the ability to send data to it. And the nice thing is, it also provides two-way communication between that project and then the clients. So we can add some interactivity to our project.
