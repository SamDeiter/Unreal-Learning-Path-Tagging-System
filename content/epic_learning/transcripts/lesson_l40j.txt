In this video we'll take a quick look at everything we've created during the course and highlight the areas where we have improved upon the base Paper2D features. We will review our changes to AI controllers, interfaces and how we used all of these features together to build a more advanced level for the project. Let's quickly summarize everything we've achieved throughout this course. We began by modifying the existing player character camera system to be more dynamic. We achieved this by using the character's velocity to impart directional movement into the camera. We then moved on to the most significant and complex of our improvements, AI behavior and ranged attacks. We created a new projectile actor that implemented the damage system when overlapping with the player, and could figure the AI to play the correct attack animation and spawn the projectile. We then moved on to adding systems to allow the enemy to determine when and how to attack the player, beginning with a simple detection system powered by an additional collision volume. We then expanded this detection to drive the concept of an alert state within the AI and use this to adjust their movement speed and facing direction. We then moved on to the decision making process when it came to attacking the player, dealing with common edge cases and simple responses in order to successfully attack the player. With that out of the way, we added a health system to the player, allowing attacks a decrease to health rather than innocently destroying them. We built this on top of the existing damage system. Next, we moved on to adding new environmental actors that would leverage the work we'd already done with the damage and health system. We created a new health pickup actor using the interface system to restore player health in a generic and flexible manner. We then added an environmental hazard that built upon the earlier work on a damage system. This removes health and also gives the impression of repelling the player character. Finally, we brought it all together by improving the basic starter level we had been using throughout the project. We began by improving the lighting within the scene with better placement and values of existing light assets, as well as adding new elements such as directional lights and post-processing volumes. To complement our lighting changes, we built a more representative tile map using more elements from the included tile set to create something larger and more interesting. In this video, we summarized how each module came together to create a dramatically enhanced paper-duty based platforming game.
