Although we have now created a blank canvas for ourselves, as it were, and so have a terrain that is ready to be sculpted into whatever we need for our visualization, let's just take a bit of time to discuss some of the options that we now have available for editing our terrain. In fact, it may well occur towards at this point that we actually need some extra terrain adding into the mix here so that we can make use of it in a certain camera view. Well, maybe the opposite is true and we need it taking away for a particular camera shot. Because of these possibilities, let's take a look now at how we can add, delete, and even change the polygon count of our landscapes as we go. To do that, let's click to enter Manage Mode, make sure that the selection tool is active, and then click a component to select it. To deselect a component, all we need to do is click again. Now, we can also click to select multiple components if we like. We can also click and drag to select more than one component at a time. And click and drag in order to deselect multiple components. Let's just drop down the tool list, and select Delete, and then click to component on our terrain. We can also change the tool to add, and hover the cursor next to an existing component edge in order to get a green preview of the new component and the location in which it will be added. All we need to do is simply click to create the new component. Now, we can go a step further, and with a component selected, we can switch the tool over to the Move Level option, which if we were streaming levels in a project, would mean that we can choose when they get streamed in and out during runtime in order to once again help with performance. Now, as well as the simple commands, we also have the ability to make changes to the overall size and resolution of our terrain should we have the need to after it is already being created. Let's set the tool to Change Component Size, and set the Resize Mode to Resample, which means that the current landscape will change to the new settings as if we created it with them. So this as opposed to our new settings either being additive or subtractive to current will mean that our current landscape is resampled rather than it expanding or contracting. A handy thing to know. If we make a change to the amount of quad detail being used then, and click Apply, we can see in the preview that the texture changes in order to reflect the updating detail. Now, we can also view this in Y-Frame to see the polygon changes, if that just helps us visualise it a little bit better. Let's set the section size option back to 63x63 quads, and the viewport back to the lit viewing mode. Being able to manipulate and customise the base terrain, even after its creation, just means that should it become apparent that adjustments to its shape are density and needed before carrying on, then we can do so without having to delete our existing landscape and start hollow for again.
