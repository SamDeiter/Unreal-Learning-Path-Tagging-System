What we want to do now is make a start at building the visual aspect of our scatter tool. In other words, what will the user see that gives them feedback inside the level? Now this is something that will be very important when it comes time for other users to use it as well. To make a start from inside the Viewport section of our Advanced scatter blueprint, let's come to the Components area, click the Add Component button, and then after scrolling to the Rendering section, click to add a billboard to our blueprint. Now inside the hierarchy section, we can then left-click and drag, so as to drop the newly created billboard onto the default scene root in order to replace it. To expand on why we are doing this, it's simply because it makes it a little easier to see where our tool is once it has been placed inside a level. Though you can simply leave the default root in place if you prefer, or set up another method of location once the tool is placed inside our scene. Next, with the billboard selected in the list so that it is made into the parent, we can add another component, and this time choose the box collision option. We can give it the descriptive name of Radius, Visualisation or something similar, and make sure that it is a child of the billboard component. Now we don't need to worry about the size of the component at this moment in time, as this is actually going to be defined by the user later on, and driven by the variable type that we created a few videos ago. Taking the time to think of how people, and yourself might interact with the tool on a day-to-day basis during a project, can help us add functionality that, well, just makes the job easier.
