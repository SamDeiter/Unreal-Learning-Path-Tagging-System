Whilst knowing a little bit about Blueprints is good, we are of course still left with the question of how we actually go about creating and using the graphs and nodes that we have talked about. Well, not to worry, as we will take a look at answering that question right now. Inside the Content Browser then, let's make sure we are inside the Level BP folder, and then double-click on the first person character Blueprint that we see. Navigation here is pretty simple, as we can move around the graph via a right-click and drag, and we can use the scroll wheel on our mouse to push in and out of the view. Whilst moving around the graph view is important, however, it isn't much used to us in and of itself if we don't know how to create the nodes that we need. And so, making sure that we are inside the Event Graph, we can simply right-click in some empty space, and then type a word into the search field so as to locate any of the nodes that are available. Let's search for the word branch here, and then click to add a branch node to the graph. Searching for nodes by name though is something that we will only be able to do properly once we become familiar with the nodes found in Unreal. And so, after right-clicking on the graph, we can also manually expand the roll-outs and see what nodes we have available. Once created, dragging from a node's output will oftentimes allow us to make an automatic connection to any subsequent nodes that we add to the flow. Indeed, if we drag off a node's output, we can note that by default Unreal will only search for what it thinks are compatible nodes to the one we are dragging from via the context-sensitive checkbox. Let's just add a flip-flop node here, and talk about some of the features found on the nodes themselves. The white triangles, then, are known as execution ports that allow the logic flow to continue onto the next node in the chain, should the current node finish the job that it has been asked to do. If we right-click on a port that already has a connection, we can also break a link. Although it's good to know that we can also hold down the alt key and click to perform the same operation. We can delete the nodes themselves via a simple click and then a press of the delete key. If we want to organize our graph a little more carefully, then we can click and drag on a node, which will allow us to move it around the graph area. Let's just make sure that we have deleted any nodes that we have created in this exercise before moving on. Looking how to perform these types of simple operations inside a blueprint will be essential as we move through the course. Although we will get lots of practice in, and so don't feel bad if you have to go through the course a little slower than you would like the first time around. Just view this as time that is needed in order for you to become accustomed to working inside a blueprint graph.
