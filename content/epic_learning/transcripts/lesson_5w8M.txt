In this module, we'll be adding a health pickup we can place into our level, or create a new actor, and then use Unreal Engine's interface system to update the player's health value in a generic and flexible way. When we implement our Healing Object, we want to implement it in the most flexible and generic way possible. That way, it'll be easy to apply the same effect to other actors within the world if we wanted to. For example, maybe later we could decide to let our enemies using the Healing Objects as well. To do this properly then, we'll create an interface and then implement that interface on our player character. Navigate to Content 2D Sidescrawler BP Blueprints in the Content Browser. Right-click in an empty space within the browser, and Indy Create Advanced Assets section of the menu, locate Blueprints Blueprint Interface. Name this new interface I Healable. We use the prefix I to remind us that this is an interface Blueprint. Double-click on the new asset to open it. In my Blueprint panel, on the right-hand side, create a new function called Heal. Moving to the Details panel below, add a float input called Amount. Compile and save the Blueprint. Note that this graph is marked as Read Only and is grayed out. That is because we don't implement the logic here. We just define what is expected of this interface. This will make more sense as we go ahead and actually implement the interface with our Healing Object, so let's start doing that now. Close the window and return to the main Editor window. Open my Duty Player Character from the Content Browser. From the Blueprint Editor toolbar, select Class Settings. In the Details panel on the right-hand side, within the Interfaces rollout, select the Add Rollout in the Implemented Interface section. Locate I Healable. With that selected, note that I Healable is now shown in the Implemented Interfaces rollout. Moving over to the My Blueprint panel on the left-hand side, we can see there's a new Interfaces rollout. Expand the rollout, and here we can see the Interface function we defined earlier, Heal. Right-click on the Heal function and select Implement Event. This automatically creates the required custom event within the Event Graph and moves us over to take a look at it. This is the event that will be called when the Player Character collides with the Health Collectible we'll be putting together soon. We'll be using this event to set a new value for the Player Health. So locate the current HP variable within the Damage rollout, and alt-left-click drag it into the Graph. Connect the Execution Pin from the Event Heal into the Set node for the current HP. Let's start by adding the Healing Amount to the Player Character's current HP value. Drag from the Amount Output of the Event Heal and locate the Float Plus Float node. Drag a reference to the current HP variable into the Graph and connect it to the lower input of the Float Plus Float node. We just need to do one more quick samples you check before setting our new current HP value. We need to make sure that we don't go over the maximum defined Health value. Drag from the Output of the Float Plus Float node and locate the Min Float node. Drag a reference to the Max HP variable and connect it to the lower input of the Min Float node. It's a good idea to reposition the nodes as we go to keep everything in order. The return value from the Min Float node will return whichever value is lower, which in this case will either be full health via the Max HP variable or a lower value. It is not possible to return a value above the maximum HP, which is exactly what we want. Connect the Return node from the Min Float node into the Input of the Set node for the current HP. That's all the setup we need to do for the Player Character, so we can compile, save and close the window to return to the main Editor window. Now it's time to create the Healing Actor itself. Right-click in an empty space in the Content Browser and select Blueprint class from the Create Basic Asset section of the menu. Select Actor from the Common Classes section at the top of the dialog box. Name this new Blueprint Actor Heal Collectible and open it in a Blueprint Editor. Let's start with the collision volume we'll use to generate the overlap events for collection by the player. In the Components tab, select Add Component and locate Box Collision. The default name of Box is descriptive enough so we can leave that. Drag the Box Component over the default Scene Root in the hierarchy to make the collision the Root object. Now we'll add the Visual Representation of the Heal object. Hit the Add Component button and locate Paperflip Book. Once again, the default name of Paperflip Book is descriptive enough so we can leave that. With the Paperflip Book component still selected, move over to the Details panel on the right hand side and locate the Sprite Role out. Select the drop-down next to Source Flip Book and locate Flip Book underscore Health Orb. Adjust the Viewport to the right view angle and select the Unlit View Mode so that we can check our collision box is the right size. Zooming in, we can see at the moment it's much too big. So select the Box Collision again, either from the Viewport or from the hierarchy. Move over to the Details panel on the right hand side and adjust the Box Extent to 10, 10, 10 in X, Y and Z. We can see that's much better. Now all we need to add to this actor is a variable to store the amount of healing this particular object will give when delivered. In the My Blueprint panel, add a new float variable and call it Heal Amount. Compile the Blueprint so that we can set a default value. Set the default Heal Amount to 10. Now let's move over to the Event Graph to implement the Healing Logic. Delete all the existing nodes apart from Actor Begin Overlapped. The only check we need to make here is to see if whatever we overlapped with, implement the I Healable Interface we set up. Drag from the other Actor Output of the Event and locate Does Implement Interface. From the Interface dropdown, select I Healable. Next, create a branch and connect it to the Output of the Does Implement Interface function into the Condition Input. Before we forget, connect the Execution Pin between the Actor Begin Overlapped Event and the Branch itself. If the Other Actor does implement this Interface, we want to send the Heal message, so drag from the Other Actor Output and locate Heal message. Place a few re-root nodes along this Execution Wire to prevent the wires from going behind the Branch node. Connect the Heal node to the True Execution Pin of the Branch. Now we need to do is specify the amount of Healing. Drag from the Amount Input of the Heal message and locate Get Heal Amount to use our existing variable. That handles the actual Healing process. Now we just need to remove the Healing Object itself to show that it's been collected. Drag from the Execution Pin of the Heal node and locate Destroy Actor. Note that the target is set to Self, meaning that the Heal collectible itself will be destroyed. With that, we're done with the Collectible Object, so let's compile, save and close the Blueprint Editor window. Let's quickly test our new functionality by printing the Player Health to the screen whenever it's changed. Open My 2D Player Character and locate Event Any Damage. Move along the Execution Path to the right until we see Process not back. Drag out from the Process not back Execution Pin and locate Print string. Get a reference to Current HP and connect it to the string input of the node. Note that when we do this, Unreal Engine automatically adds a node to convert from a float to a string. Moving on, locate the Event Heal. Drag from the Set node for Current HP and locate Print string. Seeing as it's right there, drag directly from the return of the Set node and connect it to the In string input. With that, we're done, so we can compile, save and return to the main Editor window. Now, let's place a Heal collectible in the level and position it on the raised platform on the left hand side. Move the Player Start over to the right so that the player will start near the enemy character. Start a new Playing Editor session and allow the enemy character to damage the player. Notice how, in the top left corner, we can see a decreasing value, which is the player's health. Notice if we jump up and run over the Heal collectible, the Health value increases. And with that, we're all done. We can stop the Playing Editor session and return to the main Editor window. In this module, we added a Health collectible that restore health to the Player character when it is collected. We started by creating a new Interface to manage the Healing process. We then implemented this Interface onto the Player character, adding a new Event to the Event graph to adjust the Health variables we set up in the previous video. We moved on to create the Pickup Actor itself, adding a Collision of Volume and a Paperflip Book Animation for the asset. We then added Logic to the Actor to send the Heal message to any Actor implementing the Heal Interface upon overlap and then destroyed the Actor. Finally, we added some Debug Text to monitor the state of the Player's Health and observe the results in a Play Editor session.
