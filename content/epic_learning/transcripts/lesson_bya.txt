Time now to start building the positional data of our scatter tool, and we can make a start by telling the system where on the Z axis we want it to spawn our mesh actors. Good to remember at this point then, that this will be based on the mesh objects pivot point, and so bad pivot placement here will have our tool looking as if it doesn't work properly. As a first move then we will want the random seed variable to be dragged out and placed inside the graph. Indeed, we will make use of this multiple times that the user can randomize the results whilst keeping a similar effect if they feel the results just are not quite working for them. Let's pipe the output of this variable into the stream input of the random float in range nodes that we have set up. In fact, let's drag out from the random seed variables and add yet another random float in range from stream node. This will be the Z axis placement for our static meshes, and so ideally we would probably want to expose both the min and max variables for greater control of flexibility. But, as I know we are going to be scattering plant meshes in this example, I will add a min value of minus 15, and for the max something around minus 4 will do. Just to give you the reasoning behind this, this will not only ensure that the plant stems are actually sitting in the ground, but also add some height variation at the same time. If we were using this tool to distribute say rocks or houses, or indeed anything else, we would probably want to create a new Z axis float variable and then expose that for finer control. To finish up this particular effect, let's drag the output from our topmost divide node, and then search for and add a make vector node. Byping the other divide node into its Y input, and then our Z axis offset into the Z input. What we have done here is give our blueprint the ability to select random points within the spawn area, and also cluster towards its center should the user desire it. The vector that we have created will also be used to detect collisions, and so stop us spawning inside other static mesh actors. We can set up our tools so that it can correctly place static mesh actors in the appropriate Z axis positions.
