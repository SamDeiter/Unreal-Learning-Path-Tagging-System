A tool that can help us localize our work and so it would be more specific or targeted in our terrain edit would be the region tool, which helps us make sure that our edits affect only a very specific area of the landscape. While also ensuring that unselected parts, so maybe those that are already as we would like them do not change. Let's take a look at how we use this tool then. Making sure that we are inside the landscape and tool sections of our modes tab, let's drop down the tools list and then choose the selection option from the list. If we click and drag on our terrain now, we can see that the current options make it so that we cannot actually edit this area. And so if we select the scope tool and then try to edit the landscape, we have no effect. If however we paint towards the far left of the mask, we can see that our brush starts to have a limited effect. Switching back to the selection tool, this is controlled via the brush far left settings which is very useful for controlling any hash transitions that the mask might be causing. We can also invert any mask that we have created by clicking the negative mask checkbox in order to turn it off. Now we can paint a selection mask for areas we want to affect. Or maybe it is that we want to simply remove just a portion of our selection or refine what we already have. This can easily be done by holding down the shift key and then clicking and dragging to remove from the selection. Now if we find that we had done with our edits or have made a mistake in the selection that we have made and so want to start again, we can simply click the clear region selection button in order to reset the tool. Now the region tool is definitely a powerful option at our disposal as it can help preserve areas of the terrain maybe around our building or a complex whilst edits are going on. As well as help out when we are trying to create a more landscape look to a terrain as we can cleanly mask off areas that we can then affect or not affect as we see fit.
