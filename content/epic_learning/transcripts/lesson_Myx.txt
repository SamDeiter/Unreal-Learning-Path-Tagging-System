Our target hardware and our PC is ready to go. Now we need to make sure our engine is installed and ready for HoloLens 2 development. In this module, we will make sure that the latest version of Unreal Engine is installed and ready to package HoloLens projects to experience on the emulator or the HoloLens 2. For the entirety of this learning path, we will be using Unreal Engine 4.26 for its new features, allowing us to create an experience that take advantage of mechanics such as gaze, hand tracking, spatial mapping, spatial audio, local and Azure spatial anchors, and voice input without installing any additional libraries or plugins. Each of these standalone features have a full course dedicated to them in this learning path. So let's get started by getting our tools ready. Let's begin on Unreal Engine.com and click download. Choose the licensing option that works best for you and select download now. You'll then need to either create an account with the Epic Games or log in with your already made account. After logging in, the download should start. This is to install the Epic Games launcher which we will use to launch Unreal Engine. I already have the launcher installed, so I'm just going to open it up. Your version will look much the same. Move to the library tab and at the top under engine versions, press the plus to add a new version of Unreal Engine to your library. Make sure it is version 4.26. If there are additional numbers following the 0.26, that's fine. Those are just indicating updates made to 4.26. Before we click install, select the drop down and choose options. Inside of the installation options, we need to make sure that we have all the tools necessary to develop for the HoloLens 2. Scroll down to target platforms and check HoloLens 2 and press apply. Now press install or update and let that finish. In this module, we made sure we had the version of our engine installed and set up to develop for HoloLens 2. In the next module, we'll open Unreal Engine 4.26 and create the blank project that we will use in our learning path.
