Let's recap what we learned about the data prep asset in this course. In this course, we learned that a data prep asset is a unique file type in Unreal Engine that we can use to modify, optimize, and manipulate incoming data from a data smith file. We learned about the data prep assets user interface and how to integrate it into a data smith workflow. We replaced materials on import, and we filtered by metadata to replace chair objects with our own content. When used in a data smith import workflow, the data prep asset can save us a ton of time, allowing us to focus our time and energy on making our 3D environment as awesome as possible. Take your time and set up as many helpful actions as you need before executing your data prep recipe graph. If you've created a highly customized data prep recipe graph that works great for your workflow, you can even migrate that asset into another project. Thanks for joining me for the course using data prep. For more information, please refer to the Unreal Engine documentation or additional courses on this platform.
