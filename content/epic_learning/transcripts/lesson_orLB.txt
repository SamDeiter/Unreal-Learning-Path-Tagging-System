Welcome to Developing for the HoloLens 2 in Unreal Engine. My name is Kevin Lyall. I'm excited to introduce this new learning path to you designed by Microsoft and the Unreal Engine Online Learning Team. We are going to prepare you for developing engaging and interactive experiences inside of Unreal Engine 4. This learning path contains 11 courses each built to cover best practices in various areas of development. This is a project-based learning path with each course providing a new step from starting blank project to final submission. Much of the non- HoloLens assets we will be using have already been built. These are things like the meshes, animations, materials, several blueprints, anything that does not relate directly to our HoloLens work, but they are ready to be incorporated into our project. While we will not cover how all these assets were built, if the course demands further explanation of how an asset works, we will cover it. If it relates directly to the HoloLens 2, such as the player pond or our hand blueprints, for example, we will be building them from scratch. We'll begin course 1 by collecting and setting up everything we need to get started developing for HoloLens 2 in Unreal Engine. In course 2, we will first retrieve the assets that we will be working with throughout the rest of the learning path. Then we will focus on our gaze to communicate and interact with our scenes using only our eyes. Course 3 will introduce hand rendering and interaction to further immerse ourselves into the augmented world. In course 4, we will be combining what we have learned so far by creating and utilizing a user interface to assist our new friends with building their world. That'll make more sense later on. Course 5 and 6 are all about audio. First, we will learn about the differences of spatial and traditional stereo audio. Then we will control our projects using voice commands. In course 7, it is time to merge our two worlds by scanning our environment, allowing the augmented scene to interact with our world. Course 8 is all about using the photo video or PV camera. When our project is ready, we will move into course 9 to use various tools and principles for project optimization, where, in course 10, we will prepare our final project for HoloLens app submission. Lastly, in course 11, we will be creating a multi-user experience with Azure spatial anchors. By the end of this learning path, you will have the training needed to confidently create a custom HoloLens 2 project from start to finish using Unreal Engine. There is lots to get through. So let's get started.
