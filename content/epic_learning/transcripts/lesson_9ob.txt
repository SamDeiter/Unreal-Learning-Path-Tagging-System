Hello and welcome to the Dynamic Audio Course. I'll be doing a talking in these videos, but the course has been put together by myself from my colleague Dave Raybold. You can follow Dave on Twitter at the new Tide. We've been working in Unreal Engine for quite a while now, and have written two books on Unreal Engine Audio, the now infamous Game Audio tutorial, and a more recent Game Audio implementation. We also write papers and book chapters on Game Audio and teach the sound and music for interactive games masters at Leeds Beckett University. We keep an up-to-date list of useful books and reading around the subject at our website, Game Audio Implementation. This course is all about how audio can dynamically react to game events, conditions and variables. You'll need to be familiar with an audio editor in order to produce assets to bring into the game, and you should have some basic familiarity with the engine, so take a look at these other short courses. We're going to be dealing with a bit more complexity in these courses, so we're going to assume that you're familiar with everything that we covered in Course 1, ambient and procedural sound design. If you've not already done that course, then we suggest you go and do it now. It really is the most excellent course, and will probably transform your life in the most radical and unexpected ways. Throughout the course, we'll be building up the audio in a demonstration project. You'll be able to download the final version, and we'll be including an empty version with no audio at all, so you can populate it with your own audio and audio systems, trying out the techniques yourself as we go along. In the course, you'll be learning how to dynamically change your audio in response to game variables. We'll start with some simple dialogue that changes according to true false conditions, using Boolean variables. Then we'll extend this by using integer or whole number variables, so that we can count how many times something has happened and change the audio accordingly. You'll be learning about float variables, and we'll be looking at some really useful techniques where we can map these to control the volume of audio, the volume of different simultaneous layers of audio, and the frequency with which audio events might happen. Objects that move in the game need sound to be synchronized to them. You'll learn how to use the sequence editor, both to add sounds to, and to create events that you can use to control more sophisticated audio systems. Other things that drive audio are animations. We'll look at how to synchronize sounds with animation, and how to add sounds for footsteps that vary according to the different surface types in your game level. The course will finish off with three videos that look at driving audio from particle systems and from physics systems. As you can see in this course, everything gets a lot more interactive and a lot more dynamic. So let's proceed.
