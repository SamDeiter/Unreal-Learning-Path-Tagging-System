In order to get an iOS device working with UE4, there are some procedures you will need to follow in order to deploy to and test on an iOS device. This video is here to help with that task, but should not be viewed as a tutorial per se. I will not be going through all the details step by step. There are just too many forks in the road depending on what you are building. Instead, I will be doing a brief review of the steps required. There are plenty of resources online reiterating much of this content which will cater to more specific problems and needs. Also, please note this series covers only blueprint-based workflows on PC. If you are planning to deploy a C++ project, you will need to build it through Xcode on a Mac and is not covered in this tutorial. Lastly, this procedure requires a developer.appl.com account. If you do not have one, please create one before continuing. If you are on a PC and do not have access to a Mac, then you will need to download the binaries for Open SSL in order to create your keys and build your provisioning profile. The website wiki.openssl.org has links to the latest Windows binaries. Once installed and running, you will need to create your RSA key with the following command. And generate the signing request with this one. Remember to replace the email address with your Apple developer email, the CN with your name, and C with your country. Once done correctly, you will have a signing certificate sitting in your Open SSL bin directory. If you are using a Mac or have access to one, you can ignore that procedure as you will be using keychain access to do the very same task quite soon. Now we can log into developer.appl.com. Our first order of business will be to create our certificate. Under certificate, select to add a certificate. In the following window, choose iOS app development. The next page is for Apple users. Here it explains how to use the keychain to generate your signing certificate request. Follow the instructions on this page to do so. PC users can just click continue as we have already created the certificate using Open SSL. Now we can upload our signing certificate and complete the certification. In the resulting window, download and install the CER file. Mac users will use this with keychain and PC users should save this to their Open SSL bin directory. Now that we have our certification, we need to create an app ID. Under app IDs, hit the add button to create your ID. In the resulting window, choose to make an explicit app ID using the reverse com format like com.mybusinessname.mygame. This will be important later, so be sure to remember whatever you set it up as. Select whatever options fit your application best and create your ID. Once done, we can jump back to Open SSL and create our PEM file by using this command. Being sure to change myAppleSertificate.CER to whatever your .CER file is named. Next, let's make the P12 file by running this command. In our Open SSL bin directory, you should now have two files called past.P12 and past.PEM. If so, you're good to go to the next step. Now we're at the last stage. And this is to add our device and create a provisioning profile. To do this, simply register your iDevice on developer.apple.com on the Devices page. Then create a provisioning profile linking the device to the app ID to the certificate. Finally, you will download the mobile provisioning profile. Let's make sure our P12 file, our .mobile provision file, and our .CER file are all somewhere easily accessible but safe. I generally store them on the root directory of my cDrive, but you can find any location that you know you can find easily. Once you have these files, you are ready to proceed and start making games for iOS with UE4.
