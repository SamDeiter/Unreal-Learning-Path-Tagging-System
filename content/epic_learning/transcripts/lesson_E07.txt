In this video we created a new hunger blackboard key and manipulated it directly from the behaviour tree using a service. We learned that a service is a self-contained blueprint script that will run at a fixed interval for as long as the branch it is part of is executed. The service we created increases the value of the hunger blackboard key up to a maximum value of one representing maximum hunger. We then use this hunger blackboard key with a blackboard decorator to control execution flow. The decorator will stop execution of the branch that makes our AI search for food until the hunger value is sufficiently high. This configuration demonstrates the power of behaviour trees when used in conjunction with decorators. With just a few small changes we can completely change the behaviour of our AI.
