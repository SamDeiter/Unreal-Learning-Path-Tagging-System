Although we have the base components in place for our easy to use light actor, we still need to get those parts communicating with the engine so that we can easily adjust the settings whenever we place the actor in a level. How can we do this? Well, the approach that we will take in this instance is that of creating a construction script for the actor. So that we can edit our light from inside the engine itself, let's double click to enter our light blueprint if we are not there already. And then make sure that we are looking at the default construction script via a double click if needed. The first thing that we need here is a reference to the point light that we added to the actor. And so inside the components tab, let's left click and drag our point light onto the graph. Giving us a reference to the light so that any changes we make to the intensity variable that we will create in just a moment will be local to just this particular instance. Now should we want to make global changes to all instances of an actor, then we can of course do that as well as we will see a little later on. For now though, let's drag from the point lights output, search for the word intensity and then click to select the set intensity option, which automatically sets our point light to be the target. We still need to execute this part of the blueprint though. And so let's left click and drag on the execute output of our construction script and pipe it into the input execution port of our set intensity node. With the construction script set up, we now have the ability to expose the intensity parameter so that as we construct our level and add this light actor, we can quickly and easily access its controls should we need to make adjustments to it on a per instance basis.
