Unwrapping UVs for textures and light maps can be a very time-consuming task. In most 3D modeling programs, various tools are available to customize, unwrap, and pack UVs to be perfect for textures and light maps, but sometimes it can be easier to just auto-generate UVs in Unreal Engine. In this module, we'll learn about how to generate UVs in Unreal Engine and when it may or may not make sense to do so. We primarily use UVs for two purposes, displaying textures in materials and light maps for big lighting. Auto-generated light map UVs require an existing UV map to use as a source. If your existing UV is broken up and isn't laid out properly, your auto-generated repack will also have its own issues. Also, auto-generated light map UVs are normalized from 0 to 1 on the UV grid. In other words, if your source UV has faces that are stretched or scaled beyond the size of the grid, those faces will be brought back down to the size of the grid. We can auto-generate light map UVs when we first import our geometry. In the import options, simply make sure that the Generate Lightmap UVs option is enabled. After the light map has been generated, you can view it by opening the mesh in the Content Browser and selecting the UV icon at the top of the screen and select UV1. UV0 by default is the first UV channel that was created to inform how textures would display on this mesh, so UV1 is for the light map. Typically, you will get your best, most highly detailed UV maps from manually creating these in a 3D modeling program. However, we don't always have that luxury, especially when working with complex CAD data that doesn't have UV maps. When that's the case, we can use the Unwrap UV tool or the Generate UV tool. Let's use the Unwrap UV tool first. If we go up to the UV icon, we can see that this model actually doesn't have any UVs at all. UV0 is actually blank. Select Unwrap UVs in the drop down. Here we can specify a UV channel to use for our destination into the angle threshold by which we want to allow the tool to rotate groups of faces. I'll keep the angle at default and specify channel 0 since my current UV0 is blank. We now see that we have a nice UV that we can use for this model. For more complicated geometry or for times that we may want a more particular kind of UV map, we can use the Generate UV tool. We go up to UV and select that tool now. This will project the 3D geometry of the object into the UV grid using a projection volume of a specific size and shape. When we use Generate UVs, each face is projected onto the faces of the projection volume, then that shape is Unwrap onto the grid. If that sounds confusing, it'll make more sense when you see it in practice. When this tool is enabled, you can see the outline of the projection shape around the object in the Static Mesh Editor viewport. We can move, rotate, and scale the volume as we need to. Selecting Fit will move the volume to fit the shape of the object as easily as possible. We can also change the type of projection from box to cylindrical or planar. Choose the option that best fits the projection that you need for your object, and then when you're all set, hit Apply. You can now see the newly created UV map in the preview window. Again, you will typically get the best results for UV maps by manually creating these in your initial 3D modeling program. To simplify this process, you can even generate unwrapped UVs in the recipe graph of the data prep asset that we created in a previous module.
