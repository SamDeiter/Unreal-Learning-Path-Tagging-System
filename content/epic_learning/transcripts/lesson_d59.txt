Welcome to the Using Enumerations course. My name is Kevin Mile. I'm a technical artist and graphic designer and I've been working professionally in the visualization industry since 2012. In this course, I'll be sharing some of the techniques and workflows I use in every project I work on inside of Unreal Engine. This is a beginner's course for blueprint developers written for users that are ready to learn how to create modular and programmatically built actors and UI. We're going to walk through what an enumeration or enum asset is at the most basic level and how it can be used to assist with the design, development and maintenance of your projects. We'll discuss how to create one actor blueprint with many functionalities that can all change based on the value of an enum. In addition, we will use another enum to activate those functionalities in diverse ways. Lastly, we'll add our enum to a UMG widget to programmatically build a drop-down menu of options for us to choose from and then activate specific versions of our blueprint actors remotely. Feel free to use your own project or use the provided one to follow along. While we won't be building anything from scratch, I will be walking us through how the blueprints were built and the techniques learned here can be used in all your Unreal Engine projects. In the final two modules of this course, we will use an architectural visualization project to show how enums can be created for assisting and adding interactivity to an otherwise still seen. In the next module, we'll begin by learning what an enumeration is, we'll create one, and learn how to use them in blueprints.
