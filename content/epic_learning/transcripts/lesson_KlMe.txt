Using the recipe graph, we can create functionality in our Data Prep asset to automatically replace materials that are imported into our project. Let's do that now. Let's open the Data Prep asset again. We'll set up a simple recipe to automatically replace the glass on the windows with the nice looking glass material from the starter content pack. If you haven't already, import your data Smith file again. First, we'll need to make a selection to determine which objects should have their material replaced. We could filter these windows out by layer, tag, or metadata values if they all had uniquely identifying strings that we could use. Fortunately, because this model was originally created in Autodesk Revit, we automatically have access to several metadata keys and values. You can find the metadata for any object by selecting it, then at the very bottom of the details panel, look under Data Smith User Data. I'll just filter these windows by name because they're all called system panel glazed. So I'll use this object name filter. Recipe functions are performed from top to bottom and left to right. Once we've filtered for anything containing the word panel, we want to perform a substitute material. Drag that under the filter so it occurs after the selection has been made. I'll indicate that for any of these panels with the material containing the word glass, we want to now use the starter content glass called M underscore glass. This operation can save us a lot of time, especially if we're working with a huge building covered with windows. We could also use this functionality to replace materials with our own metals, gypsum wall materials, creeds, landscape materials, and so on. We could take this a step further too. We could use a substitute material by table node to replace materials based on a data table. Under none, choose data table, then create a material substitution data table. Here we can add several material substitutions to perform at the same time. For each entry that you create, you would simply need to designate the string to filter by and the material you would like to use instead. For now though, I'll just replace the glass panels with what I had previously set up. When you're ready, hit execute to use the recipe that we created. We can now see the new glass material on all of the windows. When we hit commit, this change will be propagated to all of the meshes in the editor viewport.
