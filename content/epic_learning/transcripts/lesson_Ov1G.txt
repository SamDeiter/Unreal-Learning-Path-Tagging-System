Hello, my name is Sam Anderson and today I will be taking you through the Unreal Engine Hillside Sample project. This project showcases the unbuilt design of the Habitat 67 community in Montreal, Canada, designed by Moshe Softy. This project is provided by Epic Games and was a collaboration with both Softy Architects and NeoScape. The Hillside Sample project utilizes Unreal Engine 5 features, such as Lumine, Nanite, and Path Tracer, to provide high quality graphics at a large scale. Within the project are some additional features that can be beneficial to artists of all kinds. We will be covering some of those throughout the modules in this course, as well as the basics for how to use the project. The architectural design visualized in the Hillside Sample project is known by Mini for its vision for future living and pre-fabricated construction. The layout of the units provided each unit with desirable amenities for urban projects, including gardens, and access to sun and air for each unit. With this Sample project, we have the ability to view the project design as it was intended to be built, as well as the portion of the project that was built for the World Expo in 1967. This unpacked video will cover the entirety of the unbuilt design. If you'd like to learn more about the built project, named Habitat 67, go down to our additional resources at the bottom of this page where you'll be able to see the reality capture workflows. The content we covered today will be beneficial to artists as it represents a real example of large assets thoughtfully and efficiently constructed to provide a compelling experience, whether it is through an executable or cinematics. With this Sample project, we want to share the workflows and tools created to produce the Hillside Cinematics with all creators. You can find the project sample in the marketplace through the Epic Games Launcher. On the project's marketplace page, you will find more information about the project including supported Unreal Engine versions. After completing this course, viewers will be familiar with the project and be able to apply some of the amazing tools to their own projects. Users with basic Unreal Engine knowledge will gain insight into project organization, our direction workflows for lighting, and learn how to use assets in the sample projects such as materials and blueprints. Let's get started.
