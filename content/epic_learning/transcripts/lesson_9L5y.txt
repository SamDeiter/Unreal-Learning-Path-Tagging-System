Now that we understand how to use the Data Prep Recipe to customize our import, let's take it a step further by adding some more functionality. Let's add a recipe action that uses metadata values to replace some furniture. Back in the Data Prep graph, we first need to filter by metadata value. Add this selection to the right of the Material Replacement Action. Inside the house, we have some blockies stand in furniture that needs to be replaced. Let's replace these two lounge chairs in the front of the house with the chair asset found in the Strider Content Pack. When we select one of these chairs and scroll down in the details to the Data Smith user data, we can see the different metadata values we could choose from. For these two chairs and any other identical chairs in the project, the value for type metadata is lounge chair. So in our node, the value should be lounge chair and the key is type. Next, add a set mesh node under that one. We'll use SM underscore chair from the Strider Content. When we hit execute, we can see that the chairs are now properly replaced. Keep in mind that if the pivot point for the replacement mesh is located in a different relative location or with a different transform, your new mesh may be offset or rotated incorrectly. To make the positioning more believable, you could even add a random offset transform node after the set mesh. Let's choose rotation, keep it relative, and rotate from negative 5 to positive 5 degrees. Again, if you're working in a huge 3D file, like perhaps a school or office building, this operation alone could save you a ton of time. At this point, we could also add additional recipe actions to save even more time. I always like to filter by Mullians and merge those, or filter specific furniture assets and add them to their own layer. Now that we've explored some more complex functionality in the Data Prep recipe, you may be able to think of some ways to adapt your Data Prep asset to improve the import workflow for your project. Don't forget that you can always re-import your Data Smith file as your project changes over time.
