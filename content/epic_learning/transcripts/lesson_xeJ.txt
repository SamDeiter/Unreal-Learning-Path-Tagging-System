Some project settings in Unreal Engine are more expensive than others and may lead to less performance if they are enabled when they don't need to be used. At the start of your project and as you develop your scene, you may want to pay special attention to what features you have enabled and disabled. To access the project settings in a project file, go to Edit, Project Settings. First, let's look at the Target Hardware section under the Project section. We can set whether our application will be primarily used on desktop or console or mobile or tablet devices. We can also determine the overall level of quality, whether it should be at maximum or at a lower scalable setting. If I switch this to mobile, we can see that some project settings will automatically be modified. Most of these are post process settings. Some post process effects are not supported by default on mobile devices or are less stable, so those are disabled to improve performance. I'll keep this set to desktop. Now go to the General Settings section under Engine. Under Frame Rate, we can set a fixed frame rate if we know we don't need to run at an extremely high frame rate. You can also enable a smooth frame rate range to help hide stuttering if you can't avoid frame rate issues in the editor. Finally, scroll down to the Rendering section. In a Calling section, make sure that Occlusion Calling is enabled. This setting determines whether objects will be hidden or if they are visible to the camera. This is enabled by default to help reduce the amount of mesh draw calls we need per frame. Scrolling down, you could lower the resolution of reflection captures to save on GPU draw time. Be sure to keep this as a power of two value for best results. Under Default Settings, you can modify the post process effects that are used in your project, but keep in mind that these are overridden by settings that you have in a post processing volume or a camera actor. Keep in mind that real time ray tracing is an extremely expensive feature and is not currently supported for mobile or VR applications. If you don't really need real time ray tracing for realistic reflections, global illumination and so on, consider disabling that for your project. Take your time and familiarize yourself with the various settings that are available in the project settings. You can always find more information about any specific setting in the documentation.
