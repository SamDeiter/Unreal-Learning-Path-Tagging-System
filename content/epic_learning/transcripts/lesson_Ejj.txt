In Unreal Engine, we add materials to 3D objects to define their look and to inform how they react to light and reflections. Let's create a couple of materials to apply to the geometry that we've imported into the project. Unreal Engine renders materials using physically-based rendering, a type of shading that seeks to approximate how light actually, realistically, reacts to surfaces. The parameters that we will usually use to determine how an object reacts to light using a PBR shading are base color, roughness, metallic, specular, and normal. We can always create material information for 3D models in other programs like 3DS Max, but we will ultimately have more control and will be able to achieve a more realistic result if we create our materials in Unreal Engine.
