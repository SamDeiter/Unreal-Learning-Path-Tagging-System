Now that we have looked at the tools we can use to sculpt and edit our terrains, time to look at what we have available for painting terrain materials. Now these tools allow to transform a plain grey shape into something that resembles a textured landscape. As is the case with any of the tools that we use in Unreal, creating a believable landscape material isn't something that we can cover adequately in just a handful of videos. But what we can do here is make sure that we understand what tools we have available and grasp the basics of how they work. We're going to start first of all with understanding how the materials are constructed for use in layers. Inside the content browser then, let's come to the Materials folder where we have a number of material folders already set up as well as a master material. Just as an FYI, these materials have already been created here so that a final version of the project could be provided. Don't worry though, as we will break down not only what is being created, but also look at why. To begin then, let's double click to enter the Grass folder where, as you would expect, we have a number of bitmaps that can be used to define what our Grass material will look like. What might not be so obvious though is that we have actually created a material function here rather than a standard material. The question you will want, Andrewnd, of course, is why have we done that? Well, simply put, creating a material function actually gives us the ability to call or reference the function inside another material. Meaning, we can keep our main landscape material clutter free by simply referencing in the material function, which we will see how we do in just a moment or two. First though, let's take a look at how we go about creating material function in the first place. After right clicking in some empty space in the content browser then, we can come to the Materials and Textures section, where we will see the Material function entry in the list. So, this is how we create a new function, but instead though, we can simply open up the M function underscore Grass option that has already been created. Inside our material, we can see that the Texture sample nodes are already placed. Now, if you wanted to place your own textures here, you can simply drag and drop the texture from the content browser. Instead of using the standard TextCoord node to tell the textures how to map and tile, we have instead added a landscape quartz node that works by using the scale of our actual terrain. This is then piped into a Make Material attribute node that can be created via a right click, which means that all of the information for this particular material can be condensed into a single output and then piped into the function output node. If we close this particular function then, and instead open up the landscape material, which is just a standard Unreal material, we can see how it is that we are using these functions. First, we are adding a Material function call node that lets us select any material function already created, and as we have created rocks and grass, this gives us two with which to work. And, as we click on each call node, we can see their respective functions become selected inside the Details tab, so one has grass, the other has rocks. These are then added to a layer blend node that the terrain painting tools can read. We have added two elements via the plus icon, given them their respective names and then piped the functions into them. As it stands to make this easy to work with, we have condensed all of the parameters into a single output, which for use with an Unreal standard material, well we will need to have access to again. And so because of this, we run the blend node into a break material attribute node that then lets us pipe the outputs into a standard material, thus ensuring that we have clean and easy to edit materials. Having all these nodes and textures sitting in one place of course, can also save us time and headaches further down the pipeline should any changes need to be made.
