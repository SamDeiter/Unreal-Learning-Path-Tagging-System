A Data Prep Asset is a type of file that we can create in Unreal Engine that can be used to modify how a Data Smith file is imported. In this module, we'll create our Data Prep Asset and learn about the interface. In the Epic Games Launcher, I'll create a new project using 4.25. I'm using the AEC template and leave it blank and enable Strader Content for this project. We'll use some assets from this content pack later on in this project. In the Content Browser, I'll start by making a folder by right-clicking and choosing New folder, and I'll call this Data Smith. Inside this folder, I'll create a Data Prep Asset by right-clicking and under Data Prep, choose Data Prep Asset. If this option isn't available, you may need to enable the Data Prep Editor plugin by going to Edit, Plugins, and Enabling the plugin called Data Prep Editor. Double-click the new Data Prep Asset to open it. In this window, we have several helpful panels that we'll use as we prepare our Data Smith file. In the middle along the bottom of the screen, this is our Data Prep Recipe Graph. This graph is pretty similar to other node-based graphs that we use in Unreal Engine. We can create nodes and actions by either dragging a selection from the panel on the left, or right-clicking and choosing whatever we need. This top-left panel will show all of our incoming data found in the Data Smith file, or files, that we are importing. The panel to the right of the viewport indicates what the hierarchy will look like after being imported. This panel on the very top right allows us to assign input Data Smith files to use, as well as output destinations. Select the plus icon in the top right of this panel, choose a file, and navigate to the Data Smith file that we previously exported. Note that we could actually add additional Data Smith files as well. When you're all set, select Import in the top left of this window. In the next module, we'll import the Data Smith file and review some of the graph functions available in the Data Prep asset.
