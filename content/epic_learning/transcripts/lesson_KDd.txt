Making the construction of a real-time visualization, as easy as possible to do, is always going to be something that we strive for, with one way in which we can help do this being the use of construction scripts in our blueprints, that allows us to set up important blueprint information when our actor is created, rather than having to do it manually after the fact. To start utilizing the construction script for our automatic door, we will want to make sure that our automatic door blueprint is open, and then also make sure that we are viewing the construction script graph. If it is not available as a tab, we can double-click on its name inside the functions rollout of the My Blueprint tab so as to open it up. What we are wanting to do now is set up information that is unique to this actor, specifically the position of the left and right doors in relation to the frame mesh, and where, ultimately, the blueprint actor gets placed in the level. Rather than set this up manually each and every time we place our actor in the scene, though, we can simply use the construction script, as each blueprint class has just a single construction script that executes on creation, which is why it makes sense to set up our door starting locations when we create the blueprint, as we can then use this information later on. To have our construction script function properly, we will need to store the door starting location, which we will do via variables. To create one in the variable section of the My Blueprint tab, let's click the Add Variable button, give this a descriptive name, so door R, underscore stat, and then press Enter. Now, variables can hold lots of different types of information, from full references to actors in a scene, to arrays are, in our case, float values. We need to use float values here because the nodes that we will want to work with later will need a float input in order to both tell the blueprint where the doors are currently placed, and where they need to be moved to. Having just a single door's position, is obviously only half of the job, and so we need to store the same far the other door as well.
