Change the quality from maximum quality to scalable 3D or 2D and keep ray tracing disabled. Change the target platform to Mobile slash Tablet and we want no starter content. Select a location on your computer to save the project to. I've selected a location on my drive that is quickly accessible. Once you've also selected this location, we need a name for the project. When you're ready, select Create Project. When the project is built and open, let's set up some initial parameters and enable the correct plugins for the engine to use. To enable plugins, click on Settings in the top toolbar and open the plugins window. In the Augmented Reality tab on the left, enable HoloLens. When HoloLens is checked, Unreal Engine will indicate that it should be restarted. Let's modify a few more things before we restart. In the Virtual Reality category, enable Microsoft Windows Mixed Reality. Go ahead and close the plugins window and open the project settings. I just want to point out that we're going to set some parameters here, but I won't explain them until we need them. For example, scroll down to the Rendering tab and enable Forward Shading. We will be taking advantage of Forward Rendering for the lower Rendering cost despite having fewer features. We will discuss Rendering and performance later in the learning path. Okay, now we can restart. After Unreal Engine reopens, I want to prepare our simple starting map to stream directly to the device. Inside the editor, there are some assets that we don't need as we won't be using them. Select the SkySphere and delete it. Also, delete the atmospheric fog. What we are left with is the player starting position and a platform to stand on. Our very basic map is ready. Inside the Content Browser, create a new folder named World Builder. All of our custom assets we make will live in this folder. Inside of World Builder, create another folder named Maps. Press Save All in the Content Browser and we'll need to save the level as. I'm going to name this map Main and press Save. Return to your project settings and open the Description category. Enable Start in VR. Now go to the Maps and Modes category.
