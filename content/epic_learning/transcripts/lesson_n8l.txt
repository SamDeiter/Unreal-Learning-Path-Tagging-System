Hello and welcome to this training course. I'm Chris Wilson, an independent video game developer and in this series we will be talking about the Paper 2D plugin for Unreal Engine. We will start by giving an overview of what the Paper 2D plugin does, what kind of projects it's suitable for and how it works alongside existing Unreal Engine tools. Next, we'll move on to creating our very own project and importing the sample assets correctly. By the time we're finished, we'll be able to create a playable 2D character, builds an environment for them to move around in and create a 2D game from a number of different perspectives. Before we get started, it is important to state that this course assumes that you are somewhat familiar with a blueprint visual scripting system. If that is not the case, I would recommend taking Wes Bunn's Blueprints Essential Concepts course before attempting this one. In this video, we covered the purpose and structure of the course and what we should expect from our finished project upon completion.
