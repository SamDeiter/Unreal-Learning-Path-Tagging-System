Before beginning this course, we'll now review the hardware, software, and skills you should have beforehand. Hardware. A Magic Leap 1 device and controller is encouraged, but not required. As nearly every part of this course can be completed inside of Magic Leap's remote simulator, save for image tracking, which is only supported on Magic Leap's custom build of Unreal Engine, and as of yet not on any official release from Epic. On a similar note, while this isn't quite hardware, for image tracking you will need an image. It can be a digital image if you like, displayed perhaps on a tablet or a phone, or you can print the image. The image used in this course is included in the exercise files. If you'll be going through this course using the Magic Leap 1 device, I also recommend the Magic Leap Hub. It's a device that will allow you to leave your Magic Leap plugged into your computer and active without draining its battery. Software. Using Unreal Engine 4.22.3 installed with the Lumen and Android platforms, as well as Magic Leap's 0.19.0 SDK installed through its package manager. How to do that will be covered in the course. We will utilize Datasmith to bring an architecture model from Revit into Unreal Engine. If you do not have access to Revit 2019 or newer to open the file, the Datasmith files we will export are provided in the exercise files. While no experience developing for Magic Leap or any other XR devices required for this course, a few assumptions will be made. First of all, you should have a Magic Leap account already set up on their website. Next, you should understand the basics of developing for Unreal Engine, including how to set up a project, navigating the editor, importing files, as well as creating basic materials and blueprints. If you need a primer on using Unreal Engine, the PDF included in the exercise files will provide you some recommended courses to review before starting this one. Lastly, if you're using a Magic Leap 1 device, please ensure that you've already set it up to be a creator-enabled device. Once again, the PDF includes everything you'll need to set that up on your own. We've now reviewed the prerequisites for this course.
