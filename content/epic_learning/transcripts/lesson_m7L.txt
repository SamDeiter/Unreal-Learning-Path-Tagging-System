A UV map is a file that communicates how a 2D image is wrapped around a 3D object. In this module, we'll learn how to create UV maps in 3ds Max, as well as how to create them in unrelention after the model has been imported. So what exactly is a UV map? A UV is a 2D representation of a 3D object in a 0 to 1 grid. The letters UV and W correlate to x, y, and z for a given 3D object. Typically, a UV map is created in a 3D modeling program when the 3D geometry is created. Primarily, we use these to determine how materials and unrelention are applied to an object. Therefore, if we don't have proper UV maps, or we haven't taken care to optimize the scale, position, or rotation of the maps, we may have issues with how materials are applied when we are in unrelention. Any 3D model can have multiple UV maps. The first UV map channel is typically used for materials, and the second channel is typically used for light baking. A light map UV is used to determine how baked lights and shadows are displayed on the object. These can be created automatically in unrelention when you import a model, but you may want to create your own light map UVs and your 3D modeling program. Let's create our first UV that we will use for the material on this table. First, select all of the faces on the object, then add a modifier. If you wanted to create your UV based on a geometric shape, you could choose UVW map. But I simply want to unwrap this 3D model onto a UV grid, so I'll choose unwrap UVW. Notice that by default, we're applying this UV to map channel 1. Remember, our first channel will be used for materials in unrelention. Here edit UVs choose Open UV Editor. And here, we can see all of the faces of our object. We can see which is which by selecting them in this window. I would like to simply flatten this 3D model onto the grid, so I'll go up to mapping, and choose flatten mapping. Rotate clusters might cause some faces to be oriented the wrong direction, so I'll uncheck that. UVs created for textures do not need to be constrained to the size of the grid, so uncheck normalize clusters. Remember, UVs created for light maps do need to be constrained to the size of the grid, so you should always keep that option checked when creating light map UVs. Hit OK, and close out of the window. We could also add a second unwrap UVW modifier, and choose map channel 2 for a light map UV. Open the editor, choose flatten mapping, and normalize and rotate clusters. If you know some parts of the model should have greater light map resolution in Unreal Engine, you could even scale some of these shapes to make the more important areas larger. Just be sure that they don't overlap, and they don't go beyond the edges of the grid. At this point, we could add a map scalar modifier to all of our 3D models in the project to scale the overall size of our materials. This can be helpful if our materials are being displayed too large or too small in Unreal Engine. Select all geometry, go to modifiers, map scalar, and set the scale to 100 centimeters. By doing this, we're ensuring that all of our materials will be applied at the same uniform scale. This will be really important for when we import our model as a data Smith file. Usually, this will produce a really nice result, but sometimes you may want to create your own light maps externally.
