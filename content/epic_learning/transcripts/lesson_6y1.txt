This is Kevin Lyle with Epic Games with some updated information on installing Data Smith plugins for Revit. Starting with Unreal Engine 4.24, the Data Smith Importer plugin is included with Unreal Engine. If you start with a blank template or need to enable Data Smith in an existing project, you may need to enable the Data Smith Importer in your project. For this course, an architect created a house in Revit with the intention of utilizing Unreal Engine for visualization. This model has hundreds of objects, lights and materials already prepared by the designer. We need to install a Data Smith exporter into Revit to create Data Smith files for import. On Unreal Engine's webpage, search for Data Smith downloads and open the link. Beware that links to webpages may change. Scroll down to the Autodesk Revit exporter and download the Revit exporter for your version of Unreal Engine. After download, launch the file. And in the setup wizard, advance through the prompts and choose to install the latest version of Revit that you will be using. When the install is complete, we will be able to export Data Smith files from Revit into ready to use assets in Unreal Engine. In newer versions of Unreal Engine, the launcher has been updated with new industry-based workflows for template projects. To find the blank template described later in this course from the Epic Games launcher, launch Unreal Engine. Scroll down to the new project categories and choose Architecture, Engineering and Construction. And then the blank template. There are a few differences in the new templates. When you create your AEC project, you can now choose to enable ray tracing and other options, depending on the template, when the new project is created. The AEC templates all include the new Easy to Use Sun Sky object, which has an integrated skylight, a directional light, and sky atmosphere. In the older template, the daylight was from separate individual light and sky objects. The new integrated sun sky makes setting up your daylight quick and easy. You may want to use this in your final project rather than the older methods, to adjust any of the objects in the sun sky, simply select them in the details panel. The directional light, for instance, now defaults to 75,000 lux. And with this course, you may want to adjust the settings to match with Steve's instructions.
