This starts with the assumption that you already have your phone or tablet set up to work with UE4. If not, please watch the Android setup video before going through this one. Please be aware that though the process is nearly identical to Android deployment, AR Core will only run on capable hardware. Be sure to check this link to see if your particular device is supported before continuing. With the assumption that your device is all set up and that it is compatible, let's go ahead and create a new project. For this project, we are going to use some default engine content so everyone can follow along easily. Let's launch the engine and create a new project. Select Blueprint and Handheld AR. Next select Mobile-slash-Tablet for Render Mode. Now select a place to create our project and give it a name. I'll use AR-Underscore example. Finally, press Create Project and give UE4 a moment to launch. Since augmented reality is highly dependent on the device for testing, it is critical that we can rapidly launch to the device. Before we can do that, however, we need to configure our project for the Android platform. Let's do that now. Simply go edit, then project settings. Select Android from the list of settings on the left, then click to configure the package and accept the license if you have not already done so. We can now close the settings window. Assuming your device is connected, you should see your device in the launch menu. Let's push the project to our device. This will package it up and deliver it directly to our Android phone or tablet for testing. The project was successfully launched on my Google Pixel 3. As you can see, I am able to use my phone to look around my office and place random objects around the room. You should have fun playing around with this template. It's a great starting point and is a lot of fun to tinker with. Once complete, let's go ahead and quit the application. Now go ahead and uninstall it from our phone. Now that our project runs on our phone, we can go ahead and build for our multiple devices. Back in UE4, we can now simply select file, package project, Android, ETC2, and we should be good to go. Select the location and hit save to package the project. Notice that when we deployed for Android, the deployment was identical except for the need to test more directly on the device. You can't really simulate camera interaction, so it becomes a bit more critical. Let this complete its work and I'll meet you in the export folder. If successful, our output folder should now contain at least one APK file, an OBB file, and two bad files. The bad files will be your installer and your uninstaller, while the other files are required for building. At this point, you need to be sure your phone or tablet is connected and awake. So, double click the installer and it should begin packaging and sending it to your device. Once complete, you should be able to launch from either your phone or your tablet. That concludes how to deploy AR to your Android device.
