Included with the Pixel Streaming plugin are various blueprint nodes that we use to establish a connection to our servers and allow communication back and forth. Let's go ahead and take a brief look at them. All these can be found in the palette under the Pixel Streaming section. We're not going to cover all of these. There are additional ones. We're just going to cover the important ones for connecting, sending and receiving data. The most important thing to understand with the Pixel Streaming is the Pixel Streamer input component is used to manage the connection between the project and the server. This is automatically added to the player controller if you're running in the correct mode, standalone or packaged. It's accessed by getting the player controller and getting that component. These two nodes right here are your primary interface to working with Pixel Streaming inside of the engine with blueprints. With that said, getting the information from the server into your project is done by using the bind event to on-input event node. You can see here we are getting that Pixel Streamer input. We are using the bind event to on-input event node. And we have a delegate off of that that is going to be our custom event that is fired whenever we get information from the server. Now the information we get from the server is this descriptor, which is a string, which is basically a JSON value that comes back and then we can choose to do what we want with. In this case, there is a special node created called getJsonStringValue. It takes in that Pixel Streamer input component, takes in the descriptor from our input event, and then we can ask you for a specific field name and get back the value that was in there. This is how we get information interactively from the client. Once we have that information or if we need to send back information for some reason, we would use the sendPixelStringingResponse node, which you can see here, which again takes in that Pixel Streamer input component and sends back a descriptor to the server. The nice thing is we don't have to type in our descriptor by hand. We can use the addJsonStringValue node, which you can see here, which allows to easily create JSONStrings out of descriptors and fields or keys and values and send that on to our Pixel Streamer response node.
