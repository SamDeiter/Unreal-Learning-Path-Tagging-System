To follow along with this course, you'll want to have an architectural exterior scene much like the one I'll be using here. This scene is a rather large complex, but smaller exteriors, such as residential buildings, can still be put together following this course. This scene was built in 3ds Max and makes use of V-Ray materials, but you could just as easily use a scene from Revit, Maya, or Blender, and you could also opt for standard materials. You should already be comfortable creating 3D content and should understand the basic operations within Unreal Studio. If you aren't yet familiar with Unreal, I advise you to stop this course and instead go through some of the basic Unreal tutorials on using the interface, working with the Material Editor, Blueprint 101, working with the Mesh Editor, etc. If you have the basics down, you should be fine. But even if you don't, you should still be able to follow along with this course pretty easily.
