Creating assets for any kind of visualisation work, including architectural, is a process that can take some time. But even once we have them, that isn't the end of the process as they now need to be placed and integrated into our Unreal level. And while this is usually a painless process, there are certain types of scene assets that can greatly benefit from using blueprint-based tools to help speed up the placement process and make the end result look a little more natural. This is exactly the helpful tool that we will look at constructing in this course. In fact, let's fire up the latest version of the Unreal Engine at this point, which at the time of recording this course was 4.25 and take a look at this tool in action. Once greeted with the Unreal Project Browser then, we can click the More and Browse buttons and then locate and open the U Project file contained in the Course Files folder. Here, we can see the blueprint completed in the level. Now we will build useful aspects such as an adjustable spawn box that can be set to any size we wish, but we will build a parameter that allows us to determine how many assets are to be distributed, making it very flexible for any kind of project. And on top of this, the user will also be able to select which actors are to be included in the scatter process. Meaning this tool can be used for a wide variety of applications from scattering whole buildings to distributing foliage. Going even further though, we will construct the ability to cluster the mesh actors in the centre of the spawn area. Now we will also set up a Scale file off to create a more natural look to the placement of certain assets, so ones that may be a more organic in nature. Now the cool thing here being that if we just open up the blueprint, we are using relatively few nodes to create a really robust and production ready scattering tool for use on our own projects. As you can see, this tool will not only save time on projects, but also increases overall quality with natural looking scattering results. As I am sure you are excited to create the blueprint, without any further delays then, let's get started and dive right in.
