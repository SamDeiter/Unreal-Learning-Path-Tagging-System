If you are opening the control rig editor for the first time, it might look a bit intimidating, so let's break it down into different sections and see what each section is meant to do. On the left here we have the viewport which gives us the visual representation for all the regaliments as well as the bones and a lot more. If you click on the view option I can place at the top left of the viewport, you'll see a different section with options specific to control rig. Navigating in the viewport is similar to any other Unreal viewport. Moving on to the tabs here, first we have the Rig hierarchy tab where we can see all the joints of the character as well as controls and nulls that we create going forward. Next tab is the execution stack which will display the complete flow or the order of execution that occurs in the rig graph, so you can easily see what gets executed first for easy debugging. For that we have the curve container tab, this contains all the curves be it blend shapes or material curves that you've imported with the associated skeletal mesh. It will also display any custom curve that you'll create here. Then the final tab here is my blueprints. This displays all the different elements that belong to this blueprint including graphs, functions and variables. It's quite similar to any other blueprint that you'll see in Unreal Engine. Then this rig graph here is where the actual execution takes place. So this is where you'll use all the nodes and connections to make your control rig functional. Down here is the compiler results, this will show the time it took to compile your nodes and logic and it'll display if any error is present in the graph. Then there is details panel where you can access and edit properties related to all the rig elements and nodes. Finally there is preview scene setting. This allows you to change a number of settings for the preview scene in the viewport which includes assigning an animation to the preview mesh, switching the preview skeletal mesh and changing other viewport settings like lighting, environment and some post process settings.
