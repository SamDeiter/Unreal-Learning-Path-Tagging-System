Welcome to the course using Data Prep in Unreal Engine. In this course, we'll learn about how to create a Data Prep asset and how to code recipes in the Node Graph to modify, optimize, and manipulate how a DataSmith file is imported into Unreal Engine. When you import a DataSmith file into Unreal Engine, you're able to import geometry, materials, textures, animations, lights, and cameras, whatever you chose to export from a 3D modeling program. Once you import your content, you're able to make adjustments to optimize or modify your scene. However, when you're working with extremely large DataSets, this can take a very long time. Using the Visual Data Prep system in Unreal Engine, you can save yourself a lot of time by automating some processes right when you import. Furthermore, you can use the system to reprocess your data whenever you need to re-import your model. In a Data Prep graph, you can create reusable actions called recipes to reorganize, optimize, and modify various scene elements before they are added to the viewport and the content browser. We could use recipes to perform operations like filter assets based on metadata, merge similar objects, replace materials, replace meshes with randomized rotation values, or update Lightmap UV resolutions. In this course, you will learn how to create a Data Prep asset, how to create recipes to perform a few different operations, and how to import, process, and commit changes to add the DataSmith file content to the content browser and viewport in an Unreal Engine project.
