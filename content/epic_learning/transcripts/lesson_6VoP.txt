One of the best demonstrations of the power of Unreal Engine containers is the pixel streaming example that ships with Unreal Engine 427. Pixel streaming can be a complex system to deploy, but containers significantly simplify that process and allow it to be automated as demonstrated by the example. You can find the example files in the Unreal Engine source tree under Engine, Slash Extras, Slash Containers, Slash Examples, Slash Pixel Streaming. We have three items here. The file Docker-compose.yml is a YAML configuration file that describes how to run a minimal pixel streaming deployment in containers. The file run.sh is a script that uses the Docker Compose command line tool to run the example. And the directory project contains a Docker file for building a container image which encapsulates a demo Unreal Engine project. Looking at the contents of the YAML configuration file, there are three containers that make up the minimal pixel streaming deployment. The first container is the Co-Turn Turn Server, which allows client devices to access the WebRTC stream even if firewalls or other network topology issues would otherwise prevent them from connecting. This is the official Co-Turn container image from Docker Hub. The second container is the Serious Signaling and Web Server, which serves HTML files to web browsers and helps establish WebRTC connections between pixel streaming applications and client devices. This is the Serious Container image that ships with Unreal Engine 427. The third container is the Unreal Engine application itself, whose output will be streamed over WebRTC via pixel streaming. We build this container image from source using the Docker file in the project directory. The Docker file for the demo project is quite straightforward. It uses the Unreal Engine development container image that ships with Unreal Engine 427 to build and package a first-person Shoo-Shoo sample project with pixel streaming enabled. It then copies the package files into the pixel streaming runtime container image that ships with Unreal Engine 427 and configures the startup parameters for the project. To run the pixel streaming example, simply execute the run.sh script. This will automatically download the container images for Co-Turn and Serious and build the container image for the demo project using the supplied Docker file. This process can take a few minutes, so I'll speed up the video here. Now that the container images are all present, the three containers have started automatically and everything is up and running. The pixel streaming deployment is now ready for connections from a web browser. If we open up a browser and connect to the loopback address 127.0.0.1, we can see that the pixel streaming page is ready for interactions. Simply click the on-screen prompts and the stream will start. We can now move around the map and interact with the demo project just as if we were running it directly. With only a couple of configuration files and a single command, we've built multiple container images and deployed a fully functional pixel streaming setup. This is just one example of the way that container support empowers Unreal Engine developers to simplify their workflows and create exciting new solutions with cloud-native technologies.
