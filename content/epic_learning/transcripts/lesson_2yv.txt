Though not technically a packaging tool, the Export to Zip feature offers you a convenient way to rapidly export your project, all wrapped up in a zip file. With this tool, you can transport or backup your project quickly and easily. To begin, let's launch the engine and create a new project. Now, let's select Blueprint, Blank, and include the starter content. Now, let's select a location and name the project. I will call mine Zip Test. Because Export to Zip is not actually a packaging process, it is very fast and easy and very unlikely to fail. That said, because it is not packaging your project, it also will not create a build of your game. Instead, it will simply create a Zip Archive and copy your entire working project to it. Let's go ahead and do that now. Simply select File, Package Project, and select Zip Up Project. Now, select the location where you want to save the archive, and press Save. Now, all the required project files will be bundled up for you. Let's just give it a second to complete. Looking on the desktop, I can now see that my project exported correctly and that the zip file was made. I now have a transportable copy of my project and it is all contained in an easily managed zip file. The most common use case is likely for taking your project with you to another location, so you can work on it remotely. However, they are also useful as backups, especially when experimenting. Either way, simply unzip and launch the project file if you wish to work on the copy. Sharing or backup, it's that easy.
