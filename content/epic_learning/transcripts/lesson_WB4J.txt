Welcome to developing for the HoloLens 2 in Unreal Engine 4. This is an 11 course learning path designed by Microsoft's HoloLens 2 team and Unreal Online Learning. If you have been following along through the learning path, welcome back. If you would like to follow along from the beginning where we prepare Unreal Engine 4 mixed reality development, find this learning path on the Unreal Online Learning course library. This is course 11 where we will discuss creating a multi-user experience with Azure Spatial Anchors. We're going to discuss some important topics that relate to more advanced features of developing for the HoloLens 2. This will include a discussion about creating mechanics that can be experienced by many users with devices other than the HoloLens 2. After setting up our Azure Portal account to use Azure Spatial Anchors, we will set up our project to connect to and read from our newly created resource. We will progress through this course to construct, save, delete, and load Spatial Anchors in our environment that can be found and utilized by other users and other devices. We're going to be using a modified version of the optimized project that we made from the tools and principles for project optimization course. Let's get started in the next module where we will prepare our Azure Portal account and create a Spatial Anchors resource.
