Blueprint Communication is a fundamental part of working with Unreal Engine and Blueprints, while you could try and contain all of your code within the Level Blueprint or even a single-actor Blueprint. You might run into issues managing all that information. By breaking down what you want to do, you should be able to find a way using the methods we covered in this course to create an efficient design, such as using the Level Blueprint or communicating between components in the same blueprint. We exposed variables inside of a Blueprint to make them public so that way we could set them up at design time and we used casting to confirm the item that we want to communicate with. We created a Blueprint interface to allow us to communicate generically and message other objects so that way if it doesn't support it, it just simply fails silently, as well as event dispatchers to allow us to create a list that things can listen in on. We also looked at the Git Actor nodes as a simple way to Git Actors of a certain type, so we can start that communication process. I really hope you enjoyed this course and took away some useful information on how to communicate between Blueprints. Some of these concepts are more difficult than the others, but after this course, you should have the basic idea of how we can communicate between objects in our projects. If you feel you are stuck, try all the methods to see which might work well for your goal. Keep in mind, with all things related to programming, there's usually more than one way to accomplish your goal, which does not mean any way is more correct than another.
