In order to see the grass system working, we will need to make use of the landscape painting tools in Unreal, just as we already have in a previous section. And lay down some painted layers so as to allow us to choose where we want the grass to be spawned. How do we go about doing this? Well, first of all, we will want to make some adjustments to our landscape material so that it knows where to place the grass. Before we begin though, we will need to create a grass type. And so to do this, we will, in the content browser, right-click, and then from the menu displayed, go to the foliage section and click the landscape grass type option, giving it the appropriate name of grass underscore two. Let's then open up the landscape grass type by double-clicking on it. And once opened, adding a new item to the array by pressing the plus icon to the right of the name. Inside the actor rollout, we want to look for the grass mesh section and then after clicking on the input box type grass as the search term and then click on the grass static mesh actor to load it as the mesh instance that will be used. We will quickly change the amount of grass we are getting here by setting the density value to 750 and the scale max value for the x, y and z axes to 4. This will give us more grass in our scene and add a little size variation into the mix as well. Of course, we are just inputting quick parameters here so as to show you how to use the tool, but more time and care on these settings along with the use of multiple grass meshes would likely produce a much better looking result. With the static mesh added and the density set to ensure that we are spawning enough of the grass, let's make sure that the meshes are randomly rotated and aligned to the landscape itself via the checkboxes. Once done, we can then make sure that the grass only spawns wherever we have painted the grass material, thus making the whole process a little more procedural and controllable. Inside the content browser then let's come to the landscape material and then double click to open it up. Once open we can right click into M empty space, search for the landscape grass output node and then add it to the material. If we then expand the already existing entry or add an element if one doesn't exist, call it grass, and again if needed, select the grass landscape pipe from the grass type dropdown. Once done, we can again right click into M empty space, search for the landscape layer sample node and then add that to the material as well, setting its weight to 1, after which we can pipe the result into our newly created grass output node. We will also need to make sure that we give it the parameter name of grass so that unreal knows that it should reference the grass type we created earlier. Which once done means we can save the material and then view the results inside the 3D view. What we have hopefully seen here then is the potential that comes from adding foliage to a terrain in a more procedural way. The speed and ease of doing things this way, making it a very suitable option for use with large scale landscapes. We do need to also remember that this approach can be used with various textures so as to ensure that it feels as natural and organic as possible.
