When looking for ways to speed up our lighting workflow, one possibility we could consider is to create a reusable light actor that contains both a mesh and appropriate light that we can then manually place in a scene. One advantage to this approach is that if we want to say make a change to all of the lights in a level, we could easily come back to the original actor in this workflow, make our changes there and then have all of the instances of that actor in the level update automatically. We can change them individually rather than collectively if we want and we also don't have to worry about individual light placement as we did in the first video of the course, given that the light will always be in the same place relative to the fixture mesh, every time we place the actor in the scene. Now do we go about adding one to our level? Well let's make a start here by setting up the base actor and its components. Inside the content browser then let's right click, choose Blueprint class and then click the actor option. Good naming conventions are always required for a well-organised project and so let's type the name IES, underscore ceiling, underscore light. So which we can double click to open up the actor. We can now click the add component button and choose static mesh from the list, calling it SM underscore C light and then press enter to lock the change in place. Over in the details tab let's click the static mesh dropdown and locate our ceiling light, or any light mesh that you want to add to your scene. Now unfortunately the mesh files weren't named in the particular asset I am using and so I will be adding 290579 which again highlights why good naming conventions in a scene are essential. We see another problem here in that the exported objects don't have correct pivot placements, meaning we also need to add a location offset here of x1530, y-1260 and z-2.8. Now we are doing this so that when we place the actor in the scene the pivot will always be at the top of the light where we want it as that will make light placement very easy in terms of dragging and dropping into the scene. Let's then select the actor root so that our next component is a child of the root and not of the mesh and then click the add component button and again let's search for the word light, after which we can click to add a point light to the actor. We will need to make sure that its mobility setting is stationary so that we can change its intensity at runtime if needed and then in the details tab we can scroll down to the ies texture drop down and add our down light ies file, after which we may need to rotate our light by 90 degrees using the rotate tool and just keep an eye on the light distribution pattern to see if this is the case in your scene. Let's also move the light so that it sits just below our static mesh and as we are going to be exposing our intensity setting we will want to make sure that the use ies intensity setting is unchecked in this case.
