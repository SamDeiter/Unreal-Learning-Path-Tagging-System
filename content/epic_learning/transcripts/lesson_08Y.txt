Welcome to Developing for the HoloLens 2 in Unreal Engine 4. This is an 11 course learning path designed by Microsoft's HoloLens 2 team and Unreal Online Learning. If you have been following along through the learning path, welcome back. If you would like to follow along from the beginning where we prepare Unreal Engine for mixed reality development, find this learning path on the Unreal Online Learning Course Library. This is course 5 where we will add spatial audio to our project to capture the attention of the user and further immerse our holograms into our world. We're going to start by preparing Unreal Engine and our system for audio spatialization and distance-based attenuation. When ready, we will create new assets and prepare a provided blueprint that we can reuse in our projects. On the way, we will demonstrate the difference between spatial and traditional stereo audio and when to use each. When we have our systems built, we'll expand our audio and discuss the various revealed settings that will add some realism to our sounds and play them from an identifiable world location. This course is going to be a bit different than the other ones, in that I will not be recording from the HoloLens 2. All tests and demonstrations will take place using the input simulation that we set up with the mixed reality toolkit or MRTK. If you have not prepared Unreal Engine with MRTK, please see course 3, incorporate hand interactions with UX tools inside of this learning path. I will be using this method so I can best simulate what is known as head-related transfer function audio or HRTF. This is the spatialization technology that models how sound propagates around our head in the real world. In the next module, we will return to our world builder project to configure the plugin needed and adjust project settings to use spatialized sound.
