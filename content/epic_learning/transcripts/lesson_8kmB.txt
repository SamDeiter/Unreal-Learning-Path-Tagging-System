Let's start creating a custom control rig from scratch from the imported character. Control rig comes as a plugin, so make sure that it is enabled for the project. You can go to edit, plugins under animation category, there is control rig. It is enabled by default in UE5, but if you're migrating your project from UE4, then this might not be the case, so just make sure to enable this. Once control rig is enabled for the project, just right click on the skeletal mesh that you want to create a control rig for, and select create control rig. This will create a new control rig asset and it will automatically be named with a suffix control rig. Using this method is much easier and more convenient as it automatically creates an association of the control rig asset with the chosen skeletal mesh, and you can see the same on the thumbnail. Another way to create a control rig asset is by right clicking on the content browser, go to animation, select control rig and click on create. The preview icon here looks black because there is no skeletal mesh associated with it. You have to assign it manually when you use this method to create a control rig. In order to assign a skeletal mesh, you can simply double click to open the control rig asset. Under rig hierarchy tab, click on this green icon here that says import hierarchy. And then select the character which is skmanican in my case.
