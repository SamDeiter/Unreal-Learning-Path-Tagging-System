So, now that we have created our scatter tool, what next? Well, a good place to start in terms of working to improve our system even further would be by looking to expose some of the, as yet, unexposed variables that we create in the tool, in order to see if we can give the user yet more control over the final effect. Maybe we could also let the user set the amount of Z position offset used for object placement, and also try to introduce some extra options that might help in certain visualization projects. So, for example, we could add the ability to match the normal vector of any scene object that our scatter meshes come into contact with. The possibilities for the tool really are endless and are pretty much only limited to what we can imagine that we need.
