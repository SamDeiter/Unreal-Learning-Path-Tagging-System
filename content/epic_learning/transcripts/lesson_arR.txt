It is possible to complete this entire course starting from an empty Unreal Studio project. The assets provided to help you along include a PDF with useful links, a vignette texture, an image to use for tracking, a revet file, and the datasmith files that we'll create from that revet file. I've also included a handy batch file for resetting your head pose within the magically device. You can also download a completed version of the course project for review and comparison to your own work. Key stages of completion are saved into standalone maps for easy reference. Now that we've reviewed the course, exercise files, prerequisites, and the capabilities of the Magic Leap One device, we're ready to dive right into using Unreal Engine and the Magic Leap SDK.
