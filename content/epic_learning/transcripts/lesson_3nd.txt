Welcome to Revit Unreal Engine Fundamentals. My name is Steve Began and I am a virtual and augmented reality developer and visualization specialist for healthcare and architecture. I have been working professionally with Unreal Engine for five years and I have experienced creating enterprise applications for education, training and visualization. In this course, you will learn how to use DataSmith to transfer an Autodesk Revit file into your Unreal Engine environment and produce stunning photo realistic results. We'll cover how to set up your project with realistic, physically-based materials, how to use metadata from Revit and Python scripts to improve your workflow, how to light your scene, add post-process effects, and finally, how to showcase your work in editor or with high-quality video or photo renderings. You will learn about how DataSmith accelerates a visualization specialist workflow in Unreal Engine and how to push the limits of the Revit model's visualization capabilities. Once you finish this course, you will have a realistic environment created in Unreal Engine based on a Revit file, and you will understand the essential techniques you need to create your own architectural visualization projects. DataSmith is a collection of tools and plugins that helps users to bring their content into Unreal Engine more efficiently. By using a DataSmith workflow, we will be able to quickly import a large pre-constructed building from Autodesk Revit without needing to use an intermediary solution such as 3DS Max. We'll maintain all of our Revit materials, metadata, hierarchy, geometric instancing, lights, and cameras in our import. Traditionally, a designer would export their geometry as FBX files from Revit, then clean up that data in a 3D modeling program like 3DS Max, then import all of the 3D models as either FBX or OBJ files into Unreal Engine. By using DataSmith to import all of our data, we can literally save hours if not days. For this project, I'll be using Unreal Engine 4.22 and an architecture file created in Revit 2019. There is a Revit file in the attached files for this course that you can use to follow along, or feel free to use one of your own. For this course, you should already have a foundational understanding of Unreal Engine as well as how to navigate the editor and perform basic operations. Later in this course, we will cover how to use basic Python scripts to optimize your import workflow, but coding experience is not required for this course.
