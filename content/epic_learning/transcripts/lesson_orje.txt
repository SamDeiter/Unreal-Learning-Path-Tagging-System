This concludes the course on introducing the Unreupython API. We learned how to run Python scripts and unreal, how to use the Unreupython API documentation, how to get user selections from the content browser and outliner, and how to identify all assets of a specified class. We learned how to modify assets by getting and setting editor properties, and we generated valuable performance data by analyzing static mesh assets, actors, and components. We examined how to use built-in functions, DUR, and help to access additional functionality, and we replicated one of our Python scripts with a level blueprint to demonstrate the similarities between the two systems. We've only really just scratched the surface of working with the Unreupython API, but you should have a solid foundation to begin using this powerful system in your own projects.
