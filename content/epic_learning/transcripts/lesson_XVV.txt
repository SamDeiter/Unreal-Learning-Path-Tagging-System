DataSmith is a file type created by Epic Games that helps artists and developers to quickly and easily import their 3D content into Unreal Engine. In this module, we'll learn how to import a DataSmith file using a Data Prep asset. With a DataSmith file, we can quickly import geometry, textures, materials, lights, animations, and metadata from a 3D modeling program. To get started, make sure that you have downloaded the DataSmith X-Porter plugin for the 3D modeling program of your choice. You can find this on the Unreal Engine website. For this example, I'm using Autodesk 3ds Max. Also in your Unreal Engine project, you may need to enable the DataSmith importer plugin by going to plugins and enabling the DataSmith importer plugin. While you're here, also enable the Data Prep Editor plugin as well. Now, let's create a Data Prep asset in the Content Browser. Right-click, choose Data Prep, Data Prep Asset. I'll just call this Data Prep 1. Double-click to open the Data Prep Editor window. In this window, we can designate a DataSmith file or files to import, preview the import, and set up actions that we would like to occur on the file before we add it to the Unreal Engine project. Go to the Input section in the top right and choose a DataSmith file. I'm using this house model for now. Choose Import to bring it into the Data Prep viewer. It might take some time to compile shaders. This scene is already very optimized, but if you were to import a huge structure with hundreds or thousands of mullions, or if you import an extremely complex mechanical assembly, it would make sense to simplify some of that geometry now before it's added to your project. We first need to determine a selection criteria. Let's create a quick recipe down here in the graph to automatically create LODs for geometry that is high poly. Drag a Select by Triangle count node into the recipe graph. Set this to Filter by count that is greater than 500 triangles. Next, add a set LOD group node to happen after the filter. I'm going to use Level Architecture. When we hit Execute, this tool will perform all of the functions that we have set up in the recipe graph and show those results in this viewport. When that's done, you can hit Commit to add the model to your viewport and to your content browser with all of these changes. For large architecture or manufacturing files, you may also want to filter objects and merge or delete them from the import. This can be a really great way to perform those operations quickly. At any point, you can open this Data Prep asset, update the recipe graph, then Reimport, Execute, and Commit to make additional changes to your import.
