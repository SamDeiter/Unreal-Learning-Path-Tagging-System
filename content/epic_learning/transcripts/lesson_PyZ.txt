This video assumes you already have your phone or tablet set up to work with UE4. If not, please watch the Android setup video before going through this one. Assuming our devices are set up, let's go ahead and create a new project. For this project, we are going to use some default engine content so everyone can follow along easily. To begin, let's launch the engine and click on the new project tab. Set Blueprint and Twin Stick Shooter, next select Mobile Tablet for the Render mode, and now let's select a place to create our project and give it a name. Finally, press Create Project and give UE4 a moment to launch. Now that our project is created, let's give our project a quick play and make sure everything is working. Use WA S&D to move and the arrow keys to shoot. Press Escape to Quit. Notice that our display window was the typical display window and we lacked Android-like UI. If we want to get a more accurate test, we can also use the mobile preview found in the play drop-down. This method generally takes a little longer to test with as all the shaders must be compiled, but it is a more accurate way to test your game, if the target platform is mobile. We also get the benefit of being able to test our mobile controls. As you can see here, I can move around and shoot by just clicking and dragging on the little control pads. To quit the game, press TIL-DAY to open the console, then type Quit Game and press Enter to Quit. So we just completed the first step in deployment, primitive testing. Now let's go ahead and make sure our project is ready to deploy. If your phone or tablet is not connected to your PC, please do so now as we will be needing it soon. Now that we have tested to be sure our game works on a generated level, we need to make sure our project has been prepared for Android. To do this, let's head over to the Settings, Project Settings, and now let's scroll down our settings list to Android. You will see that at the top of the page, it will give you a warning that the project is not configured for Android. Fix this by pressing the Configure Now button to generate the manifest file. Make sure to accept a license file if you have not already done so. Once fixed, it will appear green and say platform files are rightable. Let's now rename the package to something appropriate like com.mygamecompany.mykoolgame. Now let's name our project appropriately. I will use TwinStick Shooter. If we were planning to use Google Play Services, we need to make sure the platform exists. Now scroll down to click Configure Now to build the platform into your game. At this point, you can select whatever options your specific game requires to run, but for our test, leaving them as default will be fine. Now notice how all the requirements for the Android store, such as icons and backgrounds, are able to be configured here. Feel free to use the defaults or fill them with custom graphics. Anyhow, let's go ahead and close the setting windows as we are done with it. Now that we are all done with our settings and our project is configured, we can deploy as we would to windows. If all you wish to do is deploy to and test on your specific device, use the launch menu and select your device. This will build a project onto your phone and will launch immediately when it completes. As you can see here, I have deployed to my tablet and it is playing as expected. If I look on the apps page, I will see my project as it was named in our settings. Let me just uninstall this. Directly sending your project to your device is great for testing and offers an easy path to deployment. However, we may wish to deploy to other devices and want an easier way. To do this, we need to package the content. Simply click File, Package Project, Select Android and lastly the platform you wish to target. I am going to use ETC2 for this build as it is safe assumption for most modern phones and tablets. If you navigate to the output directory, you should see there is an install.bat file. Double click that to install on your Android device. Once complete, the window will close. Check on your Android device in the apps area to check and see if it was installed correctly and test it. Looks like my project has deployed successfully and I am off to the races. If you had any trouble with sending your project to the device, please watch the Android setup tutorial.
