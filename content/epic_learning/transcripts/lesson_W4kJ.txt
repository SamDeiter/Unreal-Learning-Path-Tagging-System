Unreal Engine 5's animation mode allows you to utilize things like Control Rig and create new or adjust existing animations right inside of the Unreal 5 Editor viewport. We can do this by coming over to our animation tools and then selecting the various tool that we wish from the toolbar and adjusting the properties accordingly. Engine tools do need to work in conjunction with Control Rig. So if you do not have a Control Rig available, you'll need to set one of those up before you can fully utilize animation mode.
