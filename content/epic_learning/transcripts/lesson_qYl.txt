Inside the landscape options of the modes tab them, we will want to make sure that we have selected the paint tools. And also, make sure that we have the rock layer selected, and that we are using a brush size of 198 and a far-loved of 1, so that we can be confident of a decent coverage. Probably something worth noting here is that making large brush strokes and then modifying the size of the brush is the recommended approach, as this will ensure that there is variation within the painting. As we are doing this by hand and not via any procedural approach, we really need to do everything that we can to add break up history and naturalness to the areas that we paint. And although we are going to make use of the straight brush here, just to show how you can get a good start, the alpha channels should really be added into the mix, so as to add further randomness and break up. So painting some areas of rock then lets set a brush strength of 0.75 so that we can layer up the rock by painting multiple times over the same area. Though you can of course feel free to make use of a lower strength setting if you want more control over the layering process. Looking for the steep areas where soil might find it hard to settle then, let's start to paint our rock texture with a click and drag across the edge of the roadway embankment. This seems like a good place to start. Ideally, a road static mesh would be added here so that we could paint and blend, but again we will work with what we have. The once done we can start to concentrate on the verticals of the hills and the surrounding area, starting with quick long strokes so as to hopefully add a more organic feel to the terrain. And if we come across areas that are really steep, we can click and drag over them multiple times so that the rock texture is all we see there. Now continuing around the terrain, we will look at where we sculpted in erosion and adjust our approach to suit. As we paint the transition edge we are creating is a soft blend which whilst good in some situations doesn't mean that we should try to smooth out every transition as we again need to think about how the materials might blend on a real landscape. We also need to keep in mind that what we have here is probably going to be the hardest part to make look good as this is a long way from the final stage. More textures could be used to help improve things here, as could materials designed to add procedural detail and we would also want to make judicious use of static mesh files where appropriate to help augment and improve the believability of the landscape. So loose rocks, cliff sides and maybe even foliage or shrubbery such as grass, flowers and trees etc. At this point I am going to let you continue painting with these tools and I would strongly recommend that after painting the terrain you start the process over again, after both looking at some relevant reference material and after giving thoughts on how you might improve on the initial results that you produced. This being a process that can be repeated as many times as you like because each attempt will build both your skill with the tools and perhaps more importantly your artistic eye for what does and does not work for this particular terrain.
