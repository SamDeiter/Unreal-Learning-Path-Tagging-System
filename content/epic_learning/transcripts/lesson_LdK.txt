What is a project template and why do we want them? Well project templates are used when you're making a new project. When you start the editor, you go to the new project window, those are all templates. They're great for setting up a complete starting point for a new project. They can also contain large changes. You can enable or disable plugins by default and you can change project wide settings such as auto exposure and bloom. And then like level templates, they can actually contain content that is not included with the engine, content that you have added. The cons are, they are installed into your engine directory, so sharing is not as easy. And they can only be used to create new projects. You cannot be used to add to an existing project. Now you may have already used the new project browser before. Whenever you start up the engine by itself and don't select a project, you have the new project browser here. You can choose from a category and then we can choose from a new project template. It's going to give us some information about it and then we have some settings and then allows us to create a new template. So let's go ahead and get started at creating our new project template.
