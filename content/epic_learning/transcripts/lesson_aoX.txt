Now I want to go back to the material collection thingy. The difference between really a material collection and a single parents is that the material collection is basically shared with every material they use it. That means that changing the material collection will affect all of them. And you don't need, as you remember, we didn't need to specify any material. We just can get access to any material collection anywhere in any blueprint in Unreal. We don't need to tell him which material or which object and stuff like that. If we use something like here, the roughness or what it was before, which is a material parameter that is specific to that material, then we need to get first access to the material, then change it. And it will only affect that specific material. Because there is strength and weakness. And it's depend on each project which one you want to use. For the specific demo, it was making more sense to use a material collection.
