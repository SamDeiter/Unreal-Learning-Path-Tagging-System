Now that we have created the animation blueprint and we have included it in our character blueprint, we will now connect our motion capture application to the Unreal Engine. To do this, we will navigate to Window and click on Live Link. Live Link is the window where you can add different types of sources that will communicate with the Unreal Engine, sending live data feeds that will allow you to establish a live connection between your application and the Unreal Engine. Now I do want to repeat that for the purposes of this course, I am using a Rokoko Smart Suit Pro, so the names of the sourcing and the names of the nodes are Rokoko-specific, but keep in mind that the workflow I'm presenting is very general, and most other inertial suits that you can find out there will use the same workflow that I'm showing you right now. With that in mind, let's proceed. To add a new source, I will click on the New Source button, navigate to the Rokoko Studio Source, and select Studio. What I've done now is I've created a link between the Rokoko Studio application and Unreal Engine 4. If I click on the Studio Source, I can see some specific settings that I can change, but for the most part you don't need to worry about these. With that set up, I can close the Live Link window, and to make sure that both applications are communicating on the same board, so that the Live Data Flow can commence, I will now go to the Place Actors menu, and search for the Rokoko Receiver Actor, which I will drag and drop into my level, and make sure that the Rokoko Port number I have set here is the same as the one in the Rokoko Studio application. Once this match up, the Data Flow will commence between the two applications. Keep in mind that for this to work, you need to enable live streaming within your Motion Capture application, and you need to set the port number there as well. Since I'm using the default port, I don't need to edit this. With all that set up, we can put on our Motion Capture suits and start streaming the performance.
