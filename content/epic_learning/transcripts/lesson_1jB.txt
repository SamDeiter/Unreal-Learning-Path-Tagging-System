In this module, we will learn about the various types of files that we can import into Unreal Engine. We'll learn about recommended naming conventions and also how you may want to differentiate between different types of files that you import. Files that we import into Unreal Engine are imported non-destructively. For instance, if you import a PNG texture into an Unreal Engine project, the project creates a .uset file in the project's content folder that contains the information from the PNG file. So, when you are working with 2D and 3D files in your project, you are not working with the original files. Once we have made changes to a 2D or 3D file, we can re-import the file in our Unreal Engine content browser to quickly and easily update our .uset files. Unreal Engine supports FBX, OBJ, USD, and Datasmith 3D file types. FBX files tend to be the most common, so that's what I'll use for the majority of this course. The Datasmith file type is a unique file type that can be exported for most 3D modeling packages, and it can contain geometry, textures and materials, lights, animations, and metadata for every single asset. This can save us a lot of time if we're importing a complicated 3D assembly or a large architecture file. We will learn more about how to export and import Datasmith files later on in this course. Files that we import and save in Unreal Engine do have some file name restrictions. Every file's name, including the file path, must be less than 260 characters. Be mindful of this limitation if you're working in a project file buried several levels deep on a hard drive. Personally, I like to keep my project files as close to the root as possible to avoid any issues with file paths. File names cannot contain spaces or symbols. To keep files nice and organized, consider using folders and naming files with the common prefix and suffix. It's really easy to import a bunch of files into your Unreal Engine project, then forget to organize your project file. Also, keep in mind that if you migrate assets from one project to another, those files will retain their folder hierarchy and create folders wherever needed. File organization is important for every Unreal Engine project and it's something we should keep in mind right from the start. Here are some wood textures that we can use.
