Tracks are effectively a collection of properties for the object in the sequence. For example, we have these transform properties for the cube mesh, and we can control these properties in the track area to the right. If I expand the location track, you can see that there's an x, y, and z property. This coincides with the current world position of the cube in the scene. If I move the cube, you'll see that those properties change. So with our cube track in place, we can now begin to animate our first sequence. Up next, we'll start to animate the cube flying through our scene with keyframes. Keyframes are specific points which hold specific properties, and we can use multiple of them to define these properties over time.
