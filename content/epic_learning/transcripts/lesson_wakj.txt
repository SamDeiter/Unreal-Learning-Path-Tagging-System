In this course, we've made an animated sequence from start to finish. You can now create and add objects to a level sequence, allowing you to use keyframes to animate objects in your scene. You can use master sequences with multiple level sequences and cameras to have huge camera control over your animation. Finally, you can take everything you made in your sequence and render it into a series of frames with the movie render queue. With all that you've learned from this course, you can now create any number of sequences between using level sequences, adding objects and using keyframes to animate. You have all the foundation skills needed to animate any number of cinematics, short films, and more. If you'd like to learn more about sequencer, animation tools in Unreal Engine, or the movie render queue, head over to the Epic Developer Community for more excellent learning content from Epic Games.
