## 2025-02-18 - Optimized Semantic Deduplication with Precomputed Tokenized Sets and Inclusion-Exclusion
**Learning:** In nested loops performing comparison logic (like Jaccard similarity for semantic deduplication), performing string lowercase, regex tokenization, and filter operations on every iteration is extremely costly ($O(N^2)$ complexity on tokenization). We can optimize this by precomputing the tokenized Sets exactly once outside the loop ($O(N)$ tokenization) and mapping them using a local `Map`. Furthermore, we can calculate Jaccard similarity of two pre-allocated Sets directly by finding the intersection size and applying the Inclusion-Exclusion Principle ($|A \cup B| = |A| + |B| - |A \cap B|$). This avoids constructing a new union Set or Array, significantly reducing GC overhead and memory allocation.
**Action:** Always precompute expensive tokenization or serialization operations outside comparison loops using a local `Map` to preserve object/data purity, and optimize Jaccard/set operations using the Inclusion-Exclusion Principle to eliminate allocation overhead inside loops.
