## 2026-07-17 - Keyboard Focus Trapping & Restoration in Portaled Popovers
**Learning:** For interactive popovers (like `AccessibilityPanel`) mounted via React portals outside the main DOM tree, standard keyboard focus logic can accidentally allow tab leaks into the document body or focus loss on close. Combining keydown event listeners to intercept Tab/Shift+Tab with an open-state check and querying focusable elements within the portaled element enforces correct focus trapping. Utilizing a `wasOpen` ref inside a `useEffect([open])` handles focus restoration back to the trigger button safely without triggering accidental focus on initial mount.
**Action:** Always implement explicit focus trapping inside document keydown listeners for portaled dialogs, and use `wasOpen` refs to restore focus back to the triggering element on unmount/close.
