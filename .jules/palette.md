## 2025-07-31 - Modals and Popovers Keyboard Accessibility
**Learning:** For interactive popovers and modal dialogs (such as the `AccessibilityPanel`), adding standard WAI-ARIA roles (`role="dialog"`, `aria-modal="true"`, `aria-haspopup="dialog"`) and implementing WAI-ARIA focus behavior (automatically focusing the first element on open, trapping keyboard focus within the dialog container on `Tab`/`Shift+Tab`, and restoring focus back to the triggering element when closed via `wasOpenRef` in a `useEffect`) significantly improves the usability and accessibility of the interface for assistive technology and keyboard-only users.
**Action:** Always combine semantic ARIA tags with explicit React focus management (refs and keydown listeners) for popups and dialogs, and ensure consistent SVG/vector icon rendering via standard packages like `lucide-react` instead of loose platform emojis.
