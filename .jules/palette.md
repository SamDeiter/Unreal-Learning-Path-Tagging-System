## 2025-02-18 - AccessibilityPanel UDL Enhancements
**Learning:** For floating overlays and modal-like settings popovers (e.g. AccessibilityPanel), standard literal emojis/characters should be replaced with high-quality, accessible SVG icons from `lucide-react`. To fully align with the WAI-ARIA Authoring Practices, we should implement full keyboard focus containment (using custom keydown Tab/Shift+Tab handlers), auto-focus the first element (e.g. close button) upon opening, and use a `wasOpen` ref pattern to restore focus to the trigger button ONLY upon closing (to prevent accidental focus shift on mount).
**Action:** Always implement ARIA accessibility controls (aria-haspopup="dialog", aria-modal="true"), focus trapping, auto-focus, and focus restoration using a custom React useEffect/useRef logic whenever building or modifying modal dialogs and overlay menus.
