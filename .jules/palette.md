## 2026-08-03 - Accessible Modal Popovers and SVGs
**Learning:** For floating overlays and dialogs like the `AccessibilityPanel`, default literal emojis cause visual inconsistency across platforms and lack full styling capabilities. Furthermore, proper keyboard accessibility is often overlooked. Specifically, interactive popovers require focus restoration to the trigger element on close, focus-on-open when mounted, keyboard focus trapping (confining Tab/Shift+Tab navigation inside), and ARIA landmark roles (`aria-haspopup="dialog"`, `aria-modal="true"`) to guide screen readers accurately.
**Action:** When creating or modifying popovers/dialogs, replace emoji icons with standard SVGs (e.g., `lucide-react`), implement focus trapping in keydown handlers, manage focus transition state (`wasOpen` ref inside a `useEffect([open])` to restore focus on close), and add the required ARIA semantics.
