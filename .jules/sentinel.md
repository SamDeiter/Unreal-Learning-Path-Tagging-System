## 2026-03-03 - [HIGH] Enforce Admin Authentication on GitHub Workflow Dispatch (triggerDemandScrape)
**Vulnerability:** The callable Cloud Function `triggerDemandScrape` allowed any authenticated user to trigger a GitHub workflow dispatch via the GitHub REST API. This could lead to a Broken Object Level Authorization (BOLA/IDOR) issue and privilege escalation, where non-admin users could exhaust the GitHub Action run minutes, flood workflow queues, or trigger automated scraped processes on arbitrary engines.
**Learning:** Security gates (such as checking `request.auth.token?.admin === true`) must be applied globally on any administrative or mutation endpoints that invoke third-party APIs or processes. Assuming "internal use" or relying solely on a simple client authentication check without checking custom claims/roles is a risk to resource utilization.
**Prevention:** Always check both custom roles (like `request.auth.token?.admin`) and bootstrap fallback credentials for any high-privilege operations, and write dedicated integration/unit tests to verify both authorized and unauthorized user scenarios.
